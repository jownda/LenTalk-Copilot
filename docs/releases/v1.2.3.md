## 新增

- 图片生成改为后台任务模式：提交立即返回任务 ID，生成在桌面端后台继续执行，切换项目或重新打开后结果自动写回原节点，不重复扣费
- 新增统一 SQLite 任务记录（ai_generation_jobs），支持任务状态查询与中断提示，重启后未完成任务明确标记"可从节点重试"
- 新增「Sub2API 视频」推荐平台（video.rjm.us.ci）：/v1/videos 提交 + 自动轮询，本地参考图自动上传 /v1/files，参考图使用 Data URL
- 新增视频帧提取结果的画布自动放置逻辑（videoFramePlacement）

## 优化

- Seedance 视频模型按平台锁定规格：seedance2.5 固定 30 秒、seedance2.0 固定 15 秒，分辨率 720p，画幅 16:9 / 9:16
- 视频生成按钮防误点：生成中禁用，完成或失败后才可再次点击；提交带幂等键，重试不创建重复付费任务
- 电影提示词工作室：导演编译、连续性检查、镜头模板、资产库与参与者编辑等多处改进
- 更新弹窗简化，错误报告与上传节点、节点面板交互优化
- 中英文文案补全

## 修复

- 修复开发模式下生成任务轮询器被 React StrictMode 置假，导致后台已完成的图片任务不自动同步到节点（需切换项目才显示）的问题
