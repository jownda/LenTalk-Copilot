# v1.2.66

基于 `v1.2.65` 之后的提交整理。

## 新增

- 接入 RunningHub 画布 CLI（rhtvcli）：模型目录由服务端实时下发，含 Minimax-H3-RH-Enhanced 等标准模型 API 里没有的画布模型
- 新增「RunningHub 画布 CLI」设置卡：可查看可执行路径、登录账号、画布 ID 与目录同步进度，支持一键同步目录与参数
- 生成的图片/视频/音频改按本地时间命名（如 `2026-11-27-11-20-41.png`），同一秒多张自动加序号
- 右键菜单新增「重命名文件」：扩展名跟随真实文件、重名自动加序号、同名同内容合并，画布内引用该文件的节点一并更新
- 节点属性新增文件创建时间

## 优化

- 画布模型的参数（档位、尺寸、时长、比例）全部由模型 schema 驱动，不再写死在代码里，模型侧更新无需改代码
- 模型参数按需懒加载，单个模型约 2 秒返回；全量同步放在设置页显式触发，不占用启动时间
- 撤销/重做时自动修正被重命名文件的旧路径引用，不会因为改名出现坏图

## 修复

- 修复 `mj_imagine` 只上传一张参考图时被上游拒绝（HTTP 400「多图融合需要至少 2 张不同的图片」）
- 修复 Midjourney 分辨率档位与实际能力不符：改为标准 1024 / 高清 HD 2048 两档，不再发送无效的 `size` 参数
- 修复画布并发获取模型参数时触发 CLI 本机单实例锁冲突（`LOCAL_BUSY`）
- 修复生成失败时只提示「没有产出媒体 URL」、看不到上游真实失败原因的问题
