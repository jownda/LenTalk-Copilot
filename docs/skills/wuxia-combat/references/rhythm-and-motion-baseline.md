# 节奏与速度样片记录（非默认模板）

数据来源：一支 33 秒、1920×1080、30fps 的实拍近身格斗演示片（989 帧，36 个镜头）。以下数据描述这一支样本，只作为**风格参考**，不代表通用实拍规律，也不是剧情素材。它不能决定"谁打谁"，用户给出的时长和节奏优先。

引用规则：这些数字用于默认参数和校验，**不得**用来改变用户指定的事件、胜负或结果。用户给出明确时长或节奏要求时，以用户为准。

> 使用边界：下面保留的是旧样片观察及其旧映射，不作为当前生成默认。打斗逐0.5s交付、默认连续攻防、不自动插静腔；剧情/对白每2–3s一块。主文件写作硬规则和用户本次要求优先。未经当前逐帧核查的数字不可对外声称已实测，更不能保证视频模型执行。

|---|---|---|

## 二、段落节奏：簇 + 腔

实测结构不是均匀切分，而是**两个高频簇被两个静止腔隔开**：

```text
簇 A（交手）  5 镜，每镜 0.3–0.6s   ← 起势/接触/反应/位移各占一镜
静腔（锁定）  1 镜，1.0–1.1s，画面几乎不动
簇 B（再交手）4 镜，每镜 0.5–0.8s
静腔（留白）  1 镜，1.5–2.6s，正面静帧
```

这段样本里出现两个短镜簇和两个静止腔；它只是一个具体结构。当前输出不沿用两簇一腔作为默认；只有用户允许停顿时按需参考。

以下为样片观察的旧映射，仅用户允许停顿时考虑：

- 一段 10–15 秒的打斗，可参考 **2 个短镜簇 + 1 个静止腔**。
- 簇内每镜突出一个主要视觉任务。不要为凑节奏把不相关动作塞进 0.4s；用户明确给出的连续动作仍可同镜呈现。
- 静止腔放在**一次强接触之后**或**一次准备动作之前**，不放在打斗正中间。
- 长镜或静止腔可帮助观众重新确认空间；是否安排及出现频率由事件和时长决定，不设硬性间隔。

## 三、动作时长（30fps 实测，换算为默认值）

| 动作 | 帧数 | 时长 | 写提示词时写成 |
|---|---|---|---|
| 直拳起势 → 完全伸展 | 4–6 | 130–200ms | "0.15 秒内从肩侧到完全伸展" |
| 踢击起腿 → 腿到最高点 | 6–9 | 200–300ms | "0.25 秒内髋先转、腿到最高点" |
| 收拳/收腿 | 5–8 | 170–270ms | 常被切点吃掉，只在长镜里写 |
| 受击反应起始 | 接触后 2–3 | 70–100ms | "接触后两帧，头先动" |
| 被击退位移 | 8–15 | 270–500ms | "0.3–0.5 秒内退半个身位" |
| 完全静止（冻结/锁定） | 30+ | 1.0–1.1s | "整体静止 1 秒，只有呼吸" |

没有任何一帧是慢镜。**全片实速**。需要"慢"的时候，靠的是静止，不是变速。

## 四、四种重量交付方式（择一，不要叠用）

实测片几乎不用 hitstop，而是：

| 方式 | 做法 | 适用 |
|---|---|---|
| **拖影接触** | 运动末端轻微模糊，不遮住接触点，不做清晰定格 | 需要轻微强调速度时 |
| **受击位移** | 命中后 0.3–0.5s 内身体退 0.5–1 个身位，可双脚离地 | 需要显示力量差时 |
| **冻结强调** | 关键一次接触后整体静止 1.0s，镜头不动，只留一个细节在动 | 全片 1 次，放在最重的一击 |
| （可选）AP 双锁 | 跟移 → 骤停 → 0.1–0.15s 静默 | 用户要求"停住"或需要极强重量时 |

以上是可选的强调方式，选择其一即可，不要默认叠加。普通命中可以只写清楚接触和自然反应，不必强加特殊效果。配额：冻结 ≤ 1 次/15 秒，AP ≤ 1 次/10 秒（15 秒内最多 2 次）。

## 五、声音

实测片只有一条音乐床，无逐击音效，重量 100% 由画面承担。

- 用户没指定声音时，**不要**给每一击配"沉闷撞击声"。那会把节奏推向音效驱动。
- 写声音只写动作直接产生的：衣料摩擦、脚步、呼吸、武器与物体接触。音乐由用户决定。
- 声音先行（下一镜的声音提前进）是合法手段，但一镜只能用一次，且必须对应真实的动作线。

## 六、这套基准的边界

它是**演练式写实**：无慢镜、无特效，但有编排过的腾空与旋转。复制它的正确方式是复制镜头语法和速度纪律，把动作内容换回用户剧情。

剧情转译模式不要因为"这样好看"就自动给用户加腾空踢、旋身扫腿、1 秒冻结或甩镜；原创编排模式可按人物能力、动作目的和节奏设计招式，强调手段仍须有明确用途，不要默认叠加。
