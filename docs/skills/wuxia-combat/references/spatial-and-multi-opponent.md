# 空间、多人与持械调度

## 空间先行

先画人物和关键物件的位置：入口、出口、墙、柱、门框、台阶、可见障碍、光源和武器所在处。每次位移都要能在这张地图上成立。

## 多人

多人场景可以同时存在多条状态链，但镜头仍要让观众知道当前的主要威胁。通常让 1–2 人承担当前接触，其余人保持明确的接近、绕位、封路、恢复或被障碍遮挡状态。这个是可读性建议，不得用来改掉用户明确写出的多人同时攻击事件。

交接可以在前一个动作后果尚未结束时发生。转译模式必须保留用户指定的攻击顺序和结果，不为避免“排队”擅自添招；原创模式可设计攻击者交接、绕位和相互遮挡，逐0.5s记入动作表并维护各人的位置与状态。

## 狭窄空间

通道宽度、台阶高度和墙的位置决定人物能否并行、转身、挥动武器或后退。写清空间限制即可，不要替用户补写“为什么进入死路”。死路的动机只有用户提供时才能出现。

## 持械可读性

持续追踪武器：谁握着、哪只手、尖端或打击端朝向哪里、是否与物体接触、是否卡住或掉落。武器离手后不能下一镜无解释地回到手里。不要把“有刀/有棍”自动扩展为新的攻击或伤害。
