# 接触物理（含内劲等价链）

## 适用原则

本文件负责把接触写成可见过程。剧情转译不创建用户未给的攻击、伤势与结果；原创编排可在已定人物、兵器、伤势上限与结果内设计接触。两种模式都先从招式库、内力库取原词，再补线路和身体反馈。

内力只改变**量级**，不改变**顺序**。脚蹬地 → 髋转 → 肩送 → 末端 → 接触 → 形变，这条链在内力场景里一样成立，只是每一环的效果被放大。详见 `innerforce-and-qi.md`。

## 徒手动力链

按需要写出：脚的支撑、腿的传力、髋的转动、肩的送出、肘或手的末端轨迹。不要只写「他用力打」。

```text
脚蹬地 → 髋转 → 肩送 → 前臂/拳/肘走线 → 接触点 → 受击方形变
```

命中后，攻击者也要遵守重心变化：前倾、收步、重新支撑，或被自己的动量带走。**这一条在武侠里比任何特效都重要**——发劲的人必须有反作用，否则看起来像在推空气。

## 内劲等价链

```text
起势（沉腰／提气／屈膝） → 行气（沿脊、肩、臂或兵器可见） → 末端成形 → 释放 → 余劲
```

两条链是**叠加**关系，不是替代关系：内力可以裹在掌上，但掌仍要按掌的走线推出去。

- 只有气劲没有身体 → 像放技能，不像打架。
- 只有身体没有气劲 → 写实武侠档，完全正确；高武档则显得欠一口。

**判断该不该加内劲，看档位，不看爽不爽。** 见 `wuxia-style-tiers.md`。

## 持械动力链

持械动作至少交代四件事：

1. 哪只手握持，手腕和肘部处于什么角度。
2. 兵器从哪里起，沿直线（刺）、弧线（劈扫）、下压线还是推送线运动。
3. 接触的是人体、衣物、兵器、墙、地面、门框还是其他物件。
4. 接触后兵器是**继续通过、被卡住、反弹、脱手、被抓住**还是留在原处。

内力附着在兵器上时，额外写：附着在刃口、刃身还是整柄；附着后兵器的手感有无变化（有变化就必须演出来，例如挥动变慢半拍）；脱手后气劲是否随之消失。

**兵器的部位必须写**：剑用尖、刀用刃、枪用尖、棍用两端。写「挥刀攻击」而不说用哪一段，是最常见的含糊。

## 内力外放

隔空攻击（掌风、剑气、气环）必须写出**传播过程**，这是它与接触发力的唯一区别。

```text
起势 → 介质先动（空气扭曲、衣袖鼓起、地面尘线、水面波纹、草先伏）
→ 命中（接触点出现） → 身体形变 → 位移 → 余劲散开
```

顺序不能颠倒。**介质没动就命中，等于瞬移。**

武侠特有的一条：**先到后动**。力已经到了，环境反应晚 0.1–0.3 秒才起来。同时发生会显得轻，滞后反而显得重。

## 作用线与环境

环境响应沿作用线发生：灰尘滑开、水面被推开、门板振动、物件滚动、碎屑落下。

额外要求：

- 环境响应与量级匹配（见 `destruction-and-environment.md` 五级）。
- 破坏方向服从受力方向。
- 残留物（焦痕、裂纹、断口、压痕）持续到结尾。

## 受击顺序

```text
接触 → 短暂僵直 → 局部形变 → 脚下失稳 → 呼吸改变 → 延迟护伤或重新支撑
```

练过武的人可以压缩「短暂僵直」（抗击打更强），但**不能跳过形变与失稳**。跳过这两项，人就会显得像塑料模型。

**武侠还多一条：受击后的第一反应通常是「找回架势」，不是「倒下」。** 被打退两步之后，脚先稳住、手再抬起来——这个顺序体现的是「练过」。没练过的人才是先倒。

推、拉、拖、撞和摔不一定产生「命中僵直」。如果用户描述的是持续推动或被拖走，应写脚跟不上、衣物被拉紧、身体被带走和撞停，而不是凭空加定格。

## 量化

给出秒数和距离、步数或画幅占比。没有可靠依据时，使用相对量：半步、一个身位、四分之一画幅、退出三丈。

武侠的量级基准（**必须由小到大递进**，不能第一击就退三丈）：

| 情形 | 写实武侠 | 高武 |
|---|---|---|
| 普通一拳 | 后退半步，上身晃一下 | 后退半步，脚下石面出细纹 |
| 有效重击 | 一到两步，脚不离地 | 退出两三个身位，脚擦地犁痕 |
| 内力重击 | —（本档无隔空） | 推出数步，撞断一物或撞墙 |
| 决胜击 | 退两三步后膝一软 | 飞出数丈，撞塌一处结构 |

**写实武侠档不许出现「飞出」**。人被打击后是退、是滑、是倒，不是飞。飞属于高武及以上。

## 空场检查

写任何击退前，检查起点、方向、距离、落点、落点障碍五项。起点与落点重合时，模型会把人物钉在原地摆造型。修法见 `destruction-and-environment.md` 第 4 节。
