# 内力原词库（QI-01 ~ QI-60）

和招式库（ACT）同级的一套可追溯词汇：ACT 管**身体怎么动**，QI 管**劲怎么出去**。

**只在「高武」及以上档位使用。** 写实武侠档不用本库——那一档的「劲」只有尘土、碎石、衣料与呼吸。

## 取词路由

1. 先按 `wuxia-style-tiers.md` 定档。写实武侠 → 跳过本库。
2. 定形态：要推就取掌风族（一），要切就取指劲族（二），要变向就取借力族（五）。
3. 定代价：族四「护体与卸力」不是可选装饰，每次外放后要能接上一条。
4. 一条动作段里最多两个 QI 词：一个起势、一个主攻。三段连着用会糊。
5. 词只是索引，成品要写成可见画面，不许把编号写进提示词。

## 组合段（按段拼接，相邻段不同型）

| 段 | 组成 | 说明 |
|---|---|---|
| **起势段** | QI-23／QI-27／QI-41／QI-43 | 用地面或墙面把力借出来，先给观众「力从哪来」 |
| **主攻段** | QI-01~12（推）或 QI-13~22（切） | 二选一，不混用：面与线的物理不同 |
| **应对段** | QI-31~40 | 至少一条，证明对方也在用内力 |
| **收束段** | QI-49／QI-50／QI-60 | 落地或收器，把动作关掉 |

一次完整的交锋：起势 → 主攻 → 应对 → 收束。四段各一条，最多加一条补充。

## 禁用写法

| 禁用 | 原因 |
|---|---|
| 无起势直接发射 | 内力变成枪，身体没有参与 |
| 每一招换一种颜色 | 颜色失去信息量 |
| 气劲盖住接触点 | 看不清谁打到谁 |
| 气劲比人还大十倍 | 尺度与破坏量级不匹配 |
| 气劲像塑料／果冻 | 缺环境响应与消散 |
| 同一个招式连续重复三次 | 说明没有组合段设计 |
| 掌心一直发着光 | 气劲应该只在发力瞬间可见 |
| 用 QI 词当招式名念出来 | 词是索引，成品要写画面 |

---

**一句话总结**：先定档，再定形态，然后按「起势—主攻—应对—收束」拼段。词是拿来查的，不是拿来念的。
