# 风格四档与机动等级

写这个 Skill 最容易犯的错不是动作不好看，是**档位飘**：开场是巷子里两个人贴身短打，三拍之后主角一掌轰出十米气浪，再两拍开始御剑飞行。观众不会觉得爽，只会觉得前面那两分钟在装。

所以动笔前第一件事是**分线**，第二件事是**定档**，然后整场不许越级。

## 〇、两条线先分清

| | 武侠线 | 仙侠线 |
|---|---|---|
| 力的来源 | 身体 + 体内内力 | 真元 + 灵气 + 法器 + 阵法 |
| 时间结构 | 一瞬间的接触 | 前摇 → 释放 → 生效 |
| 代价 | 呼吸、手抖、力竭 | 真元、精血、寿元、法器、经脉 |
| 覆盖档位 | 写实武侠、高武 | 仙侠、仙侠大片 |

**档位是线内的刻度，不是跨线的滑杆。** 写实武侠升一档是高武，再往上就是换线，不是继续升档。完整分线规则见 `xianxia-lane.md`。

## 一、四档风格

| 档位 | 线 | 特效 | 破坏量级 | 典型用法 | 判断线索 |
|---|---|---|---|---|---|
| **写实武侠**（默认） | 武侠 | 无光效。只有拳风、碎石、尘土、衣料、呼吸 | 0.3 米级（瓦碎、木裂、衣破、皮下淤青） | 年代戏、传统拳械、镖局与江湖仇杀、写实向改编 | 用户只说了「打」「武打」「武侠」 |
| **高武** | 武侠 | 气劲可见但不夸张：掌风、气浪环、剑气、气墙 | 1~2 米级（石阶开裂、梁柱断、人被推出数步） | 江湖械斗、内功向、门派之争 | 用户提到「内力」「气劲」「真气外放」「掌风」 |
| **仙侠** | 仙侠 | 灵光、符箓、真元、剑芒、法阵 | 12 米级（场地破坏：墙塌、梁断、地面裂、人被轰出十几米） | 修真、宗门斗法、御剑、破阵 | 用户提到「灵力」「法术」「御剑」「符」「阵」「法宝」 |
| **仙侠大片** | 仙侠 | 法相、光柱、领域、天地异象 | 120 米 → 数千米级（削山、改河道、天象） | 国漫仙侠大片、天地大战、渡劫 | 用户提到「法相」「天地变色」「大场面」「渡劫」 |

**升档纪律**：

- 默认写实武侠。用户没点名，不得升档。
- 升档必须有触发词，且只能升一档；从写实直接跳到仙侠大片属于越级。
- 中途不得降档。开场高武、结尾变成纯写实，会让前面的破坏变成谎言。
- 用户明确要「混搭」（写实身体 + 一处超规格爆发）时，那一处只能出现在**高潮单点**，并且要有代价（力竭、兵器崩、经脉受损），不能变成常态。

## 二、机动等级：能飞多高，先定死

档位管特效，等级管**人能不能离地**。这两件事必须分开定，否则会出现「无光效的写实武侠里，主角踩着空气连换三次方向」这种硬伤。

| 等级 | 能力 | 空中占比 | 写法 |
|---|---|---|---|
| 1~2 | 凡人步法，全程地面 | 0% | 不许写飞、不许踏空、不许空中转身 |
| 3~4 | 轻功腾跃 + 短暂滞空约 0.9 秒 | 少量 | 跃起 → 提气停一口 → 空中打 1 下 → 落地 |
| 5~6 | 踏墙借力 + 滞空约 1.3 秒 | 5~8% | 借墙换位、空中换招、落地卸力 |
| 7 | 凌空飞行，悬停约 3.6 米 | 约 49% | 升空压迫 → 空中交手 → 俯冲压落 |
| 8~9 | 御空／飞天遁地，悬停 5~6.5 米 | 55~59% | 浮空战斗：抢高度、上下翻飞、俯冲再拉起 |
| 10~11 | 御剑飞行／凌空虚渡，可长时间滞空 | 60~75% | 空中施法、边飞边打、剑遁直线冲出 |
| 12 | 缩地成寸／瞬移 | 不定 | 位移过程被「折」掉，必须留残影或落点痕迹 |

**默认等级 3~4**（会轻功但打不了空战）。用户没说「能飞」，就不要让人在空中打第二下。

**仙侠线的离地必须有承载物**：剑（御剑）、云（云头）、气纹（凌空虚渡）、阵（借阵升空）。等级 7+ 也要写「气托」或「剑在脚下」——凭空站着就是飞行，不是仙侠。

**等级 12 的特殊规则**：瞬移不能用来逃避打击，只能用来改位置。写瞬移必须交代三样：起点的残影、落点的痕迹（尘、裂纹、焦痕）、以及「他为什么不早用」（真元不够、术有冷却、被锁灵压住）。

同场两人等级可以不同，这正是压制感的来源：等级 6 的人借墙换位，等级 3 的人只能在地上仰头追——**弱者被迫抬头，就是差距的可见形式**。

仙侠里更好的写法是**等级差 + 前摇差**：高阶的一方飞得高、法术大，但前摇长；低阶的一方飞不起来，但贴身快。这样才有得打。

## 三、特效六件：缺一件就不算写了特效

这条只对高武及以上生效。写实武侠档一件都不用。

| 件 | 内容 | 常见错法 |
|---|---|---|
| **形** | 环／膜／涟漪／拖尾／光柱／气刃／漩涡／剑影——具体是什么形状 | 只写「发出强大的气劲」，没有形状 |
| **色** | 一场只有一套对立色：青白 → 金白 → 金青 → 紫金雷 | 每个招式换一种颜色，像霓虹灯 |
| **量** | 半米／一米／丈许／数丈／十二米／一百二十米 | 尺度和破坏量级不匹配（气劲一米宽却炸掉半座楼） |
| **光** | 映亮石板／勾出轮廓／投出长影／照亮人脸 | 光只存在于气劲内部，不落在环境上，像贴图 |
| **破** | 碎石微溅 → 木裂 → 梁断 → 墙塌 → 地面下陷 | 只有光没有破坏，或破坏方向和力的方向不一致 |
| **影** | 一震／急推／甩镜／环绕／仰拍／俯拍——镜头怎么回应 | 气劲轰出，镜头纹丝不动 |

高武档只需要写满 **形 + 量 + 破 + 影** 四件；光和色可以极简（一层薄光、单色），写得越少越像真打。

## 四、仙侠加两件（共八件）

仙侠线在六件之上再加两件，缺了就会变成「会发光的武侠」：

| 件 | 内容 | 常见错法 |
|---|---|---|
| **源** | 这股力从哪来：真元／法宝／阵眼／地脉／他人借力 | 光效没有来源，术凭空出现 |
| **载** | 光挂在什么上：剑身／符纸／阵纹／掌心／瞳孔／宝塔 | 周身发光，找不到载体 |

**八件齐全 = 一段合格的仙侠特效。** 缺「源」缺「载」的，一律回炉。

**仙侠特效逐拍句式**：落到成品句子上，每一处术效拍点按固定顺序写全——

```text
镜头机位 + 人物 + 锚点 + 技能 + 粒子 + 光效 + 撞击位置 + 物理反馈
```

八件与句式的对应：**源／载 → 锚点＋人物；形／量／色 → 技能＋光效；光 → 光效；破 → 撞击位置＋物理反馈；影 → 镜头机位**；粒子是句式新增的一项，写「生成—行为—消散」三步。高阶术效再过能量实体化五道工序（道具化、生命周期、粒子受力逻辑、撞击前兆、静场信号），见 `SKILL.md`「能量实体化」；逐段要求与完整示例见 `SKILL.md`「仙侠特效逐拍公式」。

## 五、六个体检标记

写完自查，命中任一条就要改：

| 标记 | 症状 | 修法 |
|---|---|---|
| `fx-over` | 写实武侠档出现了光效、气劲、残影以外的超自然表现 | 删掉特效，改成尘土、碎石、衣料、呼吸 |
| `air-unsupported` | 空中有动作但找不到起跳面或中继接触点（仙侠：找不到承载物） | 补锚点或承载物，或把人放回地面 |
| `tier-drift` | 同一场里破坏量级从 0.3 米跳到 12 米 | 统一到同一档，或把超规格那一下限定为单次且有代价 |
| `effect-masking` | 光效盖住了接触点，看不清谁打到谁 | 缩光、缩短时长、把接触帧移到光之前 |
| `spell-no-cost` | 连放大术，人还站着，手不抖，法术不变小 | 补代价并累积：第三次必须比第一次小、慢、抖 |
| `formation-no-core` | 法阵铺满画面，找不到阵眼，也不知道怎么破 | 阵眼必须可见、可攻击；补布阵四段 |

## 六、跨镜留痕

破坏、气劲与法术的痕迹必须**跨镜保留**：

- 这一拍砸裂的石阶，下一拍还在裂着，不会自己复原。
- 气劲扫过的雪坡，留下一条压痕，后面的镜头能看见。
- 断掉的兵器不会在下一镜变回完整。
- **仙侠专属**：剑芒扫过的痕迹（一条整齐的切面）、雷击的焦黑、阵纹烧在地面上、灵光的余烬慢慢暗下去、法宝裂纹一直在。

留痕是档位的证据。删掉留痕，档位就变成无法验证的吹牛。

---

**一句话总结**：先分线（武侠／仙侠），再定「有没有光」和「能不能飞」，三件事定完再写字；写完自查六个标记。
