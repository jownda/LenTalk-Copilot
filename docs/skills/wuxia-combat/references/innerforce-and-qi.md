# 内力外显：气劲怎么写才不像特效

武侠和超能的根本差别不在威力，在**气劲的出身**。超能是「我发射」，武侠是「我这一掌把身体里的东西送出去了」——所以气劲必须**带着身体的痕迹**：出手前的重心、出手时的呼吸、出手后的反震。

## 一、四段：起势 → 行气 → 落点 → 余劲

任何一次内劲外放都要写满这四段，缺一段就会变成「手上突然亮了一下」。

| 段 | 必须写出 | 例子 |
|---|---|---|
| **起势** | 重心怎么沉、气怎么提、身体哪个部位先动 | 马步沉腰，双掌收于腰间，肩胛先内收再展开 |
| **行气** | 从哪到哪、走直线还是弧线、身体有没有跟着转 | 从腰经背到掌，掌心朝前推出，衣袖被内劲顶得先鼓起 |
| **落点** | 打在哪、接触面积多大、对方第一反应 | 掌风压上对方胸口，衣料整片贴陷，人退两步鞋底犁出土痕 |
| **余劲** | 气劲去哪了、消散形态、留下的痕迹 | 余劲顺着地面铺开，压弯一片草，扬起半米高的尘 |

**行气这一段最常被漏。** 只写「一掌拍出，气浪炸开」的，是把内力当成了枪——没有路径、没有身体参与，看起来就像后期贴上去的。

## 二、三种形态，三种物理

| 形态 | 作用方式 | 典型写法 | 不成立的样子 |
|---|---|---|---|
| **掌风**（面） | 面状推进，推开、压陷、掀翻 | 气流成半圆面推出，先压弯草，再推人 | 掌风像实心球一样把人撞飞（那是弹体，不是掌风） |
| **剑气**（线） | 线状切过，留下细痕 | 指尖一点，空气轻微扭曲，一线切过，竹节错开半寸后落下 | 剑气像光剑一样横扫一片（那是光效，不是剑） |
| **气墙／气环**（场） | 拦住、偏转、震开 | 双掌在身前划弧，身前空气变厚，石子打在无形处弹开 | 气墙像玻璃一样静止不动（应该随呼吸起伏、随受力变形） |

**形态与招式必须匹配**：推掌出掌风、指劲出剑气、抱圆出气环。掌法出剑气、指法出气浪，都是把内力当成了万能发射器。

## 三、离体不染色

气劲**离体之后就是独立的东西**，不许和人物糊在一起：

- 气劲与人物、衣物边界分明，不覆盖衣料本色，不把脸染成一片青。
- 气劲不是「贴在皮肤上的发光纹路」，除非用户明确要这种表现。
- 两股气劲相遇，交界线要看得清（谁在推谁），不能糊成一团亮斑。
- 气劲过处，环境要响应（草伏、尘起、水皱、烛火偏），但响应要滞后一点点，不能同时发生。

## 四、先到后爆：武侠的招牌节奏

这是 90 年代港式武侠最值钱的一条，也是 AI 最容易漏的一条。

**顺序永远是**：

```
招式先到 → 环境先留痕（裂缝、凹坑、压痕） → 延迟 0.2~0.3 秒 → 爆裂沿轨迹追上来
```

- 碎石、尘土、水花、断枝，是被**力的余波**追着掀起来的，不是和招式同时炸。
- 爆裂可以一波接一波，沿招式轨迹往前追，每波间隔 0.1~0.2 秒，越靠后越小。
- 先到后爆让观众看清「打中了哪」，再享受「炸得多大」。同时炸开只会糊成一团。

**写实武侠档不写爆炸，只写「先到后动」**：脚落地的 0.1 秒后才见尘土扬起，掌贴上胸口之后衣料才贴陷。

## 五、量级刻度：气劲多大，破坏就多大

| 气劲尺度 | 破坏上限 | 视觉参照 |
|---|---|---|
| 半米（掌前一层） | 衣破、发丝乱、草伏 | 近距离贴身发劲 |
| 一米（一人宽） | 木裂、瓦碎、人退数步 | 高武档常规 |
| 丈许（三米） | 石阶开裂、梁柱断、人被推出数丈 | 高武档全力 |
| 数丈（十米级） | 墙体塌、地面下陷、多人被震飞 | 高武顶格 |
| 十二米以上 | 场地改写、山体、地貌 | 换到仙侠线，见 `spell-and-ritual.md` 与 `xianxia-lane.md` |

**气劲尺度和破坏量级必须同时给。** 只给一个，模型会自由发挥，结果通常是气劲一米宽、炸掉半座楼。

## 六、代价：内力是要还的

写实与高武档，**每一次外放都要有代价**，至少一样：

- 呼吸：出掌后一口短促的换气，肩膀起伏一次。
- 手：掌心发白、指节发抖、虎口震裂。
- 步：退半步、后脚蹭地、重心下沉（反作用）。
- 幅度：下一招收得更小，不再全力。
- 面：额头见汗、太阳穴跳动、脸色由白转青。

中低档武侠里，「打完还跟没事人一样」比「打得不狠」更假。**力竭不是终点状态，是逐步累积的过程**：第一次代价是换气，第三次是手抖，第五次是抬不起手。

## 七、禁用写法

以下写法一律改掉：

| 禁用 | 为什么 | 改成 |
|---|---|---|
| 一掌拍出，气浪瞬间炸开一片 | 无路径、无起势、无余劲 | 沉腰、掌推出、气浪压过草、人退、尘起 |
| 内力汹涌澎湃，气息暴涨 | 抽象强化，没有画面 | 呼吸变长、衣袍鼓动、脚下石面出现细裂 |
| 浑身笼罩着强大的气场 | 静态光罩，像游戏 buff | 只有在受力时才显现的气膜，被击中处亮一下 |
| 每一招都有不同颜色的气 | 颜色失去信息量 | 全场一套色：本门一个色，对手一个色 |
| 剑气如虹，横扫千军 | 笼统形容词 | 一线切过，三根竹子错位，第二根先倒 |

## 八、气劲与镜头的配合

- **气劲出招时镜头要退**：不是被炸退，是被气浪推着轻微后仰（0.1~0.2 秒的机身后坐）。
- **接触点永远比光效重要**：光可以缩、可以短，接触点不能糊。
- **全屏光效限时**：单次不超过 1 秒，且必须有收束（收进袖子、散成雾、被雨打散）。
- **不要用气劲掩盖动作设计**：如果去掉所有气劲之后这一段没法看，说明动作设计本身是空的。

## 九、从内力到真元：同一条链，多一个来源

仙侠线的「真元」不是另一种东西，是**内力的上游**。身体链不变，但多出三段前摇。

| | 内力（武侠线） | 真元（仙侠线） |
|---|---|---|
| 存储 | 丹田，气感 | 丹田 + 经脉 + 金丹／元婴 |
| 外放方式 | 掌、指、脚、兵器 | 结印、掐诀、符、剑、阵 |
| 前摇 | 起势（0.1–0.3 秒） | 起诀 + 引灵 + 凝形（0.7–2.1 秒） |
| 通道 | 身体本身 | 身体 + 术（术是「外挂的通道」） |
| 代价 | 呼吸、手抖 | 真元团数、精血、寿元、法器损耗 |
| 上限 | 数丈 | 数丈到数里 |

**写法上的唯一差别**：内力是「他把自己的力送出去」，真元是「他借一条通道把力送出去」。所以仙侠必须写**通道是什么**——剑、符、印、阵。没有通道的真元，等于没有枪管的子弹。

仙侠线的六段、前摇、打断与代价清单见 `spell-and-ritual.md`；两条线的分工见 `xianxia-lane.md`。

---

**一句话总结**：内力是身体的延伸，不是手上的灯。写完自查——起势有没有、行气走没走、落点在哪、余劲去哪了、代价还了没有。仙侠线再加一问：**这条力走的通道是什么。**
