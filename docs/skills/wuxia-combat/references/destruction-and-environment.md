# 破坏与环境参战

破坏不是背景板，是**力量的可测量单位**。观众判断「这一掌有多重」，看的是瓦碎成什么样、梁断成几截，不是看光有多亮。

## 1. 七级破坏（武侠 + 仙侠）

等级只增不减。**6、7 级只对仙侠线开放**，且 7 级全场只能一次。

| 级 | 名称 | 可见表现 | 典型触发 |
|---|---|---|---|
| **1** | 微动 | 衣袂发丝、烛火、灯笼、落叶、尘土、水面细纹被带动 | 每一击的默认伴随反应 |
| **2** | 表面伤 | 瓦片碎、墙皮落、木桌裂、衣料撕开、皮开血出、竹竿断 | 常规命中、格挡、被击退撞物 |
| **3** | 局部断裂 | 梁柱断、栏杆崩、门板撞飞、窗棂碎、竹丛成片倒、酒坛炸开 | 中段重击、被击退撞物 |
| **4** | 结构塌陷 | 屋顶塌一片、棚架垮、楼板洞开、桥栏整段崩落、戏台塌 | 高潮前一拍 |
| **5** | 地形改变 | 石阶整段崩、地面下陷成坑、山崖崩落、水面炸开、雪坡滑坡 | 高武终局、仙侠常规大术 |
| **6** | 山体与地貌 | 削平半座山头、劈开一块巨岩、河道被截断、地面裂开一道丈宽的长谷、整片林子被推平 | 仙侠终局、元婴以上认真一击 |
| **7** | 天象 | 云层被撕开、方圆数里被雷反复打过、湖水被抽干一半、天光变色、山在动 | 仙侠大片终局、化神以上、渡劫、禁术 |

### 档位对应的破坏上限

| 档 | 上限 | 一场可用的最高两级 |
|---|---|---|
| 写实武侠 | 3 级 | 3 级一次 |
| 高武 | 5 级 | 5 级一次、4 级一次 |
| 仙侠 | 6 级 | 6 级一次、5 级两次 |
| 仙侠大片 | 7 级 | 7 级一次、6 级一次、5 级不限 |

### 分配建议

```text
0–3 秒：1 级为主，偶尔 2 级
3–8 秒：2 级为主，一次 3 级
8–12 秒：3 级，一次 4 级
12–15 秒：一次 5 级（高武以上）或一次干净利落的 4 级（写实武侠）

仙侠 15 秒：
0–3 秒：1–2 级（试探、符箓小术）
3–8 秒：3 级（法术命中、石柱断）
8–12 秒：4–5 级（场地改写，一次 5 级）
12–15 秒：一次 6 级（削山、裂地），留 1 秒收束
```

短于 15 秒按比例压缩，但**最高两级各只能一次**。

**写实武侠档顶格到 3 级。** 这一档如果有人一掌把屋顶打塌，前面所有克制的打斗都会变成笑话。

## 2. 方向纪律

破坏方向必须服从受力方向。这是最容易做错、也最容易被观众看出假的一环。

| 动作 | 碎屑方向 | 地面／环境反应 | 镜头运动 |
|---|---|---|---|
| 平推／直拳 | 沿推力轴向后方飞 | 双脚犁出两道平行浅沟 | 沿推力方向后跟 |
| 上撩／托掌 | 向上翻卷，落下时散开 | 前脚掌位置下陷，尘向上扬 | 轻微上摇 |
| 下砸／按掌 | 以落点为圆心放射外抛 | 下陷成坑，裂纹放射 | 下压后拉 |
| 横扫／横斩 | 沿切线方向横飞 | 弧形擦痕，竹叶成片被带走 | 侧向跟移 |
| 剑气／指劲 | 沿切线方向，切口整齐 | 被切物表面留下一条细线，先错位后倒 | 顺切线跟移 |
| 棍扫 | 沿棍端轨迹扇形散布 | 地面扇形擦痕，尘成一圈 | 跟着棍端走 |
| **光柱／天雷** | 从落点垂直向上掀，碎片先上后落 | 落点炸坑，坑底焦黑，边缘石面呈放射裂纹 | 固定机位或轻微上摇，不要乱晃 |
| **飞剑横扫** | 只在切线方向，切下来的部分先滑后落 | 切面光滑，断口有灼痕（剑芒高温） | 顺剑光方向跟移 |
| **土刺／地陷** | 从下往上顶，翻起的土块保持原形 | 地面整块隆起或下沉，边界是断口不是斜坡 | 低机位，随地面上升下压 |
| **冰封** | 不飞，就地凝结，冻住的东西保持原姿势 | 边缘有白霜扩散，缝隙里先结冰再崩 | 缓慢推近 |

**红线**：人向右飞，碎屑往左飘——这一镜直接废掉，观众会觉得「假得不讲道理」。

## 3. 材质响应

材质不对，观众立刻出戏。武侠场景里的东西和现代都市不一样，写错比写少更糟。

| 受击对象 | 正确响应 | 错误响应 |
|---|---|---|
| **瓦**（屋顶） | 单片碎裂、成串下滑、踩上去先陷再碎 | 像玻璃一样整片炸开 |
| **青砖／石阶** | 崩口 + 石粉，裂纹沿受力方向延伸 | 干净地切出一个圆洞 |
| **木柱／梁** | 劈裂 + 纤维外翻 + 木屑飞，断口参差 | 断口平得像切豆腐 |
| **竹** | 弯折后爆裂，纤维撕开成丝 | 像木棍一样干脆断 |
| **纸窗／窗棂** | 纸先鼓再破，木棂折断 | 整面消失 |
| **酒坛／陶器** | 裂开后炸成片，酒液泼出，碎片带釉光 | 碎成粉末 |
| **布幔／旗** | 被气流鼓动、撕裂、贴向受力面 | 毫无变形 |
| **灯笼** | 被压偏后摇晃、烛火倒向一侧、纸面烧穿 | 直接爆炸 |
| **水面** | 环状波纹 + 水柱 + 白沫，涟漪向外递减 | 像固体一样裂开 |
| **雪** | 表层被压出凹痕、扬起雪粉、坡面滑动 | 像沙子一样扬尘 |
| **人体** | 软组织压缩、骨性支撑处形变、衣物紧贴、退步 | 像橡胶一样整体弯曲 |
| **气膜／护体** | 受力处凹陷 → 涟漪扩散 → 裂纹 → 碎裂 | 直接消失 |
| **兵器** | 刃口缺口、刃身弯曲后弹直、火星、脆响 | 直接断成两截（除非明确设定） |

**仙侠材质（只在仙侠线用）**：

| 受击对象 | 正确响应 | 错误响应 |
|---|---|---|
| **山岩／崖壁** | 大块剥落、断面粗糙、崩落的石头在山坡上滚出长痕 | 像豆腐一样整齐切开（除非是剑芒，剑芒可以） |
| **玉阶／仙宫地面** | 裂成规整的碎块，缝隙里透出底下的光，碎块边缘有金属般的断口 | 像水泥一样碎成粉 |
| **云／雾** | 被推开、被撕开、出现一个洞又慢慢合上，边缘翻卷 | 像固体一样被劈开且不闭合 |
| **水面（仙侠）** | 被抽起成柱／成鞭，落下时砸出深坑，水面先凹后炸 | 像玻璃一样裂开 |
| **冰** | 先白后裂，裂时发出连续的"咔"声，碎块里冻着东西 | 直接消失 |
| **护体灵光** | 凹陷 → 涟漪 → 出现裂纹 → 从裂纹处开始崩，碎片化成光点 | 一击即碎，或永不被破 |
| **结界／光墙** | 有厚度，受击处凹进去，能看见对面被折射变形 | 像一张纸 |
| **阵纹** | 被打断处烧黑、断口冒烟、断掉的那一段失去光泽，其他段还在运转 | 整座阵一起消失 |
| **法宝** | 缺口、裂纹、宝光暗一层、飞行轨迹开始发抖 | 直接碎成渣（除非剧情需要） |
| **修士身体** | 与常人相同，但伤口边缘有焦痕（法术所伤）或白霜（寒毒），血可以是热的 | 化成光点消失（除非是「道消」这种明确设定） |

**法术对撞的专属响应**：一声闷响 + 空气扭曲 + 尘环外扩 + 两种颜色的光互相啃。**不给法术对撞配金属火花**，那是兵器。

**同属性法术相撞**：两团同源之力黏在一起，越粘越大，然后一起熄掉，中间落下一片被抽空的静区（尘悬停、火熄灭、声音消失半秒）。

## 4. 空场几何（必查）

写击退、踢飞、撞落之前，先做一次几何检查。

```text
起点位置 → 飞行方向 → 飞行距离 → 落点 → 落点上有障碍吗
```

三种失败：

1. **起点即落点**：他在墙前，你写「倒飞撞上那面墙」。起点和落点重合，模型会把人钉在原地摆造型。
2. **落点无空场**：方向正对墙，但没写撞墙，人飞到墙里穿模。
3. **障碍位置错**：写「撞上身后的柱子」，柱子却在飞行路径侧面。

三种修法：

- 先把人打到开阔处（用一个位移波段），再给重击；
- 把障碍放到飞行路径**前方**，写明距离（「退出三米，撞在第二根柱子上」）；
- 改成横向滑退（「沿石板横滑两米，鞋底刮出白痕」），避开正后方的障碍。

**武侠特有的一条**：屋顶和竹林里的「空场」是假的——瓦会碎、竹会挡，写飞退时要说清是踩碎瓦滑出去，还是撞断两棵竹才停。

## 5. 残骸账本

破坏一旦发生，就必须记账，并在后续镜头里持续出现。

按时间顺序写：

```text
[3.0s] 左侧第二根柱子被撞断，断口朝外，上半截斜插在瓦砾里 —— 之后一直在。
[7.5s] 地面出现一道从门口延伸到院中的沟，深约一掌 —— 之后一直在。
[12.0s] 整片西侧屋檐塌落，露出后面的天光 —— 之后一直在。
```

交付时把这些写进 `DESTRUCTION AND ENVIRONMENT` 段落，用一句话锁住：

```text
左起第二根柱子自 3.0 秒后一直断裂；地面沟痕从门口延伸到院中；西侧屋檐自 12 秒后整体缺失，天光成为新的背景光源。
```

不许出现：断柱自己长好、沟痕消失、屋檐塌了下一镜又完整、碎瓦重新排列整齐。

## 6. 环境参战

环境不只是被打，还可以**参与打斗**。武侠的场景尤其如此——客栈、竹林、屋顶、渡口，本身就是战术。

| 用法 | 写法 | 注意 |
|---|---|---|
| **借力** | 蹬墙反冲、踩碎栏杆上跃、踏竹借弹力、把对手摔向柱子 | 蹬踏点要先有可见的承重反应（落灰、裂纹、竹弯） |
| **阻断** | 掀翻酒桌当掩体、踢倒屏风隔断、砍断灯笼绳制造烟幕 | 阻断物要停留足够时间，形成真实的空间变化 |
| **限制** | 窄廊限制长兵器、湿滑石板削弱脚步、屋内无法起轻功 | 限制对双方都成立，不能只坑一方 |
| **传导** | 掌力沿木柱传到横梁、脚震沿石板传开、水面传波 | 传导路径要可见 |
| **遮蔽** | 起尘、掀灰、破窗纸、雪雾 | 遮蔽 ≤1 秒，且必须保留运动轮廓 |

**环境不能只对一方有利。** 只让主角借环境、对手全程被环境坑，会让打斗失去对抗感。

## 7. 破坏与量级的对应

同一个世界里，破坏等级要能反推出人物量级。

| 人物量级 | 随手一击 | 认真一击 | 决胜一击 |
|---|---|---|---|
| **三流武人**（会点拳脚） | 1 级 | 2 级 | 2 级 |
| **二流好手**（走江湖的） | 1–2 级 | 2 级 | 3 级 |
| **一流高手**（一方成名） | 2 级 | 3 级 | 4 级 |
| **绝顶**（高武及以上） | 3 级 | 4 级 | 5 级 |

如果一个人随手一击就是 3 级，那么他的认真一击必须是 4 级，否则观众感觉不到「他认真了」。

**写实武侠档里，「绝顶」也只能到 3 级。** 这一档的强，靠的是**快、准、少犯错**，不是拆房子。

### 仙侠的境界与破坏对应

| 境界 | 随手一术 | 认真一术 | 决胜一术 |
|---|---|---|---|
| **炼气** | 1 级 | 2 级 | 2–3 级 |
| **筑基** | 2 级 | 3 级 | 3–4 级 |
| **金丹** | 3 级 | 4 级 | 5 级 |
| **元婴** | 4 级 | 5 级 | 6 级 |
| **化神以上** | 5 级 | 6 级 | 7 级（一次） |

**境界的差不是数值差，是「随手」与「认真」的差。** 金丹的随手一击等于筑基的决胜一击——这一条比任何台词都能说明代差。

**越级挑战的写法**：低境的一方只能靠 ①打断施法 ②贴到近身 ③破阵眼 ④借地形 ⑤用一次性的东西（符、丹、法宝自爆）。**不许写「他爆发了所以赢了」**——那是没有来源的力。

**境界高不等于打得好看。** 化神对化神如果只是两个光柱互推，还不如金丹对金丹的贴身斗法。**破坏是尺度，可读性才是戏。**

## 8. 收束

打完不能立刻停。收束的 1–2 秒要留给世界：

- 碎瓦还在从檐口滑落，尘土还在落，水面的圈还在扩；
- 断掉的灯笼还在晃，火苗在纸面上爬；
- 竹枝还在弹回，叶子还在往下飘；
- 胜利方喘息、手在抖、兵器垂下去；
- 失败方滑退到停下、想撑起身又倒下。

镜头在这 1–2 秒里持续后拉或横移，**不出现两人静止对峙的构图**——那会被拍成静态海报。

武侠还有一件别的东西：**收束时人可以做一个礼节动作**（收剑、抱拳、转身走），这是武侠独有的句号。

**仙侠的收束要多留一样东西：痕迹。**

- 阵纹烧在地上，边缘还在冒细烟，风一吹才慢慢暗下去（不是瞬间消失）。
- 剑芒扫过的地方，切面光滑，过了几秒才开始渗出水（石头的湿气被蒸出来了）。
- 雷击的坑还在冒热气，焦黑的边缘一圈灰白的灰。
- 法宝落地插在石缝里，还在震，光一点一点暗下去。
- 灵光的余烬像萤火一样往上飘，飘到半空才灭。

**仙侠最好的结尾不是「他赢了」，是「这片地方再也回不去了」。**

---

**一句话总结**：等级只增不减、方向服从受力、材质必须对、空场必须先查、残骸必须记账。
