# 轻功：让身体离地，但别让物理消失

轻功是武侠最容易被写坏的一项。写实的轻功不是「飞」，是**把地面的力借到更远的地方**：起跳有据、空中有限、落地有卸。删掉这三样，轻功就变成漫威式飞行，武侠味立刻消失。

## 一、五个锚点，缺一个就是浮空

每一次离地都要按这个顺序写全：

```
起跳面 → 方向与弧线 → 中继接触点（可无） → 落点 → 恢复姿态
```

| 锚点 | 必须写出 | 例子 |
|---|---|---|
| **起跳面** | 踩的是什么、有没有被踩坏 | 脚下一块松瓦先陷下去，才起 |
| **方向与弧线** | 往哪、什么弧度、多高 | 斜上三尺，弧度很低，几乎贴着瓦面掠过去 |
| **中继接触点** | 中途碰了什么（墙、檐、竹、肩、兵器） | 脚尖在檐角点了一下，方向由斜改直 |
| **落点** | 落在哪、落成什么样 | 落在对面屋脊，前脚掌着瓦，瓦响了一声 |
| **恢复姿态** | 落地后身体怎么接上动作 | 屈膝、下沉、随即起身出招，中间没有站直 |

**中继接触点可以没有**（一次长距离腾跃），但起跳面、落点、恢复姿态三样必须有。有中继点的，一定要写出「接触改变了什么」——方向、速度或高度，不能白踩一下。

## 二、滞空时间有上限

按 `wuxia-style-tiers.md` 的等级表执行，这里给出写法对照：

| 等级 | 滞空 | 空中能做什么 | 不能做什么 |
|---|---|---|---|
| 1~2 | 无 | 全程地面 | 任何离地动作 |
| 3~4 | ≈0.9 秒 | 跃起 → 提气停一口 → 空中打 1 下 → 落地 | 空中换方向、空中接第二招 |
| 5~6 | ≈1.3 秒 | 借墙换位、空中换招、落地卸力 | 连续三次变向、原地悬停 |
| 7 | 悬停 ≈3.6 米 | 升空压迫、空中交手、俯冲突进 | 无支撑长时间静止（要写气托） |
| 8~9 | 悬停 5~6.5 米 | 浮空战斗、抢高度、俯冲再拉起 | 完全无代价的自由飞行 |
| 10~11 | 长时间滞空 | 御剑飞行、凌空虚渡、边飞边打 | 找不到承载物（剑／云／气纹／阵） |
| 12 | 瞬移级位移 | 缩地成寸、瞬移改位 | 无残影、无落点痕迹、用来逃避打击 |

**0.9 秒能做什么，要按帧算**：约等于 22 帧。一次起跳 6 帧、一次出手 8 帧、一次落地 8 帧——刚刚好。所以等级 3~4 的人**在空中只能打一下**，写两下就是违规。

## 三、三种轻功，三种力

| 类型 | 力学 | 写法要点 | 常见错法 |
|---|---|---|---|
| **提纵**（向上） | 腿的压缩爆发，垂直 | 先屈膝、脚踝发力、落地时膝盖要吃住 | 直着腿起跳、悬在空中慢慢升 |
| **掠**（水平） | 贴地滑行 + 小步频，几乎不离地 | 脚尖点地两三下，身体前倾，衣摆拖成一条 | 写成平行飞行、脚不着地 |
| **踏物**（借力变向） | 借外部支点改向 | 踩墙、点檐、踏竹、蹬肩、踏兵器 | 踩空气、无支点凭空改向 |

**踏物是武侠味最浓的一种**，也是最能体现等级差：等级 6 的人踩着墙面横移，等级 3 的人只能追着影子转。写踏物时，**被踩的东西必须有反应**——墙皮落灰、竹枝弯下去再弹回、瓦片翻起、肩膀被踩得下沉半步。

## 四、踏水：一次变向，不是水上漂

- 默认规则：踏水只用于**一次猛烈变向**，脚尖点水、水花炸开、人已经换了方向。
- 长时间水上奔跑只有用户明确设定「水上漂」时才写，且必须写：每一步的水花、身体的倾斜、脚下的水面凹陷。
- 踏水后不许立刻再踏一次水，中间必须有别的支点或落地。

## 五、空中打斗的三条铁律

1. **起跳必须有据**：地面被踩碎、墙面落灰、竹枝弯折——都在起跳那一帧可见。
2. **空中只做一到两下**：一次攻击加一次防守调整，不能连打三招。高于等级 7 的浮空战斗另算，但也要写气托与代价。
3. **落地必须卸力**：屈膝、滑步、踩裂、扬尘、身体下沉——至少两样。空中狠狠砸下来然后笔直站住的，是最典型的假。

## 六、落地卸载的四种写法

| 方式 | 适用 | 画面 |
|---|---|---|
| **屈膝吸收** | 常规落地 | 膝盖弯到接近直角，衣摆先落、身体后停 |
| **滑步拖行** | 高速前冲 | 后脚犁出一道土痕，滑出两三步才停 |
| **踩碎缓冲** | 重落 | 落脚处的瓦／石板碎裂，碎片向四周弹 |
| **翻滚化解** | 高处坠落 | 肩先着地、顺势滚一圈、起身时手里兵器还在 |

落地后的**第一件事**决定了这段打斗的可信度：是立刻出招（说明他准备充分），还是先喘一口（说明他吃力）。两者都对，但必须选一个。

## 七、禁用写法

| 禁用 | 为什么 |
|---|---|
| 双脚一蹬，身体缓缓升起 | 无爆发，像电梯 |
| 在空中连续变换三次方向 | 违反动量，观众会出戏 |
| 悬停半空俯视对手，衣袍猎猎 | 无支撑、无代价，除非等级 7+ 并写了气托 |
| 轻轻落在地上，如一片羽毛 | 无重量，与「狠狠砸下来」同属失真 |
| 踩着空气借力 | 没有支点，等于飞行 |
| 起跳前不写脚下 | 观众不知道力从哪来 |

## 八、与镜头的配合

- **起跳用低机位**：仰拍能同时给出起跳面与高度差。
- **滞空用跟随**：镜头跟着人升，但要慢半拍，让人「冲」出画面一点。
- **落地用落幅**：镜头随人下压，落地那一刻机身一震。
- **长距离腾跃用全景**：一定要能看到起跳面和落点，两个都不在画面里就变成了凭空出现。
- **不要让镜头比人先到**：观众要先看见人从哪来。

## 九、仙侠的御空：把「起跳面」换成「承载物」

仙侠不需要蹬地，但**不能凭空站着**。轻功五锚点在仙侠线改写成：

```text
承载物 → 方向与弧线 → 中继（换气／换剑／借阵） → 落点 → 恢复姿态
```

| 承载物 | 写法 | 失效的样子 |
|---|---|---|
| **御剑** | 剑在脚下放大到一尺宽，剑身与脚之间有薄薄一层光，人被托在剑脊上 | 人站在一把正常大小的剑上（物理不成立） |
| **云头** | 脚下聚一团云，云边翻卷，升高时云在下面流 | 云像棉花糖一样硬 |
| **凌空虚渡** | 每一步落下都有一圈气纹散开，像踩在水面，脚步有节奏 | 无气纹、无节奏地滑行 |
| **借阵** | 阵纹亮起，人被从阵眼处托上去 | 阵没亮人就飞了 |

**御空的三条纪律**：

1. **加速与转向要有气纹**：衣袍被压向反方向，脚下光纹被踩散。
2. **悬停要写「维持」**：手不松、剑在轻微发抖、额角见汗。长时间悬停是有消耗的。
3. **落地必须卸势**：仙侠的高级写法是「膝盖不弯，脚下地面先裂一圈」——力被导进地里，不是被身体吸收。

**瞬移（等级 12）只用来改位置，不能用来躲。** 写瞬移必须交代三样：起点的残影、落点的痕迹（尘／裂纹／焦痕）、以及「他为什么不早用」（真元不够／被锁灵压住／术有冷却）。三样缺一样，观众就会问「那他刚才为什么不瞬移」。

**被锁灵阵压住的修士可以直接掉下来**——这是仙侠最好的「空中被打断」：飞行中的剑忽然熄光，人开始往下坠。

---

**一句话总结**：轻功 = 借力，不是飞行；仙侠的御空 = 换一个借力的对象，不是取消借力。写完自查五锚点（仙侠是承载物）齐不齐、滞空有没有超等级、落地卸了没有。
