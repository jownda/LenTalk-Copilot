# 法术原词库（FA-01 ~ FA-86）

和招式库（ACT）、内力库（QI）同级的一套可追溯词汇：ACT 管**身体怎么动**，QI 管**内劲怎么出去**，FA 管**仙侠的术怎么成形、怎么飞、怎么落地**。

**只在仙侠线使用。** 武侠线（写实武侠／高武）不取本库——高武的劲走 QI 库。

## 取词路由

1. 先按 `xianxia-lane.md` 定境。炼气只配取一、二族的小术；金丹以上才配剑芒与五行全开。
2. 定类型：直击（二、三、一族部分）／场域（五族）／改变（七族）——三类物理不同，别混。
3. 一次施法**最多两个 FA 词**：一个起诀或引灵，一个主术。三段连着取会糊成一团光。
4. 取完必须补：载体（剑／符／印／掌／阵眼）、前摇（手／物／天）、代价（真元／精血／法器）。
5. 词只是索引，成品写成可见画面，编号不进提示词。

## 附：三库叠用规则

| 组合 | 允许 | 写法 |
|---|---|---|
| ACT + FA | ✅ 最常用 | 身体动作给走线与接触点，FA 给术的形态；身体仍要有四段发力 |
| QI + FA | ⚠️ 少用 | 只在「内力灌入法术」时用，写清哪一段是内力、哪一段是真元 |
| ACT + QI + FA | ❌ 一条动作段里不超过两个库 | 三个一起取会让一格塞进三个动作，模型会糊 |

**仙侠线的默认组合是 ACT + FA。** 身体负责「他怎么站、怎么退、怎么挡」，法术负责「出去的是什么」。没有 ACT 的仙侠就是光在飞。
