# 武侠美学：留白、气韵、江湖

动作对了，武侠还可能不像武侠——因为它缺的不是招式，是**气质**。这一份管的是「像不像武侠片」，不是「打得对不对」。

## 一、留白：不是每一拍都要有事发生

武侠与超能最大的审美差异在这里。超能片靠密度堆爽感，武侠靠**收放**：

- 两人对峙三秒不动，只听见风、烛火、远处的脚步声——这三秒比三招更贵。
- 交手中间插一次呼吸：肩落下去、手指松一下、眼神从刃上移到对方眼睛。
- 打完不要立刻接下一段。留一个镜头：衣角还在摆，雪还在落，人没动。

**留白长度**：短打 0.5~1 秒，决斗类对峙可到 2~3 秒。整段里留白总量控制在 15% 以内，超了就变成慢。

留白时**必须有一个仍在动的细节**（衣摆、烛焰、呼吸、飘落的雪），否则画面会死。

## 二、气韵：让空气参与

武侠的画面里，**空气是有重量的**。次级运动是气韵的主要来源：

| 元素 | 写法 |
|---|---|
| 衣袂 | 出手前先鼓、出手后拖、落地时压下再扬 |
| 发丝 | 快动作时贴脸，急停时甩到前面，静止时一根在飘 |
| 雪／雨 | 随气劲改变方向，但不夸张成漩涡；落在刃上会化 |
| 雾／尘 | 被身体挤开再合拢，有延迟 |
| 烛火／灯笼 | 被掌风压偏，恢复时晃两下 |
| 水面 | 只在接触点起涟漪，波纹向外递减 |

**次级运动要有延迟**：人已经停了，衣摆还在走 0.2 秒。这一下就让画面从「摆拍」变成「有惯性」。

## 三、招式名、门派、辈分

| 情形 | 做法 |
|---|---|
| 用户给了招式名（降龙十八掌、独孤九剑） | 直接用，并按名字可推断的动作特征写（掌法=面状推力；剑法=线状切割） |
| 用户没给 | **不自己编门派和招式名**。用动作本名（直刺、横斩、沉桥、贴身靠） |
| 用户给了门派 | 用**可见差异**表达，不用旁白介绍：起手式、步法、兵器握法、行礼方式 |
| 需要体现辈分／身份 | 用礼节动作（抱拳、让招、先收兵器）、站位（长辈居中、晚辈侧立） |

**不写门派是有原因的**：一旦写出「武当剑法第三式」，模型会开始编造不存在的招式，动作反而变空。门派要靠**身体习惯**透露，不靠名字。

如果用户坚持要门派，就把它转译成三个可见参数：**起手姿态、发力习惯、收招方式**。

**仙侠线同理，换成三个参数**：结印的手法（双手／单指／剑指）、术的媒质（剑／符／阵／印）、代价的痕迹（血／白鬓／法器裂纹）。道统名（剑修、符修、阵修）同样不进成品，只用来选词。见 `xianxia-aesthetic.md`。

**仙侠美学另有一整套规则**（慢远静、一个冷底一处破色、仙侠的规矩与句号），本文件只覆盖武侠线的质感。仙侠线请改用 `xianxia-aesthetic.md`。

## 四、江湖规矩：动作的动机来源

武侠的打斗很少是「为了打赢」，多半是「为了某个规矩」。这一层能让动作有分寸：

- **留手**：明明能杀却收力半分——收力这个动作本身要可见。
- **点到为止**：兵器停在距咽喉一寸处不动。
- **不背后下手**：对手转身时停住，等他转回来。
- **辈分让招**：长辈先让对方三招，第三招后才还手。
- **护人**：为了挡在某人前面而放弃进攻机会。

这些不是道德说教，是**节奏工具**：它们天然制造停顿、让招、收势，正好是武侠需要的呼吸点。

## 五、环境即对手

武侠的空间不是背景，是参与者。每个场景给 1~2 个可用的战术元素，不要全用：

| 场景 | 可用元素 | 战术价值 |
|---|---|---|
| 客栈 | 长凳、酒坛、楼梯、横梁、二层栏杆 | 高低差、可投掷物、窄通道 |
| 竹林 | 竹竿弹性、落叶、视线遮挡 | 借力变向、藏身、声音误导 |
| 雪原 | 松软地面、雪坡、能见度 | 脚印暴露位置、滑步、雪墙 |
| 屋顶 | 瓦片松动、屋脊、檐角 | 落脚不稳、借力点、坠落风险 |
| 渡口／水边 | 湿滑石板、船板晃动、水面 | 打滑、失衡、踏水变向 |
| 寺庙／道观 | 香炉、经幡、石阶、铜钟 | 障碍、声效、庄严感反衬暴力 |

**地形响应要克俭**：每条镜头最多两处环境互动，用满就变成杂技。

## 六、声音：武侠的一半是听的

### 拟声与音效

用短、干、硬的现场声，不要「轰鸣」：

```
WHOOSH（挥空） / CLANG（刃碰） / TANG（轻兵器脆响） / THUD（重击闷响）
BLADE SCRAPE（刃刮） / TILE CRACK（瓦裂） / CLOTH RIP（衣破）
HEAVY BREATH（喘息） / WATER IMPACT（落水） / CHAIN SNAP（链绷）
```

- 高速动作的声音短（0.1~0.2 秒），尾音不收。
- 留白段只留环境声：风、虫、远处狗吠、烛芯爆响。
- 声音要**跟着接触点走**，不能提前，也不能滞后太多。

### 喊招铁律

如果用户要「喊招」（港式武侠常见）：

- **出招那一瞬爆喝**，短促有力，绝不拖长音，绝不慢半拍。
- 前期只用「喝」「哈」「嘿」这类气声，不报名号。
- 只有在**关键招式**或**终局**才喊完整招式名。
- 喊招与动作同步，不是先喊后打。

### 无 BGM 的选项

武侠打斗可以全程无配乐，只留同期声。这在高武以下档位通常更高级——音乐会替观众判断「这里很燃」，而留白让观众自己判断。

## 七、笼统词黑名单

以下词一律不许出现在成品里，必须换成可见画面：

| 黑名单 | 换成 |
|---|---|
| 剑光如虹 | 一线白光切过，三根竹子先后错位 |
| 招招致命 | 每一招都指向要害：咽喉、心口、持械手腕 |
| 气吞山河 | 掌风压过草坡，草成片伏下再慢慢立起 |
| 快如闪电 | 0.4 秒内从三丈外到贴身，中间有一次踏地变向 |
| 内力深厚 | 一掌之后石阶裂开一道，他退半步换气 |
| 招式精妙 | 连消带打三下：拍挡、沉桥、贴身靠 |
| 杀气腾腾 | 兵器先动半寸，然后人动 |
| 惊天地泣鬼神 | （删掉，写具体破坏） |

## 八、三种美学坐标（供选择，不是模板）

用户没指定风格时，可以从这三条里选一条最接近的作为默认倾向：

| 坐标 | 特征 | 适合 |
|---|---|---|
| **港式凌厉**（90 年代） | 密度高、节奏快、喊招、先到后爆、抽帧打击停顿 | 江湖仇杀、门派冲突、热闹 |
| **写实克制**（徐浩峰一路） | 招式极少、每一下都有交代、声音真实、不飞 | 硬派武侠、年代戏、兵器对决 |
| **写意飘逸**（卧虎藏龙一路） | 轻功多、留白多、环境参与强、动作如舞 | 意境向、爱情线、山水 |

选定后**整场保持一致**，不要第一段港式、第三段写实。混搭会让观众觉得风格在漂。

---

**一句话总结**：动作负责「打得对」，这一份负责「像武侠」。留白给呼吸，气韵给空气，规矩给动机，声音给质感。
