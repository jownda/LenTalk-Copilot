# 中式兵器：剑走线、刀走面、枪走点、奇门走变

武侠的兵器不是「拿把刀砍人」，每一类都有自己的**力学性格**。把刀当剑使（走直线刺）、把枪当棍抡，观众说不出哪里错，但会觉得「不像练过的」。

## 一、四类兵器

| 类 | 一句话性格 | 长度／距离 | 主要作用线 | 弱点 |
|---|---|---|---|---|
| **剑**（双刃直身） | 轻灵，走**线** | 0.6~1.0m／一臂半 | 点、刺、抹、削、挑、缠 | 格挡能力弱，硬碰会崩刃；不擅长劈 |
| **刀**（单刃弯身） | 刚猛，走**面** | 0.6~0.9m／一臂 | 劈、砍、撩、扫、推、按 | 大幅挥砍后有明显回收期，落空就漏 |
| **枪／棍**（长杆） | 控距，走**点**（枪尖）或**片**（棍身） | 1.8~2.6m／两至三个身位 | 扎、刺、点、扫、圈、压、拨 | 被贴身就废；收回慢 |
| **奇门**（双持／链索／暗器） | 走**变** | 视种类／近到中 | 双持交错、链索缠拉、暗器点杀 | 依赖持有关系与环境，断了就没 |

## 二、每类的写法要点

**剑**——要写出「线」的存在感：

- 剑尖始终是一条指向；变线靠手腕与肩，不靠大幅抡臂。
- 交剑是**刃身相压争中线**，不是两根铁棍对砸。
- 刺要写剑尖、削要写刃口中段、劈要用前端三分之一（虽然剑不擅长劈）、格挡要用剑脊或剑身平面。
- 剑的胜负来自**时机与线路**，不来自力量。

**刀**——要写出「面」的压迫与回收期：

- 劈砍是一条弧，起点在肩后，落点在目标后方——写完整弧，不要只写「一刀砍下」。
- 刀落空会有 0.5~1 秒的回收期，这段时间是他的破绽，必须被对手利用或至少被看见。
- 刀可以硬碰，但硬碰之后刀刃会缺口，缺口要留到后面。
- 单刃意味着有一侧是薄的：刃背可用于格挡，但挡多了会弯。

**枪／棍**——要写出「距离暴政」：

- 枪扎一条线：出手极快、回收极快，一扎不中就再扎，不做大动作。
- 棍打一片：扫要写弧，压要写两端，戳要写棍尾。
- 长兵器的核心是**不让对手进内圈**；一旦被贴身，长兵器只剩推、压、抵、弃四种用法。
- 长兵器转身慢，被绕到侧后就是死。

**奇门**——要写出「持有关系」：

- 双持必须分别写左手和右手，两把不能同步做同一个动作，否则看起来像一把。
- 链索要写：起点在哪、缠住什么、松紧状态、哪只手控、怎么收回。
- 暗器要算数量：几枚、已用几枚、还有几枚、落点在哪。**飞刀不许自己飞回来。**

## 三、兵器相碰只有三种结果

| 结果 | 动作 | 后续 |
|---|---|---|
| **格**（挡停） | 硬接，两刃相交 | 双方手臂一震，位置不动但都在找下一个角度 |
| **绞**（绕压） | 顺着对方力缠绕、压住中线 | 压住的一方下一拍直接刺或劈；被压的要抽刃或换线 |
| **崩**（弹开） | 斜向发力把对方兵器震偏 | 兵器偏离，出现空门，谁先回位谁得手 |

**「兵器不断碰撞」是无信息量的写法。** 每一次碰撞必须产生以上三种之一，并且改变态势。

## 四、金铁交鸣：声音与火花要短、要准

- 声音短促、干、硬：`CLANG`、`BLADE SCRAPE`、`TANG`、`THUD`。不要「轰鸣」。
- 火花只在**刃与刃接触点**出现，最多十几粒，向外迸 0.2 秒即灭。
- 火花方向服从碰撞角度，不是四面均匀散开。
- 重兵器相撞是闷响（`THUD`），轻兵器相碰是脆响（`TANG`），音色不能混。

## 五、兵器账本：五件事全程不许含糊

出场前先定死，之后每一拍都继承：

1. **谁握着**（明确到人，不许「一把刀在两人间飞舞」）。
2. **哪只手**（换手必须有动作过程）。
3. **刃／尖朝向**（每一拍都要能看见朝向）。
4. **状态**（完整／缺口／弯曲／断裂／脱手／卡住）。
5. **位置**（在手上、在地上、插在梁上、被踢开）。

**换手、拾械、弃械、飞掷、出鞘、收鞘**——这六个状态转换必须写出过程，不许下一拍无解释地完成。武器不许复制、变形、无故回到手里。

## 六、长短之争：「一秒生死」

长兵器对短兵器（或空手），不要写成势均力敌的长时间拆招。用一条决定性因果链：

```
长兵器在外圈承诺一次大幅攻击 → 短兵器方承受擦伤或刚好避开一条线
→ 身体切入对方两肘以内 → 长兵器尚未收回时完成一次紧凑决定性攻击
→ 双方错身，或倒入动作后果
```

要点：

- **胜负来自距离与时机**，不是「谁内力强」。
- 慢动作只放在最后的决策空隙，故事时间最好不超过半秒；接触发生立刻回到全速。
- 败方的兵器必须停在**已承诺、无法回收**的位置上——这是胜负的证据。
- 短兵器贴身时不做大幅展示性弧线，用紧凑的直线（捅、抹、顶）解决。

反过来，长兵器要赢，就必须写出**距离控制**：用长度把对手逼在外圈，一扎一收，不给贴身机会。长兵器被贴身之后还挥得开，是最常见的硬伤。

## 七、空手对兵器的三种合理写法

| 写法 | 前提 | 关键动作 |
|---|---|---|
| **切入控臂** | 对方刚出招未收 | 掩手切入、压住持械前臂、控腕，不碰刃 |
| **夺械** | 已压住前臂 | 夺刃控腕、勾械卸械——**先控臂再夺**，不能伸手抓刃 |
| **脱离／抄器物** | 实力差距大 | 后撤、绕柱、抄板凳石块，承认兵器优势 |

**空手方正面格挡刀刃是不合物理的**，除非有明确的内力护体，且护体要写代价。

## 八、禁忌清单

| 禁忌 | 说明 |
|---|---|
| 刀走直线刺 | 刀不适合刺，除非明确写「以刀尖点」 |
| 剑大幅劈砍 | 剑劈会崩，除非写清代价 |
| 长兵器被贴身仍挥大弧 | 空间不够，会穿模 |
| 一人同时应付三把刀仍占上风 | 除非等级差距悬殊且有可见依据 |
| 兵器长度随镜头变化 | 必须有固定几何 |
| 断刃仍能干净直刺 | 断口无尖就只能拉割、推切、卡压 |
| 缺口的刀下一镜变完整 | 状态必须累积 |
| 暗器数量超支 | 要算清楚 |

---

**一句话总结**：先问「这是什么兵器、多长、走什么线」，再写动作。兵器是力学，不是道具。
