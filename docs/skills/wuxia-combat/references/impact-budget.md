# 冲击预算：打击感怎么花

打击感是**有限资源**。慢放、定格、震屏、白闪用滥了，每一次都会变轻；用得省，一次就够观众记住。本文件规定谁可以用、用几次、怎么用。

## 1. 三件套先于一切

任何一次命中，先检查这三件事是否成立；三件不成立，加多少特效都是空的。

| 件 | 时长 | 写法 | 不成立的表现 |
|---|---|---|---|
| **接触帧可读** | 2–3 帧 | 接触点、受力方向、被击部位同框，接触点本身清楚 | 只看到一团光／一片尘，看不到打到哪 |
| **后果持续** | 0.3–0.5 秒 | 位移、形变、失衡、衣料受压、脚下犁痕、身后凹陷 | 打完立刻恢复原状，像没事发生 |
| **反作用** | 同帧或下一格 | 攻击者退半步、手腕发麻、兵器反弹、脚下先碎 | 攻击者像站在滑轨上 |

**第三条是武侠的分水岭**。发劲的人自己也要被自己的力顶回来——退半步、后脚蹭地、肩膀沉一下。只有被打的人在动、打的人纹丝不动，看起来就是两个人贴图对撞。

## 2. 片型与配额

先判片型，再决定能用多少花活：

| 片型 | 定格／抽帧 | 升格 | 全屏光效 | 甩镜 | 破坏上限 |
|---|---|---|---|---|---|
| **写实武侠**（港式凌厉） | 抽帧 2–3 帧，≤3 次/15s | 不用 | 无 | ≤2 次/15s | 3 级 |
| **高武** | 抽帧 ≤4 次/15s | ≤1 次/全片，只给决胜 | ≤0.5 秒/次 | ≤2 次/15s | 5 级 |
| **写意飘逸** | 不用抽帧 | ≤2 次/全片 | 无 | ≤1 次/15s | 3 级 |
| **仙侠** | 抽帧 ≤4 次/15s | ≤1 次/全片 | ≤1 秒/次，≤2 次/15s | ≤2 次/15s | 6 级 |
| **仙侠大片** | 抽帧 ≤3 次/15s | ≤2 次/全片 | ≤1.5 秒/次，≤2 次/15s | ≤3 次/15s | 7 级 |

判断线索：

- 「收着打」「写实」「不要特效」「徐浩峰那种」→ 写实武侠。
- 「港片那种」「90 年代」「凌厉」「拳拳到肉」→ 写实武侠 + 抽帧。
- 「内力」「气劲」「掌风」→ 高武。
- 「飘逸」「意境」「像舞一样」→ 写意飘逸。
- 「灵力」「法术」「符」「御剑」「法阵」→ 仙侠。
- 「法相」「天地变色」「大场面」「渡劫」→ 仙侠大片。

**用户没有明说时，默认「写实武侠」**。这一档不靠特效，靠接触、后果与抽帧，也最不容易翻车。

## 3. 抽帧：90 年代港式的招牌

`hit-stop` 在武侠里通常做成**抽帧**：命中瞬间抽掉 2–3 帧，画面出现一次极短的跳格，然后爆回全速。

```text
掌根压上胸口的瞬间抽掉两帧，画面跳了一下；下一格他已经退出去，
衣料还保持着被压陷的形状。
```

要点：

- 抽帧长度 **2–3 帧**（约 0.08–0.12 秒）。超过 5 帧就变成定格造型。
- 抽帧只给**重击**，普通连击不用——连击里用抽帧会把节奏打碎。
- 抽帧期间**必须有一个细节还在动**（一缕发、一片落叶、衣角），否则画面会死。
- 抽帧前后速度差要明显：抽帧前极快，抽帧后同样极快，中间那一下顿才显出来。

## 4. 升格（慢放）的正确用法

升格是全片最贵的资源，用错一次就毁掉整场节奏。

**正确写法**：

```text
剑尖抵到咽喉前三寸的瞬间慢放半秒，喉结动了一下，一线血珠沿着剑脊滑下去；
半秒后立刻恢复实时，剑已被收回鞘中，人还站着。
```

拆开看：

1. 慢放只覆盖**接触／临界那一瞬**，约 0.3–0.5 秒屏内时间。
2. 慢放段只承载**形变与细节**（皮肤凹陷、血珠、布料折叠、尘粒悬停）。
3. **位移全部回实时**：飞退、犁地、撞物、落地，一个都不许在慢放里演。
4. 慢放前一镜必须交代退路有空场。

**错误写法**（会拍成 PPT）：

```text
✗ 时间几乎静止，他缓缓向后飞出，穿过墙壁，慢慢落地，全过程慢放。
```

问题：慢放承载了位移全过程，模型会把整段反馈拍成持续数秒的定格造型，「打」变成「飘」。

**武侠特有用法**：慢放放在**决策空隙**而不是命中瞬间——两人错身那一刹那、兵器将触未触的那一瞬。故事时间最好不超过半秒，接触一发生立刻回全速。

## 5. 全屏光效的红线（只对高武以上）

- 单次 ≤0.5 秒（仙侠可到 1 秒，仙侠大片 1.5 秒），句内写死时长与收束方式：「爆光 0.5 秒后迅速收束，只剩接触点一圈残弧」。
- 光爆中**两人轮廓与接触点必须可读**。做不到就缩范围，别糊掉整帧。
- 不设「铺满画面 1.5–2 秒」的例外。要大场面靠碎片、尘、镜头运动，不靠长亮。
- 气劲与灵光都不许染色天空或改变环境底色。
- **仙侠专属**：一次大术的光爆只允许出现在「释放」这一段，不许从引灵一路亮到收势。引灵与凝形的光是小的、局部的、可在人身上的。

## 5b. 法术自身的节奏（仙侠）

法术不是「一个特效」，是一段**有内部节奏的表演**。好的法术自带冲击：

```text
静（0.3–0.5s，环境音抽掉，只留呼吸） → 起诀（手） → 引灵（低鸣，光渐起）
→ 凝形（最亮的 1–2 帧） → 释放（一声炸，光爆 ≤1s） → 生效（破坏、尘、lag 0.2s） → 收势（余烬、喘息）
```

三个可用的强调点，按需取一到两个：

| 强调点 | 手法 | 用在哪 |
|---|---|---|
| **凝形那一瞬** | 抽帧 2–3 帧，法术在手里停住，光最亮但范围最小 | 大术起手，观众看到「成形了」 |
| **释放那一瞬** | 甩镜 + 短震 + 一声爆 | 决胜一击 |
| **生效那一瞬** | 升格 0.3–0.5 秒，只覆盖破坏的形变，不覆盖位移 | 全片一次，给最重要的那一击 |

**禁止**：把抽帧、升格、光爆三个全堆在同一个法术上。三个一起用，这一下就没有层次了，而且配额一次烧完。

## 6. 打击感的六个替代手段

当配额用完、或者片型不许用慢放时，用这些手段制造冲击：

1. **速度突变**：极快 → 骤停 → 极快。节奏差本身就是冲击，成本为零。
2. **镜头急推 + 受控短震**：接触瞬间推近 20–30 厘米，机身抖 2–3 帧，方向沿受力方向。
3. **先到后动**：脚落地 0.1 秒后才见尘土扬起；掌贴上胸口之后衣料才贴陷。这一下延迟让力显得有质量。
4. **环境滞后反馈**：烛火被压偏再立起、竹枝弯下去再弹回、水面波纹向外递减。
5. **声音先行**：破风声在画面前 0.1 秒到达，接触声与接触同帧。
6. **衣料与发丝**：人停了，衣摆还在走 0.2 秒。最便宜的「有惯性」。

这六个可以叠加，且不占慢放配额。

## 7. 打击层级

同一场里，不同量级的攻击要拉开差距，否则全片一个力度。

| 层级 | 铺垫 | 表现 | 环境 | 用途 |
|---|---|---|---|---|
| **普通击** | 无 | 无特效 | 微动（尘、衣料） | 铺垫、试探、连击填充 |
| **有效击** | 半拍 | 短促速度突变 | 表面伤（衣破、皮开、瓦碎） | 转折、打断 |
| **重击** | 一拍可见前摇 | 抽帧 2–3 帧 + 短震 | 局部断裂（木裂、石阶裂） | 中段改位置 |
| **决胜** | 长蓄势 + 一次换气 | 升格 ≤1 次 或 抽帧 + 甩镜 | 结构塌陷（梁断、墙塌） | 结尾一次 |

**全片只允许一次决胜层级。** 出现第二次，第一次就不值钱了。

## 8. 声音与冲击的先后

顺序固定，不可颠倒：

```text
破风声 → 接触声（材质声 + 低频） → 余振 → 环境余响（碎屑落地、瓦片继续滑）
```

- **命中先于震屏、音效和破坏。** 反了就是「先炸后打」。
- 兵器接触是金属声（`CLANG`／`TANG`），肉体接触是闷响（`THUD`），内力接触是「闷响 + 一声短促的气流」——三者不能混。
- 不给每一击都配音效。连击段只保留关键三击，中间用破风声带过。
- 喊招（如用户要求）与出招**同帧**，不许先喊后打，也不许拖长音。

## 9. 打击感的节奏骨架

一段 15 秒的打斗，冲击不应该均匀分布：

```
0–2s     试探（轻，无特效，只有脚步与呼吸）
2–5s     第一次有效击（对方先占优 → 观众以为要输）
5–9s     压制（连续三下，每下都比上一重，但都没有决胜）
9–12s    反转（一次重击改位置，抽帧）
12–15s   决胜（升格半秒 或 一次干净利落的一击）
```

这是最不容易塌的分布。**均匀分布 = 没有高潮**；前 12 秒就把所有牌打完 = 结尾空掉。

---

**一句话总结**：三件套不成立，一切特效都是空的；配额按片型给；抽帧给重击、升格给决策空隙、决胜全片只有一次。
