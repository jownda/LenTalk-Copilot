# 交付检查（74 条）

生成前实际读取主文件、招式库、内力库或法术库、运镜库和中文写法。检查失败只修对应问题，不凭感觉宣称已经执行 Skill。

## 一、分线与档位（最先查）

1. **线别是否定死**？武侠线里有没有偷偷冒出的法术、符箓、法阵、法宝？
2. **档位是否定死**？写实武侠／高武／仙侠／仙侠大片各是什么量级，全场是否一致？
3. 有没有**中途升档**？开场贴身短打，三拍后一掌轰出十米气浪。
4. 有没有**中途降档**？前段炸了半座楼，后段又变成纯写实。
5. **机动等级**是否与档位匹配？写实武侠里有人飞起来了吗？
6. 空中的每一个动作，是否找得到起跳面、中继接触点，或仙侠的承载物？（`air-unsupported`）
7. 破坏量级是否与术或气劲的尺度匹配？气劲一米宽却炸掉半座楼属于越级。

## 二、时序与来源

8. 打斗是否逐 0.5s 列格，连续、无空缺/重叠且总长正确？15s 纯打斗必须 30 格。
9. 剧情/对白是否每 2–3s 一块，混合内容分别按类型规划？
10. 每个攻击/防守动作是否引用招式库 ID 与原词？每个内力或法术动作是否引用对应库 ID？每镜景别、运镜是否引用运镜库 ID？
11. 去掉名称之后是否仍能辨认动作？不能只堆术语或自造运镜名。
12. 成品是否移除了内部 ID、文件路径与检查标记？

## 三、三条底线（最高优先级）

13. **力有来源**：武侠线是否写出支点／推进／蓄势／代价中的至少两样？仙侠线是否点名真元／法宝／阵法／地脉／他人借力之一？
14. **先接触后反应**：命中是否先于火星、闪光、震屏、音效、破坏？有没有「光一亮，远处同时炸开」？
15. **破坏只增不减**：已碎的瓦是否在后续镜头里保持碎？断口、裂纹、沟痕、阵纹烧痕是否持续到结尾？

## 四、发力与打击感

16. 每次重击是否能找出「脚蹬地 → 髋转 → 肩送 → 末端」四段中的三段？
17. 每次命中是否具备三件套：接触帧可读（2–3 帧）+ 后果持续（0.3–0.5 秒）+ **攻击者反作用**？
18. 是否只有被打的人在动、打的人一动不动？有则补反作用（退半步、后脚蹭地、兵器反弹、法术后手抖）。
19. 击退前是否做过空场检查（起点、方向、距离、落点、障碍）？起点与落点是否重合？
20. 位移尺度是否由小到大递进？有没有第一击就退三丈？
21. **写实武侠档有没有出现「飞出去」**？这一档只能退、滑、倒。

## 五、内力（武侠线）

22. 四段是否齐全：起势（重心）→ 行气（路径）→ 落点（接触）→ 余劲（消散）？
23. 气劲形态是否与招式匹配？推掌出掌风、指劲出剑气、抱圆出气环。有没有掌法出剑气？
24. 气劲是否**离体不染色**？有没有覆盖衣料本色、把脸染成一片青？
25. 介质是否先动？有没有抬手即命中？
26. 是否写了「先到后动」？力到了，环境反应晚 0.1–0.3 秒才起。
27. 一场是否只有一套对立色？有没有每个招式换一种颜色？
28. 气劲是否只在**发力瞬间**可见？有没有掌心一直发着光？
29. 全屏光效是否写了时长（高武 ≤0.5 秒）与收束方式？光爆中轮廓与接触点是否可读？
30. 每次外放是否**还了代价**？喘息、手抖、虎口震裂、幅度变小、额头见汗，至少一样。
31. 力竭是否是**累积**的？有没有打完五掌跟没事人一样？

## 六、轻功与御空

32. 五锚点是否齐全：起跳面（仙侠为承载物）→ 方向与弧线 → 中继接触点（可无）→ 落点 → 恢复姿态？
33. 滞空是否超出对应等级？等级 3~4 约 0.9 秒，只能在空中打一下。
34. 有没有**无因浮空**？双脚一蹬缓缓升起、悬停俯视、踩空气借力、无承载物站立。
35. 被踩的东西是否有反应？墙落灰、竹弯再弹、瓦翻起、肩沉半寸。
36. 落地是否卸力？屈膝、滑步、踩碎、翻滚，至少两样。有没有狠狠砸下来然后笔直站住的？
37. 踏水是否只用于一次猛烈变向？有没有变成水上漂？

## 七、兵器

38. 兵器类型与动作是否匹配？有没有刀走直线刺、剑大幅劈砍、长兵器被贴身仍挥大弧？
39. 每一拍是否写出了**兵器的部位**（剑尖／刃口中段／棍端／棍尾）？
40. 兵器账本五项是否成立：谁握、哪只手、刃／尖朝向、状态（缺口／弯曲／断裂／脱手）、位置？
41. 换手、拾械、弃械、飞掷、出鞘、收鞘，这六个状态转换是否都写了过程？
42. 兵器是否**复制、变形、无故回到手里**？断刃是否还能干净直刺？
43. 每一次兵器相碰是否产生「格／绞／崩」之一，并改变态势？有没有无信息量的连续碰撞？
44. 火花是否只在接触点、短促、方向服从碰撞角度？重兵器是否用了闷响、轻兵器是否用了脆响？
45. 长短之争是否由距离与时机决定？败方的兵器是否停在「已承诺、无法回收」的位置？

## 八、仙侠：法术与代价

46. **法术六段是否齐全**：起诀 → 引灵 → 凝形 → 释放 → 生效 → 收势？有没有压成「抬手—白光—爆炸」？
47. **每一处术效拍点是否按逐拍公式写全八段**：镜头机位 + 人物 + 锚点 + 技能 + 粒子 + 光效 + 撞击位置 + 物理反馈？缺哪段补哪段，粒子是否写了「生成—行为—消散」？
48. **前摇是否写了至少两种载体**（手／物／天）？观众能不能提前看出他要放大招？
49. 引灵是否有来源（四周空气、地面、符纸、剑身、天上）？还是凭空出现？
50. 凝形是否有**具体形状、大小、颜色**？还是只有「强大的力量汇聚」？
51. **有没有一次施法被打断，或差一点被打断**？打断是否发生在凝形之前？
52. 每次大术是否**还了代价**？真元、精血、寿元、法器、经脉，至少一样。
53. 代价是否**累积**？第三次施法是否比第一次更小、更慢、更抖？
54. 施法类型物理是否正确？直击类有飞行时间、场域类先地后罩、改变类有持续消耗。
55. 五行相遇是否写成**抵消方式**（白汽／泥流／熔滴／断口／根裂），而不是「谁更强」？
56. 雷法的声音是否**晚于闪光**（0.2–0.5 秒）？同时响的雷是假的。

## 九、仙侠：符箓、法宝、法阵、光

57. **符数是否记账**？说三张就是三张，有没有用完了又掏出来？「取符」的动作是否可见？
58. 符的失败是否写了（受潮／撕破／真元不足）？最后一张是否留到关键时刻，或明确写「摸到袖底是空的」？
59. **法宝三属性是否成立**（祭炼几成／灵性／损耗）？每用一次是否留下更深的损耗？
60. 御剑四段是否齐全（出鞘／悬停／飞行／归鞘或被击落）？剑光是否走弧线、有长度？
61. 法宝对轰是否写成**属性压制 + 消耗竞赛**？有没有写「谁的宝光先暗」？有没有变成两个光球比大小？
62. **丹药是否有完整动作**（倒出／入口／喉结／药力上来的脸色）？有没有「吞了颗丹药就好了」？
63. **法阵三要素是否齐全**（阵图／阵眼／阵旗）？阵眼是否可见、可攻击？
64. **布阵四段是否写了**（落旗／连线／合拢／启动）？有没有敌人站着看他布完阵？是否有人掩护或在挨打中完成？
65. **阵内规则是否有可见症状**（脚步变慢／符纸点不着／皮肤浮红线／剑芒缩短）？有没有只写「受到压制」？
66. **灵光是否有载体**（剑／符／印／阵纹／掌心）？是否落在环境上（照亮脸／映在湿石／投出长影）？
67. **光是否让开了接触点**？接触帧是否可读，而不是「一团白光吞没两人」？
68. **剑芒长度是否与境界匹配**（一寸／一尺／三尺／丈许／数丈）？长芒末端是否飘散而不是硬棍？
69. 护体光是否只在受击时亮（≤0.4 秒）、碎后需要重新凝？有没有一直亮着像 buff？

## 十、武侠与仙侠质感

70. 是否有**留白**（武侠 ≤15%、仙侠 20–30%）？留白时是否有一个仍在动的细节？
71. 次级运动是否有**延迟**？人停了，衣摆还在走 0.2 秒。
72. 是否擅自添加了门派、道统、招式名、法宝来历、辈分设定？用户没给的，不许自己编。
73. 环境互动是否每条镜头超过两处？超过就变成杂技。
74. 黑名单词是否已全部换成可见画面（武侠：剑光如虹、招招致命、气吞山河、快如闪电、内力深厚；仙侠：仙气飘飘、道骨仙风、法力无边、天地变色、灵光暴涨）？
75. 喊招／念咒（如要求）是否与出招同帧、短促、不拖长音？是否只在关键招式或终局才完整喊出？声音顺序是否固定（破风 → 接触 → 余振 → 环境余响）？

## 十一、收束

76. 收束的 1–2 秒是否留给了世界（碎瓦滑落、尘土下落、灯笼摇晃、水面扩圈、阵纹冒烟）？
77. 有没有出现「两人静止对峙」的构图？那会被拍成静态海报。
78. 结尾是否有句号（武侠：收剑／抱拳／转身；仙侠：御剑而去／留一物／留痕不留人），或者明确选择不写？

## 十二、能量实体化与蓄力（仙侠进阶）

79. 能量是否有实体形态并按兵器语法运动（鞭按鞭法抡扫缠绞、弦按弦法崩弹）？还是只是一团会发光的东西？
80. 能量生命周期是否写全：成形 → 携行 → 压缩蓄力 → 释放 → 回收或转移？释放后能量去哪了（吸回、灌地、残留物上继续跳）？
81. 蓄力是否写成身体动作序列（逐指扣紧、逐段压缩）？有没有只写「力量汇聚」？
82. 粒子是否有受力逻辑（被惯性扯出又弹回、分叉断裂重连）？
83. 关键重击是否给了摄影机一层反馈（过曝、噪点、被震波推偏、后仰失稳）？对撞的反震是否按双方量级分配？伤害后果里能否找到前面注入的能量（断肢带电尾、断口电弧乱跳）？

## 十三、血肉与断肢

84. 每处血肉是否能回溯到明确伤害决策（谁／什么兵器／哪个解剖位／什么角度）？有没有无来由的血浆？
85. 顶级血腥（断肢／腰斩／内脏）是否只给决胜击、一场一次？默认档是否未超中档（用户没点名残酷）？
86. 断肢三段是否齐全（切断帧→断肢去向→断口后续）？断口是否跨镜保留，没有下一镜长回去？
87. 血的物理是否成立（方向服从刃口／旋转离心弧线／晚半拍／有量有落点）？有没有只写「鲜血直流」？
88. 仙侠创口是否带能量痕迹（电弧乱跳／焦黑／冻珠／平整切口延迟出血）？有没有用「血肉模糊」「惨不忍睹」这类概括词代替可见画面？

## 十四、声音与声线

89. 有声线参考时，是否三段齐全：音频引用＋**同句图像锚点**＋「不新增人物、不新增第二个声源」的兜底？有没有只给音频不给图？
90. @ 引用的名字是否唯一？素材库有没有重名（「藏医」与「藏医2」并存导致自动挂错）？成稿里的标记是否回读核对过，而不是凭手输？

---

检查摘要应简短：线别与档位、境界与真元预算、时序格数、使用的招式／内力／法术／运镜原词出处、破坏推进到几级、主要连续性结果、尚未验证的成片效果。不要把整张检查表塞进提示词。
