# 高速复杂动作的影视呈现

用于用户要求“复杂动作、连招、更刺激、出拳更快”，或反馈画面像慢速拆招的情境。本文件调整银幕编排与视频提示词的呈现，不提供现实格斗训练或伤害效果优化。用户指定的剧情、结果、人物能力和风格仍优先。

## 先设计组合，再落时间格

先从已授权动作与连招库中选出完整的表演短语，再将同一短语分配到连续半秒格；不要逐格随机抽一招。内部记录短语的起始状态、视觉发展、复杂动作亮点、结束状态与下一段接口。成品逐格写出变化，不能只说“完成一套连招”。

复杂性应来自看得见的变化：曲线与直线的交替、身体朝向与高低层次变化、移动中的连续表演、双方位置交换，以及有起落过程的旋转或腾空动作。根据角色能力与用户授权选用，不需要每段全部出现。不得只用直拳与正向踢腿重复轮换来代替“招式丰富”。

复杂动作成品表达与信息精简按 `chinese-action-writing.md` 执行：内部保留原词映射，成品写辨识动作所必需的可见过程。常见名称仅作辅助；不能把库中复杂词条投喂后就假定模型理解，也不能为缩短文字删掉形成该动作特征的转向、起落或空间变化。

在允许原创的15秒复杂高速段中，优先设计两段视觉结构不同的连续组合，并设置一个有完整进入与退出过程的复杂动作亮点。这是起稿检查，不是强行增加剧情或命中的配额；用户限制优先。复杂动作可以占多个格，但前后的衔接持续运动，不在动作前后各停半秒摆姿势。

## 半秒是记录窗口，不是动作耗时

- 一格可包含同一组合内的多个短动作以及对方的回应；写清“先、随即、同时、仍在延续”的关系。不能把两个独立的大幅旋转、腾空和落地过程硬塞进半秒。
- 快速短动作可在半秒格内较早完成主要位移，余下时间已经进入接续；不把手臂从起点到终点均匀拉满0.5秒。复杂全身动作按自身过程分配时间，不能统一套短动作时长。
- 将“动作本体速度、动作之间的间隔、镜头长度”分别描述。镜头持续一秒不代表出拳持续一秒；剪辑更密也不等于身体更快。
- 受击反应、衣发余势与后续表演并行。0.3–0.5秒是可见反馈的延续窗口，不是每次接触之后必须单独等待的时间。幅度较大的状态变化仍须留出足够画面，不能跳过。
- 默认正常播放、无慢动作、无速度渐变、无命中定格。短促方向性运动模糊只出现在快速运动末端；身体位置、动作起止和结果保持可追踪。不要用全屏模糊或复制肢体来掩盖动作。

## 组合的节奏与摄影

让短动作形成紧密的节拍组，较复杂的全身动作形成连续的弧线；两者的速度与画幅变化构成节奏，避免所有动作都匀速、等长、等力度。快速段保持接续，不要求每个动作重新展示准备和完整收势。

复杂动作优先使用能容纳全身路径的中景或全景，保持足够镜长展示完成过程。近景用于短促交换与接触关系，不为了“近景占多数”切掉腿部、转身或落地。镜头跟随整体移动，不逐手追逐；一镜到底沿同一路径完成景别变化。

## 与旧参考的关系

本模式优先于参考中的“每格只取一招”“同词两次/同族三次”“连打只取两三拍”“主战族以外不能取”“腾空一段最多一次”等风格性数量建议。这些建议不能成为自动删掉复杂动作或截短组合的理由。词库来源、角色辨识度、实体路径与状态连续性仍需检查。

连招库提供候选素材，其原表和映射不必原样整段照抄；只在影视创作授权内组织动作。不得为了刺激改变人物胜负、增加武器或升级伤势。

## 交付前自查

1. 去掉“高速、复杂”等形容词后，是否仍能从具体时序看出组合和速度？
2. 是否存在完整组合与复杂动作亮点，而非30格互不相连的单招？
3. 是否把短动作拉满半秒，或把每次反馈串行安排成等待？
4. 复杂全身动作是否得到完整画面与合理时间，是否为了近景或快速剪辑切掉关键过程？
5. 是否分别说明动作本体速度与接续间隔，且没有靠提高剪辑频率冒充提速？

以上为文本编排检查。只有实际生成并观看视频后，才能判断目标模型是否实现速度、复杂动作与连续性；没有出片时不得声称视觉问题已解决。
