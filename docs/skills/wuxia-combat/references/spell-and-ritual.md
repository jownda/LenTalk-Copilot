# 法术：六段、三类、一条打断线

仙侠最容易拍砸的地方，是**法术变成了「抬手 → 白光 → 对面爆炸」**。这三步之间少了四步，观众看到的就是特效而不是斗法。

## 一、六段，缺一段就散

| 段 | 时长 | 必须写出 | 失败的样子 |
|---|---|---|---|
| **1 起诀** | 0.3–1.2s | 手做什么（结印／掐诀／剑指／按符）、嘴动不动、身体朝向 | 手一直垂着，法术从胸口冒出来 |
| **2 引灵** | 0.2–0.5s | 灵气从哪来（四周空气、地面、符纸、剑身、天上）、怎么聚（旋、吸、涌、凝） | 没有任何聚集过程，凭空出现 |
| **3 凝形** | 0.2–0.4s | 具体形状（球／锥／线／环／刃／网／掌印／符纹）、大小、颜色 | 只写「强大的力量汇聚」 |
| **4 释放** | 0.1–0.3s | 怎么出去（推、掷、指、劈、洒、吐）、初速、轨迹 | 原地消失，对面已炸 |
| **5 生效** | 0.3–0.6s | 打在哪、什么反应、破坏几级 | 只有光，没有后果 |
| **6 收势** | 0.3–1.0s | 手怎么收、光怎么灭（散成雾／缩回／被风吹散／残焰）、人怎么喘 | 光一收，人跟没事一样 |

**六段总时长约 1.4–4 秒。** 这个数字很重要：它决定了这段法术能不能被躲、能不能被打断、一场 15 秒能放几次。

**短法术可以压缩到 4 段**（省起诀与收势），但**省掉的必须是「快」的部分，不能省「形」与「后果」**。压缩成「抬手—白光—爆炸」的不叫快，叫缺。

## 二、三类法术，三套物理

| 类型 | 代表 | 物理 | 写法要点 |
|---|---|---|---|
| **直击类** | 雷法、剑气、火球、冰锥、光柱 | 有弹道、有飞行时间、有落点 | 距离 ÷ 速度 = 飞行帧数。10 米约 0.15 秒（4 帧），必须让观众看见它飞过去 |
| **场域类** | 法阵、结界、领域、毒雾、剑域 | 先落地成形，再有边界，再有效果 | **顺序不能反**：纹路先出现 → 边界合拢 → 规则生效。反了就是贴图 |
| **改变类** | 召唤、变化、御物、搬运 | 必须有持续消耗，中断即散 | 写「他一直在维持」：手不松、额见汗、脚下纹路一直亮着 |

**直击类最常见的错**：法术瞬移到位。观众没看见飞行过程，就感觉不到速度，也感觉不到「他能躲」。

**场域类最常见的错**：结界先有罩子，再有地面。正确的是地先亮，罩后起。

## 三、前摇（telegraph）：观众必须提前知道他要放大招

仙侠的紧张感全在「他快放出来了，你来不及了」。

三种前摇写法，**至少写两种**：

| 载体 | 写法 | 例 |
|---|---|---|
| **手** | 结印的速度、指节的力度、手掌翻转 | 双手在胸前扣成一个印，指节因用力发白 |
| **物** | 符纸自燃、剑鸣、铃响、宝塔震颤、镜面起雾 | 剑身在鞘中先响了一声，三寸青芒从鞘口漏出来 |
| **天／环境** | 云聚、风停、鸟散、水面起纹、烛火同时压低、尘粒悬停 | 檐下的雨忽然斜了，所有烛火朝同一个方向偏 |

**风停、鸟散、烛火同偏**是最便宜也最有效的前摇，成本几乎为零。

## 四、打断：仙侠独有的失败方式

| 打断方式 | 时机 | 后果 |
|---|---|---|
| **打手** | 起诀或凝形中 | 印散、法术溃散成一团乱光炸在自己手上、虎口裂 |
| **打物** | 引灵中 | 符纸烧掉半张、剑被击偏、法器裂一道纹 |
| **打身** | 凝形后、释放前 | 法术反噬，从体内往外炸，吐血、经脉受损 |

**打断只能发生在凝形之前或凝形之中。** 已经释放出去的法术不能被打断，只能被挡、被躲、被同类法术对掉。

**反噬要可见**：不是「他受了内伤」，是从袖口渗出的一线血、是掌心焦黑、是咳出的血落在地上冒烟。

## 五、五行：只写抵消，不写数值

相克不是伤害加成，是**两股力碰在一起时，谁先消失、以什么方式消失**。

| 相遇 | 可见结果 |
|---|---|
| 水 → 火 | 大量白汽炸开，火被压成一条线，水也少了一半，两败 |
| 土 → 水 | 水被挡住，混成泥流沿墙淌下，土墙塌一角 |
| 金 → 木 | 木被切断，断口整齐，金器刃口卷了一点 |
| 火 → 金 | 金器烧红、滴下熔珠，落地冒烟，但没断 |
| 木 → 土 | 地面裂开，根须从缝里钻出，把土块顶翻 |
| 同属性相撞 | 不分胜负，只有消耗：两团火合成一团更大的火，然后一起熄灭 |

**同属性相撞最忌讳写成「谁更强谁赢」**——那是数值游戏。正确写法是：两股同源之力黏在一起，谁先松手谁输，输的人被自己的力反推。

## 六、雷法：仙侠最好的打击感

雷有三个天然的时间差，用好了比任何特效都重：

```text
先见光（0.0s） → 后闻声（0.2–0.5s，按距离） → 再落点爆炸（0.05s 后）
```

真实的雷是「光先到、声后到」，因为光比声快。**这个物理事实恰好就是「先到后爆」的仙侠版**：观众先被闪一下，然后才听见，最后才看见石头飞起来。

| 雷法形态 | 写法 |
|---|---|
| 天雷（引天） | 云层先亮一下 → 一道竖光落地 → 雷声晚 0.3s → 落点石面炸开、焦黑一圈 |
| 掌雷（自出） | 掌心先聚出细小电弧（不刺眼）→ 推出 → 电弧沿手臂爬过 → 接触处爆开、空气有焦味 |
| 雷网（场域） | 多道细雷在地面连成网 → 网内一切被电得跳起 → 网收拢时最亮 |

**雷声必须晚到。** 同时响的雷是假的，观众说不清哪里不对，但一定觉得不对。

## 七、咒术与禁术：慢的、无声的、要还的

| | 咒术 | 禁术 |
|---|---|---|
| 外观 | 无光或极弱光，只有唇动、指掐、对方身上起反应 | 明显异象：黑气、血纹、天空变色 |
| 速度 | 慢（2–5 秒），但**不可打断**（除非杀了他） | 快（1–2 秒），威力极大 |
| 代价 | 精血、记忆、声音、寿元 | 必然反噬，且不可逆 |
| 写法 | 写「对方的变化」：皮肤下有什么在爬、瞳孔变色、动作变慢 | 写「施术者的变化」：头发白一段、手背上浮出纹路、七窍渗血 |

**禁术的反噬必须让观众看见，且必须在同一场里发生。** 放到下一场等于没写。

## 八、代价清单（每次大术至少一样，且累积）

| 代价 | 可见写法 | 累积表现 |
|---|---|---|
| **真元** | 呼吸变长、指尖发抖、站姿松了 | 第三次之后，法术变小、变慢 |
| **精血** | 唇色变淡、脸色转青、手背血管凸起 | 第二次之后开始晃，第三次要扶东西 |
| **寿元** | 鬓角白一缕、眼角多一道纹、声音变哑 | 不可逆，写完就一直在 |
| **法器** | 裂纹、宝光变暗、剑身发烫 | 裂到第三道就废了 |
| **经脉** | 虎口裂、袖口渗血、咳血 | 再施法会痛，动作变形 |
| **因果** | 天空聚云、远处雷声、鸟兽惊散 | 结尾必须落地（天雷、反噬、追杀） |

**代价不是惩罚，是节奏工具。** 它让观众知道「他还能放几次」，从而产生紧张。没有代价的法术，等于没有血条的 boss。

---

**一句话总结**：法术不是光，是六段时间、三类物理、一次前摇、一笔要还的债。写完自查——起诀在哪、灵气从哪来、形状是什么、飞了多久、打中了什么、他还得起吗。
