# 血肉与断肢：暴力要有真实的后果

武侠与仙侠的暴力，差距不在打得多狠，在于**后果写得清不清楚**。观众记住的不是「他很猛」，而是「那条手臂飞出去的时候还在闪电弧」。

这份文件只管一件事：**伤口、断肢、血、残躯**怎么写才真实、才有量感、才不像游戏特效。

## 〇、先立三条纪律

1. **血肉是后果，不是装饰**。每一处血肉必须能回溯到一次明确的伤害决策：谁、用什么、切在哪个解剖位置、什么角度、什么速度。说不出这四样，血就是泼上去的颜料。
2. **一场只给一次顶级**。断肢、腰斩、内脏外露属于顶级血腥，一场只能出现一次，给决胜击。普通击只有血线与渗血。两次断肢连着来，第二次观众就麻木了。
3. **分级先看剧情硬需求，再看用户口味**。剧情事件本身已经是断肢、腰斩、分尸（用户剧本写明「断臂」「拦腰截成两段」），就按重档写、写足、不许写软——把断臂写成「擦伤」是失职。只有剧情没定时，才默认中档；用户额外要求「再狠一点／不删减」时升档。三档：轻（血线、渗血、破皮）／中（喷溅、断指、入肉见骨）／重（断肢、腰斩、内脏）。无论哪档，一场的顶级血腥仍然只给决胜击。

## 一、伤害要打在结构上，不是打在「身上」

真实感的第一来源是**解剖精度**。不写「砍中肩膀」，写「戈锋从腋下与肩窝之间的连接处切入，沿肩关节向上硬斩出去」。

| 部位 | 打这里会发生什么 | 写法要点 |
|---|---|---|
| 手腕／肘 | 失去握持，兵器脱手或垂落 | 先写兵器脱手，后写血——手先不听话 |
| 肩关节 | 整条手臂失去支撑，可被整个挑断 | 必须写出关节分离的一瞬，肩窝露出 |
| 咽喉 | 气声断、血呈雾状喷出、身体先软后倒 | 声音先断，人后倒 |
| 肋侧 | 入肉深但不立刻致命，血沿衣料渗出 | 适合中档，写「衣料迅速洇深」 |
| 腰部 | 腰斩：上下身分离，内脏随血坠出 | 顶级档专用，一场一次 |
| 后颈 | 头颈失控、身体还会往前冲两步 | 先写身体惯性，后写倒地 |

**同一次伤害，至少写三样**：切入口（刃从哪进）、断开的东西（骨／筋／关节）、身体失控的方式（哪一段先不听话）。

## 二、血的物理五条

血不是红色贴图，它有质量和方向。

1. **方向服从力**：血沿断面的朝向喷，不沿镜头的喜好喷。刀刃从左下往上挑，血就往右上斜喷。
2. **旋转带离心**：被抡起来甩出去的躯体，血沿旋转切线甩出一道弧线，不是直直下落。这是「在空中炸开」最容易被忽略的一条。
3. **晚半拍**：断口先张开，血稍后才到峰值——先到后动的血液版。切口越干净利落（利刃、快刀、剑芒），血越会延迟到人已经转身才喷出来。
4. **有量、有落点**：写「血水喷溅，沿断臂甩出的弧线在泥地上砸出一串深色点」，不写「鲜血直流」。落点要留痕：泥地、戈锋、衣袍、脸。
5. **血雾是空间标记**：大量出血在空气中形成短暂血雾，血雾能「接住」后续动作的剪影（长戈在血雾中回旋飞回，就是靠血雾给背景对比）。

## 三、断肢三段（固定结构，缺一段就不真）

```text
切断帧 → 断肢去向 → 断口后续
```

1. **切断帧**：必须清楚、完整、爆裂。画面明确看到刃切进哪里、什么被断开、切口什么形状。一两帧，不许「一声惨叫带过」，也不许把镜头切走回避。
2. **断肢去向**：断下来的部分去哪了？写轨迹＋携带物。例：「断臂带着整团尚未释放的雷电拳头高速旋转着冲向高空，压缩雷核还在闪动，拖出一串青白电尾，像一颗被斩出去的雷电流星。」断肢不能凭空消失，它飞出去的路线就是下一拍的素材。
3. **断口后续**：断口是持续状态。喷血、断骨外露、失控的能量在断口里乱跳、伤者因剧痛和失衡踉跄。这条状态要跨镜保留，不许下一镜长回去。

## 四、血腥与能量联动（仙侠线必写）

仙侠的创口不是普通创口，血里必须能找到前面注入的力：

- **雷法**：断口内电弧乱跳、血与雷混成爆散物、切口边缘焦黑碳化。
- **火法**：血瞬间蒸成暗红蒸汽、创面焦黑、几乎无血（反而更狠）。
- **冰法**：血在离体瞬间冻成暗红冰珠、断面结霜、没有喷溅只有坠落。
- **剑芒**：切口平整如切豆腐，血延迟半拍才涌出来——快刃的招牌。
- **毒／腐蚀**：血变黑、滴落处烧出小坑、创口持续冒烟。

**能量与血肉同时炸开**是这类戏最有效的一帧：「鲜血、碎肉和青白雷光同时炸开，像一团血和雷混在一起的爆散物猛地向上掀飞。」

## 五、处置链：把暴力做成一段流程

真正有压迫感的不是「一刀砍死」，是**胜利者对失败者的处置过程**，每一环都有画面：

```text
缴械 → 折断 → 抓取 → 抡转 → 抛投 → 补杀 → 收兵器 → 残躯落地
```

实战范例（风长老）：双臂被反拧折断 → 抓住一只断臂把整个人抡起 → 原地高速旋转数圈 → 抛向高空 → 回身拔戈、借转身惯性掷出 → 从腰部拦腰截成两段，鲜血、碎肉和内脏在空中炸开 → 凌空一握，长戈在血雾中回旋飞回 → 风沙和残躯缓缓坠下。

这条链的价值：

- 每一步都是**可拍的独立动作**，不需要慢镜也能看懂；
- 力量差不需要形容词，「把人抡起来转圈」本身就是量级宣告；
- 结束动作（收回兵器、斜指地面、残躯坠下）给了收束，暴力才有句号。

## 六、声音（可选，用户要声音设计时才写）

- 断骨：闷响，不是脆响；一声，短。
- 断肢落地：湿而钝，比金属落地晚半拍。
- 血喷：短促的「噗」，之后是滴落，不是持续水声。
- **安静比声音更狠**：切断帧之后给 0.2 秒环境音（风、沙、旗响），血才喷出来。

## 七、黑名单与替代写法

| 不写 | 换成 |
|---|---|
| 血肉模糊 | 断口的具体状态：骨茬、断面、血的颜色与流速 |
| 惨不忍睹 | 一个具体细节：断指还扣在戈杆上 |
| 鲜血直流／血流如注 | 方向、量、落点：血沿断臂弧线在泥地砸出一串深色点 |
| 一片血雾 | 血雾的边界，它遮住了什么、露出什么 |
| 死不瞑目 | 眼睛的反光在雷光里亮了一下就暗掉 |

**内脏**只在重档、且用户点名时写，写一个具体器官＋状态（「肠段随血坠出，挂在断口边缘」），不铺陈、不罗列、不超过一句。

---

**一句话总结**：血肉的真实感不来自血多，来自**结构（打在哪）、方向（往哪喷）、去向（断下来的部分飞去哪）、残留（断口一直在）**。四样写全，一刀就够；缺一样，砍十刀也像泼颜料。
