# 仙侠美学：仙气是「空」出来的，不是「加」出来的

武侠的高级是**收得住**，仙侠的高级是**留得白**。

一场仙侠戏如果每一帧都在发光、每秒都有法术、每句话都在讲境界，它不会显得仙，只会显得吵。真正的仙气来自三件事：**慢、远、静**。

## 一、三条仙气法则

| 法则 | 具体做法 | 反例 |
|---|---|---|
| **慢** | 关键动作比武侠慢一拍：抬手慢、转身慢、剑出鞘慢 | 全程快切，法术连发，像格斗游戏 |
| **远** | 常用远景与大全景：人在山中是一个点，云在脚下不是背景板 | 全是特写与中景，没有尺度感 |
| **静** | 每场至少一次「什么都不发生」：风过、云移、叶落、钟响 | 从头到尾都在打 |

**留白比例：仙侠 20–30%，比武侠的 ≤15% 更宽。** 因为仙侠的尺度大，观众需要时间「看清有多大」。

留白时**必须有一个仍在动的细节**：一缕云、一片落花、剑穗的摆、水面的纹。全静止会变成壁纸。

## 二、六类场景与它们的用法

| 场景 | 光 | 材质 | 适合的戏 |
|---|---|---|---|
| **仙山／云海** | 日出前的冷青、云隙光 | 石阶、古松、铁链、云 | 立威、登场、告别 |
| **月下／水畔** | 单一冷月、水面反光 | 石桥、芦苇、舟、雾 | 对决前的对峙、隐秘对话 |
| **竹林／雪原** | 高反差、雪地反光 | 竹、雪、冰、枯枝 | 追击、伏击、快节奏 |
| **洞府／丹房** | 内部光源：丹炉、夜明珠、符火 | 石壁、铜器、药柜、蒲团 | 疗伤、炼器、密谋 |
| **废墟／古战场** | 阴天、残光、烟 | 断碑、焦土、残阵、白骨 | 大战之后、旧仇、禁术 |
| **天宫／宗门大殿** | 顶光、巨大窗格、香烟 | 玉阶、铜鹤、经幡、巨柱 | 审判、宣战、终局 |

**同一场戏只用一个场景。** 中途换景会让仙侠变成旅游片。

## 三、色彩：一个冷底 + 一处破色

仙侠的默认调色是**水墨**：青、白、灰、墨，加一点点暖。

| 层 | 色 | 占比 |
|---|---|---|
| 底 | 冷青 / 月白 / 石灰 | 70% |
| 中 | 墨黑（衣、影、石） | 20% |
| 破色 | 一点金（法宝）／一点朱（血、符）／一点紫（雷） | ≤10% |

**破色只能有一处。** 金色法宝配朱红符纸配紫色雷光，等于三种颜色在打架。选一个，让它成为全片最亮的东西。

**正邪不靠衣服颜色分**。穿黑衣的可以是正道，穿白衣的可以是魔头。用**行为**分：正道收力、留手、先礼后兵；邪道抢攻、偷袭、拿人当盾。

## 四、服化道：三件必备，两件禁用

**必备**：

1. **一件会动的东西**——道袍下摆、宽袖、剑穗、腰带、长发。仙侠的飘逸全靠它，静止的服装会让法术变成摆拍。
2. **一个身份标记**——发冠、簪、腰牌、宗门纹、断剑。观众靠它认人。
3. **一处旧痕**——袖口的磨损、剑鞘的裂纹、补过的衣角。全新的一身会让角色像刚出厂的模型。

**禁用**：

- 现代剪裁（西装领、拉链、牛仔裤、运动鞋）
- 塑料感的反光面料
- 过于繁复的刺绣与流苏（会吃掉动作）

## 五、语言的腔调

仙侠的对白要**古而不涩**：听得懂，但不像现代人说话。

| 可以 | 不可以 |
|---|---|
| 「道友」「前辈」「师叔」「不必」 | 「你好」「OK」「没问题」「搞定」 |
| 「你输了。」「还没。」 | 「你完蛋了」「我劝你善良」 |
| 四字句偶尔用一次（「剑走轻灵」） | 通篇四字，像在念课文 |
| 沉默、点头、抬手 | 边打边解说自己的招式原理 |

**招式名只在关键时刻喊一次**，且与出招同帧。整段喊三遍，气势就散了。

**不许解释设定。** 不要写「他是金丹期，所以能御剑」。让观众从「剑芒三尺」和「他一剑削断石桥」自己看出来。

## 六、礼与规矩（仙侠独有的戏剧资源）

仙侠世界有**规矩**，这是它比武侠多出来的一层戏：

| 规矩 | 用法 |
|---|---|
| **先礼后兵** | 开打前抱拳／稽首／报家门，对方不回礼就是挑衅 |
| **不斩来使** | 有人可以走进战场而安全离开，这给了传话与谈判的空间 |
| **斗法不伤凡人** | 强者必须收力，收不住就是失德，会被人围攻 |
| **同门不杀** | 打到一半收手，改用「押回去」 |
| **誓言与因果** | 发过的誓会应验，这是仙侠特有的「必须遵守的规则」 |

**「收力」是仙侠最好的克制表现**：他能一剑削平山头，但在城门口只用了一寸剑芒，因为身后是凡人。这一个细节比十句台词都能说明他是好人。

## 七、声音：仙侠的静比响更贵

```text
远：风、云、水、钟、鹤唳、诵经（低、混响长）
中：衣料、脚步（踩石／踩雪／踩水，要分清）、剑鸣
近：呼吸、心跳、血滴、符纸燃烧的"嗤"
法术：起诀时几乎无声 → 凝形时低频嗡 → 释放时一声爆 → 余韵是回声
```

**关键手法：法术之前先静一下。** 把环境音抽掉 0.3–0.5 秒，只留呼吸或风，然后法术炸出来——这一下的对比比任何音效都重。

**不要给每个法术都配 BGM 高潮。** 全片只给一次。

## 八、笼统词黑名单

以下词出现在成品里，一律换成可见画面：

| 黑名单 | 问题 | 改成 |
|---|---|---|
| 仙气飘飘 | 没有画面 | 衣摆被气流托起半寸，一直没落下来 |
| 道骨仙风 | 评价，不是描写 | 背很直，站着不动，风吹到面前自己分开 |
| 气势磅礴 | 空 | 云被从中间推开，露出下面的山脊 |
| 天地变色 | 无法拍 | 云层被从下往上照亮，所有影子同时朝外拉长 |
| 法力无边 | 无数值、无画面 | 一掌按下去，方圆十丈的地面同时下沉半尺 |
| 剑光如虹 | 陈词 | 一道青白横过，三根石柱先后错位 |
| 灵气逼人 | 无载体 | 他站的地方，草从石缝里往外长 |
| 惊天地泣鬼神 | 空 | 一块山岩从崖上脱落，砸进云里，很久才听见声 |

## 九、仙侠的句号

武侠的句号是收剑、抱拳、转身走。
仙侠的句号多三种：

1. **御剑而去**：剑放大，人上去，背影越来越小，云合上。
2. **留下一物**：把剑插在原地、把符贴在门上、把丹药放在石上，然后走。
3. **天地回应**：云散、雨停、光收，天地恢复原样，只有地上的痕迹还在。

**最好的仙侠结尾是「痕迹」**：人走了，阵纹还在地上，焦痕还在冒烟，断剑还插在石缝里。观众记住的不是他多强，是那一片没恢复的废墟。

---

**一句话总结**：仙气来自慢、远、静；破色只有一处；规矩比力量有戏；结尾留痕不留人。
