# 法阵：仙侠的空间武器

法阵是这个 Skill 里**唯一一种「先改变空间、再打人」的手段**。它不是特效，是布景级的力量投送装置。

写法上有一条铁律：**观众必须能看懂这座阵的形状、中心在哪、怎么破。**

## 一、三要素，缺一个阵就不成立

| 要素 | 是什么 | 必须可见 | 失败的样子 |
|---|---|---|---|
| **阵图** | 地上的纹路 | 怎么出现、什么颜色、多大范围、什么图案（圆／方／八角／符文链） | 光从地上冒出来，但看不出是阵 |
| **阵眼** | 阵的核心，通常是一件法器或一个人 | 位置、形态、保护、可被攻击 | 阵铺满画面，但找不到打哪 |
| **阵旗／节点** | 布阵的支点 | 几面、插在哪、什么颜色、有没有被拔 | 阵凭空成形，没有布置过程 |

**阵眼必须在画面里。** 这是仙侠动作戏的基本契约：观众知道「打那里就能破」，紧张感才成立。找不到阵眼的阵，只是一块发光的地毯。

## 二、布阵四段（法阵是慢招）

```text
落旗（0.5–2.0s） → 连线（纹路亮起，0.3–0.8s） → 合拢（边界成形，0.2–0.5s） → 启动（规则生效，0.3s）
```

**布阵是全片最慢的动作。** 所以它必须满足下面三条之一，否则就是「敌人站着看他布阵」：

1. **有人掩护**：同伴在挡，他在布；掩护的人被打退，阵还差两面旗。
2. **在挨打中完成**：一边退一边插旗，旗插歪了，阵就有缺口。
3. **阵是提前布好的**：开场就已经在地上，只是没启动——这是最省时间也最阴的用法。

**布阵被打断是最有戏的失败**：旗被踢飞、纹路断了一截、阵成了一半（只有半边生效，另半边是空的）。

## 三、阵内规则必须写成可见症状

不要写「入阵者受到压制」。要写**规则在他身上留下的痕迹**：

| 阵的类型 | 规则 | 可见症状 |
|---|---|---|
| **困阵** | 走不出去 | 走了十步，回到原地，地上的脚印是同一个 |
| **杀阵** | 持续伤害 | 皮肤下浮出细红线、衣料自己裂开、血从耳中渗出 |
| **压阵** | 变慢变重 | 抬脚要两拍、剑抬不起来、呼吸可闻、膝盖发颤 |
| **幻阵** | 看见假的 | 对面出现三个一模一样的人，但只有一个人有影子 |
| **锁灵阵** | 施不了法 | 掐诀掐不出光、符纸点不着、法宝在袖中不动 |
| **聚灵阵** | 增强 | 自己这边的光变亮、伤口在合、但阵眼在对方手里 |

**锁灵阵是最有戏剧性的**：它把仙侠打回武侠——两个修士在阵里只能用身体打。这是最好的「混搭」理由，不需要额外解释。

## 四、入阵与破阵

### 入阵三法

| 方法 | 写法 | 代价 |
|---|---|---|
| **强攻一点** | 集中火力打阵眼，纹路从被打处开始崩 | 慢，会被阵的其他部分反击 |
| **走生门** | 找到纹路的缺口（阵没布完、旗被拔了、地形破了） | 需要先看出缺口，通常要有人牺牲吸引注意 |
| **以身入阵** | 用自己当新的阵眼，反控这座阵 | 极险：控不住就被阵吞了，控住了也出不去 |

### 破阵的三种结果

1. **阵毁人伤**：阵眼炸开，布阵者吐血，纹路烧黑留在地上。
2. **阵毁阵在**：只破了一角，阵还在运转，但出现了缺口。
3. **阵被夺**：控制权易主，原来的阵现在打原来的人（最爽，也最难写）。

**破阵必须有代价。** 白破的阵不值钱。

## 五、法阵的镜头三件套

少一个，观众就不知道自己在看什么：

| 镜头 | 作用 | 机位 |
|---|---|---|
| **俯拍全景** | 让观众看懂阵的形状、范围、阵眼在哪 | 正俯或高角度斜俯，人小阵大 |
| **平视压迫** | 让观众感觉阵从脚下起来 | 低机位，纹路从画面下缘往上爬 |
| **特写阵眼** | 让观众知道该打哪 | 特写法器／符文，最好有人正在打它 |

**顺序通常是：平视（阵起）→ 俯拍（看懂）→ 特写（打阵眼）。** 反过来也行，但不能只有一种。

## 六、阵纹的视觉语法

| 元素 | 写法 |
|---|---|
| **线条** | 细、直、有转折，不是云雾状；亮起时像烧红的铁丝 |
| **符文** | 小、密、成串，转起来像齿轮；不要写成「看不懂的古文字」 |
| **节点** | 阵旗处有亮点，像钉子钉在地上 |
| **边界** | 一层薄光墙，有厚度（能看见里面折射），受击会凹陷 |
| **地面反应** | 石面被烧黑、草被压平、水被蒸干、雪融化后又结冰 |

**阵纹不能飘在空中。** 绝大多数阵是画在地上的；浮空的阵只能是「领域」级别（化神以上），而且必须有支撑（悬空的符、环绕的宝塔）。

## 七、跨镜留痕

阵破了，痕迹要留：

- 地面烧黑的纹路（一直在）
- 焦痕边缘还在冒细烟
- 断掉的阵旗斜插在土里
- 碎掉的灵石，碎片还有微弱余光（会慢慢暗下去，但不会立刻灭）
- 阵眼处一个坑，坑底有金属熔过的痕迹

**留痕是法阵存在过的证据。** 不留痕，观众会以为那阵是幻觉。

## 八、失败写法

| 失败 | 问题 |
|---|---|
| 他一挥手，一座大阵瞬间铺满山谷 | 没有布阵过程，阵变成魔法地毯 |
| 阵法启动，天地变色，敌人动弹不得 | 规则没有可见症状 |
| 阵中光芒万丈，两人在其中激战 | 光盖住了动作，看不到打什么 |
| 他破了阵 | 没写怎么破、破了多少、付出什么代价 |
| 阵眼是一颗珠子，在天上 | 阵眼不可攻击，紧张感为零 |

---

**一句话总结**：法阵 = 阵图 + 阵眼 + 阵旗，四段布成，三镜讲清，破了要留痕。观众找不到阵眼，这场戏就白打了。
