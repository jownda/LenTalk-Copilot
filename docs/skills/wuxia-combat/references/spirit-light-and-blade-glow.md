# 灵光、剑芒与真元外放

仙侠的光不是装饰，是**信息**。观众靠它判断：这人什么境界、这招多大、打中了没有。

写光的唯一标准：**每一处光都要能回答「它挂在哪、有多大、照到谁身上」。**

## 一、先分清三种光（最常混）

| 名称 | 形态 | 是否离体 | 长度／范围 | 用法 |
|---|---|---|---|---|
| **灵光** | 面状、膜状、罩状 | 可以离体（护体、结界） | 贴身的薄薄一层，或数丈的场 | 护体、照明、驱邪、结界 |
| **剑芒** | 线状，从刃口延伸出去 | **不离体**，始终连着剑 | 一寸 / 一尺 / 三尺 / 丈许 | 延长攻击距离、切物 |
| **剑光** | 飞行轨迹的拖尾 | 完全离体 | 随剑飞多远就多长 | 御剑飞行、飞剑取人 |

**混用会让观众分不清他在挥剑还是在放法术。** 剑芒是「剑变长了」，剑光是「剑飞出去了」，灵光是「身上有层光」。

## 二、光的三条纪律

### 1. 光必须有载体

不许凭空出现。合法载体：剑身、刃口、符纸、阵纹、掌心、指尖、印诀、眼、眉心、宝塔、镜面、地面裂缝。

反面例子：「他周身腾起一片灵光」——没有载体，光从哪来？改成：「肩背处的道袍先透出一层薄光，像被从里面照亮。」

### 2. 光必须落在环境上

光不落地，就像贴图。必须写至少一样：

- 照亮半张脸（下巴、颧骨、眼窝的阴影跟着变）
- 映在湿石板上（有反光、有水纹）
- 投出长影（影子比人先动）
- 穿过雾／烟／雨，出现可见的光柱
- 照亮对面的兵器（刃口反出一道细线）

### 3. 光不能盖住接触点

**接触帧的光要缩到轮廓级。** 顺序永远：光在接触点外侧收拢 → 接触点清楚 → 光再爆开。

写「一团白光吞没了两人」= 这一段废了，观众不知道谁打中谁。

## 三、色温与门派色

**一场只有一套对立色。** 两个阵营各一个色，不许每个法术换色。

| 阵营／体系 | 主色 | 辅色 | 用法 |
|---|---|---|---|
| 正道·剑修 | 青白 / 月白 | 一线银 | 克制、干净、细而长 |
| 正道·道门 | 金白 | 淡青 | 温暖、厚重、有符纹 |
| 佛门 | 金 | 琥珀 | 圆融、包裹感、不刺眼 |
| 雷法 | 紫电 / 青白 | 焦黑（落点） | 闪、短、有残影 |
| 邪道 / 魔道 | 暗红 | 紫黑 | 粘稠、往下淌、会吸光 |
| 妖族 | 琥珀 / 翠 | 墨绿 | 生物感、有纹理、像活物 |
| 阵纹 | 与阵主同色 | — | 线条，不发光晕 |

**暖冷对立最好用**：正道冷白、邪道暗红，一眼就分得清谁是谁。两个都用金光是新手错误。

## 四、剑芒长度 = 境界的可见刻度

这是全篇最有用的一个换算。**剑芒有多长，比任何台词都能说明他多强。**

| 剑芒 | 长度 | 能做什么 | 对应境界 | 镜头 |
|---|---|---|---|---|
| 一线 | 一寸（3cm） | 贴身削、割绳、破符 | 炼气～筑基 | 特写刃口 |
| 短芒 | 一尺（30cm） | 切木、断竹、破皮甲 | 筑基 | 中近景 |
| 三尺 | 一米 | 断梁、裂碑、削石 | 金丹 | 中景，能看到芒与剑的连接 |
| 丈许 | 三米 | 断墙、裂地、斩多人 | 元婴 | 中远景，芒比人长 |
| 数丈 | 十米以上 | 削山、断桥、开河 | 化神以上 | 远景，人变成一个小点 |

**芒越长，越要写它的「软」**：长芒不是一根硬棍，末端会飘、会散、会被风吹弯。硬邦邦一条直线是光剑，不是剑芒。

## 五、灵光的四种正确用法

| 用法 | 写法 | 注意 |
|---|---|---|
| **护体** | 只在受击处亮一下，凹陷 → 涟漪 → 裂 → 碎 | 不许一直亮着像 buff |
| **照明** | 掌心托一团光，照亮周围三丈，有明确的光锥 | 要写出光的边界与衰减 |
| **驱邪／净化** | 光扫过，黑气退散、符纸化灰、地面焦痕变淡 | 必须有「被驱散的东西」在退 |
| **伪装／幻术** | 光织成人形、雾里出现多个影子 | 要留一个破绽（影子不动、没有呼吸） |

**护体光是最容易写坏的**：一直亮着的护体光等于没写。正确是一次性的——被打到才亮，亮完就碎，碎了要重新凝（需要时间，这就是破绽）。

## 六、光效预算（写进 FORCE AND IMPACT）

| 项 | 上限 | 说明 |
|---|---|---|
| 全屏光 | ≤1 秒/次，≤2 次/15s | 每次句内写死时长与收束方式 |
| 护体光 | 只在受击时亮，≤0.4 秒 | 不许常亮 |
| 飞行拖光 | ≤身体长度的 3 倍 | 拖太长就变成流星 |
| 环境染色 | 不许把天空、地面整体染成一种颜色 | 只许局部照亮 |
| 持续发光的物件 | 全片最多 2 件 | 剑、符、阵纹算 |

## 七、失效写法对照

| 失效 | 问题 | 改成 |
|---|---|---|
| 周身灵光暴涨 | 无载体、无形状、无范围 | 道袍下摆先亮起来，光沿着布纹往上爬，到胸口停住 |
| 剑气纵横三万里 | 尺度无意义、无落点 | 一道丈许长的青芒横过，三根石柱先后错位，第三根晚半拍才倒 |
| 五彩斑斓的光 | 颜色无信息 | 全场只有青白与暗红，青白是他，暗红是他对面 |
| 光芒万丈，天地变色 | 无法拍 | 云层被从下往上照亮，地面所有影子同时朝外拉长 |
| 一剑光寒十九洲 | 文学修辞 | 剑出鞘一寸，鞘口的青芒把檐下的雨照成一条条亮线 |

---

**一句话总结**：光要有载体、要落地、要让开接触点。剑芒长度是境界刻度，颜色是阵营信息，时长是预算。
