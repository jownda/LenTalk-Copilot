# 武侠与仙侠打斗

## 核心职责

把「东方武学与修真斗法」写成**看得懂、有分寸、像练过、有余味**的动作与镜头。

这个 Skill 装两条线，**分线是动笔第一件事**：

| | **武侠线** | **仙侠线** |
|---|---|---|
| 力的来源 | 身体 + 体内内力 | 真元 + 天地灵气 + 法器 + 阵法 |
| 上限 | 人力所及 | 借来的力，远超身体 |
| 时间结构 | 一瞬间的接触 | 前摇（结印）→ 释放 → 生效 |
| 代价 | 呼吸、手抖、力竭 | 真元、精血、寿元、法器、经脉 |
| 输赢 | 谁先犯错 | 谁先耗尽／谁的阵眼被破 |

两条线共用同一套**身体因果**：脚、髋、肩、末端、接触、后果，一个都不省。仙侠不是「武侠加光」，是**把力的来源从身体外包出去**——所以仙侠的每一术都要回答「这股力是谁的、用什么还」。

按既定剧情转译时，用户提供的打戏剧情是唯一事件来源。人物、关系、动机、事件顺序、谁攻击谁、谁受伤、谁占优、谁逃脱、谁倒下、强弱、结局如何发生，全部以用户输入为准。

创作/补全打戏时，允许设计新的攻击、防守、假动作、反击、术法与衔接；不把新招式当作新故事事件。不得擅自改变用户给定的人物关系、动机、门派归属、伤势上限、胜负或结局。

本 Skill 负责：

- **分线**：武侠线 / 仙侠线，先锁死再动笔。
- **定档**：写实武侠 / 高武 / 仙侠 / 仙侠大片。
- **定境与机动**：仙侠线定境界（决定真元预算与术的规模），两线都要定「人能不能飞、能滞空多久」。
- 把事件拆成可拍摄的动作、力的过程、位移、镜头、破坏与声音。
- 为每一次攻击补足**力的来源**：武侠线写支点／推进／蓄势／代价；仙侠线写真元／法宝／阵法／地脉／借力。
- 为每一次命中补足**打击感**：接触帧可读、后果持续、攻击者自身也被自己的力反推。
- 分配**留白**：武侠 ≤15%，仙侠 20–30%。
- 保住**兵器与道具、伤势累积、脚下与法阵状态的连续性**。

## 三条不可违反的底线

1. **线不串、档不越级**。默认写实武侠：无光效、破坏顶格 3 级、人不飞。用户没点名「内力／气劲／剑气」，就不许出现气劲；没点名「灵力／法术／符／阵／御剑」，就不许出现仙侠手段。整场只升不降，且只能升一档。
2. **力有来源**。武侠线：每一次发力、腾空、变向，必须写出支点或推进或蓄势或代价，至少两样。仙侠线：每一术必须点名真元／法宝／阵法／地脉／他人借力之一，并写出前摇。「他是高手所以可以」不算来源，「他是金丹期所以可以」同样不算。
3. **先接触，后反应**。命中顺序永远是「身体／兵器／法术先到位 → 环境反应才起来」，而且反应要**晚 0.1–0.3 秒**（雷法为雷声晚 0.2–0.5 秒）。先有光、先有尘、先有爆炸再有人，一律重写。

## 不得越界

- 不改变用户给定的人物关系、动机、能力归属、伤势上限、胜负或结局。
- 不擅自添加门派、道统、招式名、辈分、师承、法宝来历。用户没给的，不自己编（见 `wuxia-aesthetic.md` 第三节、`xianxia-aesthetic.md` 第六节）。
- 不把写实武侠写成高武或仙侠：不因为「更好看」就加气劲、加飞行、加法术、加破坏。
- 不为了炫技牺牲可读性：动作再快，接触点必须看得见；法术再亮，也不能盖住「谁打中了谁」。
- 不写无因浮空、不写武器无故换手、不写伤势自愈、不写残骸复原、不写符用完了又掏出来。
- 不把游戏数值（冷却、等级、伤害百分比、蓝条、真元百分比）写进提示词，只写可见的距离、身体力学、接触、后果与恢复状态。

## 适用范围

**武侠线**：徒手与持械的近身交锋、以一敌多、江湖仇杀、门派冲突、镖局护院、屋顶追逐、竹林与雪原对决、渡口与客栈的狭窄空间、轻功追击、暗器与奇门、内力对拼。

**仙侠线**：修士斗法、御剑与飞剑、符箓对轰、法宝相斗、单阵／群阵攻防、护山大战、宗门审判后的追杀、渡劫、正邪对决、凡人以武破修士、天地异象级的大战、法相与领域（仙侠大片档）。

**两条线之间**：练武的对修真的、同一人先武后法（需触发）、低境越级挑战（需代价）——都适用，见 `xianxia-lane.md` 第三节。

不适用于：纯远程枪战、追车为主、机甲驾驶舱操作与仪表流程、纯特效演示片（没有人打）、纯武器技术教学。这些不属于本 Skill 的动作编排范围。

## 优先级

1. 用户明确给出的剧情、事件顺序、人物关系、线别、档位、境界、兵器与法宝、动作结果和输出要求。
2. 上文三条底线。
3. 本文件的写作硬规则、授权边界与连续性要求。
4. 适用的参考文件中的硬性连续性规则。
5. 参考文件中的默认倾向和风格建议。
6. 示例只用于展示写法，不构成剧情或参数默认值。

## 第一步：分线

**动笔第一件事不是设计动作，是分线。** 分错线，后面所有参数都会歪：把仙侠写成「武侠加光」，会得到一堆没有代价的法术；把武侠写成仙侠，会让巷战变成烟花。

| 判断线索 | 线别 | 档位 |
|---|---|---|
| 只说了「打」「武打」「武侠」「决斗」 | 武侠线 | 写实武侠（默认） |
| 「内力」「气劲」「真气外放」「掌风」「剑气」 | 武侠线 | 高武 |
| 「灵力」「法术」「御剑」「符」「法阵」「法宝」「真元」 | 仙侠线 | 仙侠 |
| 「法相」「天地变色」「大场面」「渡劫」「仙魔大战」 | 仙侠线 | 仙侠大片 |

**默认是武侠线的写实武侠。** 没说，就不许发光、不许飞、不许放术。

详细分线规则、九境预算、混搭纪律与四个仙侠体检标记见 `xianxia-lane.md`。

## 第二步：定档

| 档 | 特效 | 破坏量级 | 判断线索 |
|---|---|---|---|
| **写实武侠**（默认） | 无光效。劲只有尘土、碎石、衣料、呼吸 | 0.3 米级 | 用户只说了「打」「武打」「武侠」 |
| **高武** | 气劲可见但不夸张：掌风、剑气、气环、气墙 | 1~2 米级 | 提到「内力」「气劲」「真气外放」「掌风」 |
| **仙侠** | 灵光、符箓、真元、剑芒、法阵 | 12 米级 | 提到「灵力」「法术」「御剑」「符」「阵」 |
| **仙侠大片** | 法相、光柱、领域、天地异象 | 120 米 ~ 数千米级 | 提到「法相」「天地变色」「大场面」 |

档位飘是这个 Skill 最致命的错误：开场巷战贴身短打，三拍后一掌轰出十米气浪。升档纪律、四个通用体检标记见 `wuxia-style-tiers.md`。

## 第三步：定机动等级

档位管特效，等级管**人能不能离地**。这两件事必须分开定。默认等级 3~4：会轻功，但打不了空战。

| 等级 | 能力 | 空中占比 | 空中能做什么 |
|---|---|---|---|
| 1~2 | 凡人步法，全程地面 | 0% | 不许离地 |
| 3~4 | 轻功腾跃 + 滞空约 0.9 秒 | 少量 | 空中只能打 1 下 |
| 5~6 | 踏墙借力 + 滞空约 1.3 秒 | 5~8% | 借墙换位、空中换招 |
| 7 | 凌空飞行，悬停约 3.6 米 | 约 49% | 升空压迫、空中交手 |
| 8~9 | 御空飞天，悬停 5~6.5 米 | 55~59% | 浮空战斗 |
| 10~11 | 御剑飞行／凌空虚渡，可长时间滞空 | 60~75% | 空中施法、上下翻飞 |
| 12 | 缩地成寸／瞬移级位移 | 不定 | 位移不可用连续镜头交代，必须留残影或留痕 |

**0.9 秒约等于 22 帧**：起跳 6 帧 + 出手 8 帧 + 落地 8 帧，刚好。所以等级 3~4 的人在空中只能打一下，写两下就是违规。

**仙侠线的离地必须有承载物**：剑、云、气纹、阵。等级 7+ 也要写「气托」或「剑在脚下」，不许凭空站着。

## 写作硬规则

### 发力：四段身体链（两线通用）

```text
脚蹬地 → 髋转 → 肩送 → 末端（拳/掌/指/肘/膝/脚/肩/兵器）
```

**至少写出三段。** 只写「他用力打」的是无效描写。

四段之外还要有**反作用**：攻击者退半步、后脚蹭地、肩沉一下、兵器反弹。这一条是分水岭——只有被打的人在动、打的人纹丝不动的镜头，直接判失败。

高武档在四段之上再加一段**行气**：起势（沉腰／提气）→ 行气（沿脊、肩、臂可见）→ 末端成形 → 释放 → 余劲。见 `innerforce-and-qi.md`。

**仙侠线的身体动作退到第二层，但不消失**：结印的手、掐诀的指、踏罡的脚、御剑时绷紧的肩。删掉所有光效之后，这一段必须还剩「他在退、在挡、在喘、剑在抖」。

### 打击感：三件套 + 先到后动

每次命中必须具备：

1. **接触帧可读**（2–3 帧）：接触点、受力方向、被击部位同框。
2. **后果持续**（0.3–0.5 秒）：位移、形变、失衡、衣料受压、脚下犁痕。
3. **攻击者反作用**：同帧或下一格。

再加**先到后动**：力已经到了，环境反应晚 0.1–0.3 秒才起来。刀砍进柱子，木屑晚半拍才炸开；剑刺进肩，血晚半拍才渗出来。同时发生会显得轻，滞后反而显得重。

**仙侠版的先到后动**：剑芒先过，石头后错位；雷先闪，雷声后到，落点最后才炸。

### 兵器：先问四件事

写任何持械动作前，先定死：

1. **什么兵器**（剑走线／刀走面／枪走点／棍走片／奇门走变）。
2. **多长**（决定距离，距离定错后面全错）。
3. **哪一段接触**（剑尖、刃口中段、刃根、刃背、棍端、棍尾）。
4. **接触后怎样**（继续通过／卡住／反弹／脱手／被抓住）。

兵器账本五项：谁握、哪只手、刃／尖朝向、状态、位置。见 `wuxia-weapon-grammar.md`。

**仙侠线的兵器要加两项**：剑芒多长（一寸／一尺／三尺／丈许）、法宝祭炼到几成。见 `spirit-light-and-blade-glow.md`。

### 轻功与御空：五个锚点

```text
起跳面 → 方向与弧线 → 中继接触点（可无） → 落点 → 恢复姿态
```

**中继点可以没有，起跳面、落点、恢复姿态三样必须有。** 被踩的东西必须有反应（墙落灰、竹弯再弹、瓦翻起、肩沉半寸）。落地必须卸力（屈膝／滑步／踩碎／翻滚，至少两样）。见 `qinggong-and-airborne.md`。

**仙侠的御空把「起跳面」换成「承载物」**：剑、云、气纹、阵纹。腾空不需要蹬地，但必须看见「托着他的东西」，以及每次加速时的气纹与衣袍受压。

### 交锋：四阶段

每一个有意义的交锋都按这个结构写，不要写成一串没有因果的招式：

```text
起势 rise   —— 立距离：架势、前脚、护手、兵器线、地形、对方的空门
承载 carry  —— 投入一个主威胁：明确的起点、路径、目标
转折 turn   —— 对方的具体答案：格、让、退、压、绞、引、借地形／打断施法
收束 close  —— 后果与恢复：新架势、距离变了、失衡、衣破兵损、下一拍的空门
```

**一次交锋只放一个主动作，最多加一个接续。** 快速连击也要在两次动作之间写出可读的换线。

**仙侠线的转折多一种答案：打断。** 打手（印散）、打物（符毁剑偏）、打身（反噬吐血）。见 `spell-and-ritual.md` 第四节。

### 法术：六段（仙侠线专属）

```text
起诀 → 引灵 → 凝形 → 释放 → 生效 → 收势
```

六段总时长约 **1.4–4 秒**。这个数字决定了一场能放几次、能不能被躲、能不能被打断。**仙侠的张力全在「他快放出来了，你来不及了」。**

前摇（telegraph）至少写两种载体：手（结印）、物（符纸自燃／剑鸣／铃响）、天（云聚／风停／烛火同偏）。见 `spell-and-ritual.md`。

### 仙侠特效逐拍公式（仙侠线强制）

仙侠线上每一处术效拍点（施法、释放、命中），成品句子必须按八段顺序写全，缺一段就是没写完：

```text
镜头机位 + 人物 + 锚点 + 技能 + 粒子 + 光效 + 撞击位置 + 物理反馈
```

| 段 | 写什么 | 缺了会怎样 |
|---|---|---|
| **镜头机位** | 机位高度＋景别＋焦段观感＋运镜，交代「哪个镜头在看这一拍」 | 观众没有观察立足点，尺度失真 |
| **人物** | 谁在施法／出招：身份锚点＋可见施法动作（结印／掐诀／御剑姿态） | 光与动作脱钩，人在给特效当背景 |
| **锚点** | 力的载体＋空间参照：剑身／符纸／阵纹／掌心，加一个环境地物 | 光凭空出现（即缺「源」「载」） |
| **技能** | 术的族别与形态：剑芒几尺／雷法／五行／禁术，量级匹配本境 | 形与量说不清，破坏没有上限感 |
| **粒子** | 粒子的「生成—行为—消散」：石屑沿切线炸起、光尘悬停半秒、符灰上飘 | 术没有质感，像一层贴图 |
| **光效** | 形、色（一场一套对立色）、量、时长，且必须落在环境上 | 光悬在半空，不照亮任何东西 |
| **撞击位置** | 精确命中点：哪个部位／哪根柱／离地几米／哪块地砖 | 接触点不可读，不知道打到了哪 |
| **物理反馈** | 碎片方向、冲击波、人体位移、地面开裂、攻击者反作用、环境滞后 0.1–0.3 秒 | 打了像没打，力度是空的 |

示例（一句完整的八段句）：

> 「低机位仰拍（离地 0.9 米，18mm 广角缓推），青袍剑修掐剑指上挑——锚点：剑脊中段凝出三寸青芒，脚下青石板纹路微微亮起作力源参照——剑芒三尺斜劈；粒子：芒过处石屑沿切线炸起，细碎光尘悬停半秒才灭；光效：青白单色，映亮左侧廊柱并勾出他半张脸，亮起到收束共 1 秒；撞击位置：右前方第三根廊柱离地 1.2 米处；物理反馈：柱身平整切口，上半截晚 0.2 秒滑落砸起尘土，剑修收势后脚蹭退半寸。」

与特效八件的对应：**源／载 → 锚点＋人物；形／量／色 → 技能＋光效；光 → 光效；破 → 撞击位置＋物理反馈；影 → 镜头机位**。粒子是公式新增的一项，必须写「生成—行为—消散」三步，不许只写「火星四溅」一笔带过。逐拍公式管单拍怎么写，法术六段管一个大术的时间结构，两者叠加使用。

### 能量实体化：把术写成道具（仙侠线进阶）

过了八段公式之后，一段高级的仙侠术效还要再过五道工序。全部提炼自实战验证过的出片提示词：

1. **能量道具化**：给能量一个实体形态（鞭／弦／纱／锁链／水流），然后用兵器语法写它——鞭就按鞭法写（抡、扫、提、砸、缠、绞）。能量一旦有了道具形态，就要遵守兵器账本：粗细、长度、怎么运动、缠在哪、怎么解。例：「手腕粗、数十米长的青白雷电长鞭」。
2. **能量生命周期**：成形 → 携行（随身体运动、被惯性甩出）→ 压缩蓄力 → 释放 → **回收或转移**。释放不是终点：能量去哪必须交代——吸回拳心、灌入地面、残留在断肢上继续乱跳。压缩蓄力要写成**身体动作序列**（小指先扣、无名指跟上、拇指最后压住拳面），不许写「力量汇聚」。
3. **粒子受力逻辑**：粒子写「受什么力、怎么回应」——被惯性向后猛扯拉成长线、下一瞬弹回勒住手臂；时而分叉、时而断裂、再重新接上。四溅是死粒子，有受力逻辑的才是活粒子。
4. **撞击前兆两层**：拳未到，震纹先到（拳锋前方挤出肉眼可见的环形震纹）；对方先反应（胸甲和衣摆被拳风与电流冲得后扯）。力场先于接触到达画面，这是「先到后动」的镜像用法。
5. **静场信号**：爆发前写 0.3–0.5 秒的突然安静——「仿佛所有声音都被吸进了拳头里」。安静本身就是最大的前摇。

物理反馈可以扩到第四层——**摄影机也是受击者**：短促过曝、电流噪点、取景边缘被雷光照亮、被震波推得微微偏移、被正面冲击顶得后仰失稳。关键重击给一层摄影机反馈，现场感立刻翻倍。

反震要**按量级分配**：两拳对撞，双方反应各按力量差写——一方滑出七八步、双脚犁出长痕，另一方被横向抛飞翻滚数圈。两边动作幅度一样大的对撞是假的。

伤害与能量联动：能量不凭空消失。断肢带着未释放的雷核飞上高空拖出电尾，断口内部电弧继续乱跳——后果画面里必须能找到前面注入的能量。

### 血肉与断肢：暴力要有真实的后果（两线通用）

- **血肉是后果，不是装饰**：每处血都要能回溯到「谁、用什么、切在哪个解剖位、什么角度」。写不出这四样，就是泼颜料。
- **打结构，不打「身上」**：不写「砍中肩膀」，写「从腋下与肩窝之间切入，沿肩关节向上斩出去」。每次伤害至少写三样：切入口、断开的东西（骨／筋／关节）、身体失控的方式（哪一段先不听话）。
- **断肢三段**：切断帧（清楚、完整、爆裂，一两帧不回避）→ 断肢去向（轨迹＋携带物，断臂带雷核飞上高空像流星）→ 断口后续（喷血、骨茬、能量乱跳、跨镜不复原）。
- **血的物理**：方向服从刃口（往下挑就往上斜喷）、旋转带离心弧线、晚半拍、有量有落点、血雾接住后续剪影。
- **血腥分级跟剧情走**：轻（血线渗血）／中（喷溅、入肉见骨）／重（断肢、腰斩、内脏）。剧本已写明断臂、腰斩的，直接按重档写足，不许写软；剧情未定时默认中档。重档一场只给一次、给决胜击。
- **处置链**：缴械 → 折断 → 抓取 → 抡转 → 抛投 → 补杀 → 收兵器 → 残躯落地。力量差不用形容词，「把人抡起来转圈」本身就是量级宣告。

解剖六处的伤害后果表、能量创口五型（雷／火／冰／剑芒／毒）、黑名单替代写法见 `references/blood-and-gore.md`。

### 法阵：三要素

```text
阵图（地上的纹路） + 阵眼（可被攻击的核心） + 阵旗／节点
```

**阵眼必须在画面里。** 观众知道「打那里就能破」，紧张感才成立。布阵四段：落旗 → 连线 → 合拢 → 启动。法阵是全片最慢的招，所以必须有人掩护、或在挨打中完成、或提前布好。见 `formation-and-array.md`。

### 符箓与法宝：道具账本

符是子弹，法宝是伙伴，丹药是暂停键。三样都要记账：谁有、用了几次、还剩多少、坏到什么程度。**符说有就是有，说三张就是三张。** 见 `talisman-and-artifact.md`。

### 光：三条纪律

1. **光必须有载体**（剑、符、印、阵纹、掌心），不许凭空出现。
2. **光必须落在环境上**（照亮半张脸、映在湿石板、投出长影、穿过雾成光柱）。
3. **光不能盖住接触点**，接触帧的光要缩到轮廓级。

一场只有一套对立色。剑芒长度是境界的可见刻度。见 `spirit-light-and-blade-glow.md`。

### 破坏：七级，只增不减

1 微动（衣发、烛火、尘、水面细纹）→ 2 表面伤（瓦碎、木裂、衣破、皮开）→ 3 局部断裂（梁断、门飞、竹倒）→ 4 结构塌陷（屋顶塌、棚垮）→ 5 地形改变（石阶崩、地面陷）→ 6 山体与地貌（削平山头、断流、裂谷）→ **7 天象（云散、落雷成域、方圆数里改观）**。

**一场只允许一次七级、一次六级。写实武侠顶格到 3 级，高武到 5 级，仙侠到 6 级，仙侠大片才给 7 级。** 残骸与灵光余烬必须记账并留到结尾。见 `destruction-and-environment.md`。

### 留白：不是每一拍都要有事发生

- 武侠线：短打留白 0.5–1 秒，对峙可到 2–3 秒；整段留白总量 ≤15%。
- 仙侠线：留白 20–30%，因为尺度大，观众需要时间看清有多大。
- 留白时**必须有一个仍在动的细节**（衣摆、烛焰、呼吸、飘落的雪、一缕云），否则画面会死。
- 收束的 1–2 秒留给世界：碎瓦滑落、尘土下落、灯笼摇晃、阵纹冒烟。

### 声音：声线绑定必须「音频＋图像」双锚

用户给了声线参考（[音频N]）时，绑定写法固定三段，缺一段就会凭空长人：

```text
① 使用 [音频N] 作为 @角色名 的唯一人声参考
② @角色名（@图N／画面中某特征）——图像锚点必须同句出现
③ 此声音仅绑定画面中的某角色，不新增人物、不新增第二个声源
```

**只给音频不给图，是最常见的翻车点**：声音没有脸，模型会给它配一张新的。图像锚点可以是 `@图N`，也可以是「画面中蓝袍老者」这种可辨识特征。

**引用名要唯一**：素材库同时有「藏医」和「藏医2」时，@ 会自动挂到带序号的那个；先改名去重（藏医-老年／藏医-青年），再在成稿里回读一遍实际插入的标记，不要凭手输。

|---|---|---|---|---|---|
| 写实武侠 | ≤3 次/15s | 不用 | 无 | ≤2 次/15s | 3 级 |
| 高武 | ≤4 次/15s | ≤1 次/全片 | ≤0.5 秒/次 | ≤2 次/15s | 5 级 |
| 写意飘逸 | 不用 | ≤2 次/全片 | 无 | ≤1 次/15s | 3 级 |
| 仙侠 | ≤4 次/15s | ≤1 次/全片 | ≤1 秒/次，≤2 次 | ≤2 次/15s | 6 级 |
| 仙侠大片 | ≤3 次/15s | ≤2 次/全片 | ≤1.5 秒/次，≤2 次 | ≤3 次/15s | 7 级 |

**抽帧只给重击，升格只给决策空隙。** 仙侠的升格最好给「将触未触」或「术成未发」。详见 `impact-budget.md`。

## 默认摄影与节奏基准

- 开局用中景或中远景，让观众先知道距离、屏幕方向与地形。**仙侠开局用大全景**，先给尺度。
- 一次投入的推进用跟移；侧步与换线用短暂横移。
- 碎片剪辑必须保留一个**方向锚点**（运动方向、固定地标、对手肩线、兵器轴线、阵纹走向）。
- 用竖直硬边（柱、门框、墙缝、光柱）做深度参照，让「退了两步」在画面上可测量。
- 人物的头发、衣摆、裤脚要跟着动作甩起来，且**比身体晚 0.2 秒**停下。仙侠的宽袖与剑穗更明显。
- 镜头可以偶尔跟丢更快的那个人；重新找到时，他已在下一个动作里。
- 45 秒的片子只需要三个完整可读的标志性招式，其余用局部、遮挡、撞击与后果表达。
- **仙侠的法阵必须有俯拍全景**：观众要看得懂阵的形状与阵眼在哪。

## 输入整理

拿到用户输入后，先抽出这些（缺的按默认填，并在开头一句话说明所用默认）：

1. **线别与档位**：武侠线／仙侠线；写实武侠／高武／仙侠／仙侠大片。没说 → 写实武侠。
2. **境界与机动等级**：仙侠线要定境界（决定真元预算与术的规模）；两线都要定等级（能不能飞）。没说 → 等级 3~4；仙侠线默认金丹、等级 5~6。
3. **人物与兵器／法宝**：几个人、谁打谁、各持什么、有什么法宝符箓、谁占优。
4. **事件**：必须发生的事与必须不发生的。
5. **空间**：在哪、地形材质、退路、可用物件、有没有可布阵的地面。
6. **时长与画幅**：默认 15 秒、16:9。
7. **有没有内力／法术、有没有喊招／念咒、要不要配乐**。

## 快速通道

用户只给一句「两个人在客栈打」时，不要反问，直接按默认出稿：**武侠线 / 写实武侠 / 等级 3~4 / 徒手或随手兵器 / 15 秒 / 一镜到底或 7 镜 / 无光效 / 破坏顶格 2 级**。开头一句话说明这些默认值。

用户只给一句「两个修士打」时，按 **仙侠线 / 仙侠档 / 金丹 / 等级 5~6 / 15 秒 / 破坏顶格 5 级 / 全屏光 ≤2 次** 出稿，并默认给一次「差一点被打断」的施法。

**用户提了法术、符、阵、法宝，就不要再问「要不要光效」——那是他点的东西。** 要问的是「有没有代价」。

## 统一工作流

### 1. 分线、定档、定境、定级

先写一行抬头：

```text
武侠线 · 写实武侠 / 机动等级 3~4 / 破坏顶格 3 级 / 无光效
仙侠线 · 仙侠 / 金丹 / 等级 5~6 / 真元 10 团 / 破坏顶格 5 级
```

这一行是后面所有的约束。

### 2. 建立账本

- **事件账**：E## 必须发生的事。
- **人物账**：谁握什么、哪只手、什么状态；仙侠线加真元余量、符数、法宝损耗。
- **空间账**：地形、障碍、退路、可用物件（最多两个）、可布阵面积。
- **道具账**：符几张、丹几颗、法器几件、阵旗几面。

### 3. 选时间粒度

纯打斗按 0.5 秒列格，15 秒 = 30 格。有对白的段落按 2–3 秒一块，不套打斗粒度。

**仙侠要注意跨格**：一次大术会跨 3–8 格（六段），不能挤在一格里写完，也不能平均铺满。

### 4. 写成四阶段交锋

每 2–4 格一个交锋：起势 → 承载 → 转折 → 收束。相邻两个交锋之间要有**状态变化**（距离、伤势、兵器、位置、真元），不能原地重来。

### 5. 设计镜头

一次交锋一到两个镜头。开局宽，接触近，收束拉远。碎片剪辑保留方向锚点。仙侠记得给法阵俯拍。

### 6. 分配资源

按弧线分配打击层级：试探／有效击／压制／反转／决胜。抽帧给重击，升格给决策空隙，留白给呼吸。**仙侠的决胜通常是一次大术，所以前面必须预留它的前摇时间。**

### 7. 保持连续性

人物位置、朝向、距离、伤势、兵器状态、脚下条件、残骸、真元余量、符数、法宝损耗、阵纹位置，全部继承。**没有任何一项可以在切镜后自动复原。**

## 输出格式

内部完成 A 层规划与检查；默认向用户展示简短说明和 B 层完整提示词。

### 默认必须交付完整提示词

用户要求设计、编写、改写或补全打斗时，除非明确说「只要规划表」「只要分镜」「只要动作提纲」，最终答复必须包含一份可直接复制的**完整成品提示词**。

完整成品提示词必须满足：

- 使用下方 B 层全部字段，正文写全场景、人物与兵器锚点、线别档位与境界、空间、画幅/时长、光学与手持状态、连续运镜路径、动作时序、内力或法术体系（写实档写「无」）、力学与打击、破坏账本、连续性、光线、声音和正向约束。
- 纯打斗按 0.5 秒逐格写入 ACTION TIMING；15 秒必须在成品内完整保留 30 格，不得用「按上表执行」概括。
- 一镜到底需求必须写明：单个连续无剪切镜头、摄影机起点/路径/景别变化/落点、节拍间连续连接、禁止切镜与瞬移。
- 成品使用自然、连续、可执行的语言；保留逐格时间码，但移除内部 ID、文件路径、事件编号和检查标记。

### A. 动作与镜头规划表（内部）

```text
| 动作格 | 时间 | 来源E/B与约束S | 招式原词/ACT-ID | 内力或法术原词/QI-FA-ID | 兵器·法宝与部位 | 成品可见动作与线路 | 对手回应与受力结果 | 破坏等级/残留 | 下一格接口 | 镜头号 |
```

归并镜头：

```text
| 镜头 | 覆盖动作格/时间 | 时长 | 景别原词与焦段 | 机位高度 | 运镜原词/ID | 起点—路径—落点 | 内力·法术与兵器状态 | 切点接口 |
```

### B. 成品提示词

```text
SCENE CONTEXT
FIGHTER AND WEAPON ANCHORS
LOCATION AND SPATIAL BLOCKING
FORMAT MODE
OPTICS / CAMERA
SHOT RHYTHM
ACTION TIMING
QI AND TECHNIQUE SYSTEM
FORCE AND IMPACT
PHYSICS AND CONTINUITY
DESTRUCTION AND ENVIRONMENT
LIGHTING
AUDIO
POSITIVE CONSTRAINTS
```

字段说明：

- **SCENE CONTEXT**：第一句就声明**线别 + 档位 + 境界（若有）+ 机动等级 + 破坏上限**。例：`仙侠线，仙侠档，金丹，机动等级 5~6，破坏顶格 5 级`。整场锁死。
- **FIGHTER AND WEAPON ANCHORS**：一人一句——身份、外观锚点、打法（一种主兵器或空手 + 一个战术偏好 + 一个弱点）。兵器写明类型、长度、握法、刃/尖朝向。仙侠线补：本命法宝、符数、真元厚薄。不写心理解释。
- **QI AND TECHNIQUE SYSTEM**：**这一段是两线的主要分界。**
  - 武侠线：有没有内力、气劲形态（掌风/剑气/气环）、颜色、起势方式、行气路径、接触形态、消散方式、代价。写实档只写「无光效，劲只体现为尘土、碎石、衣料与呼吸」。
  - 仙侠线：改写为**法术与法宝体系**——本场用哪几族术（剑诀／五行／雷法／符箓／法阵／禁术）、灵光的形与色、剑芒几尺、符几张、法宝几件及祭炼几成、真元总量与已耗、施法前摇的方式、打断规则、代价清单。
  - 整场说一次，不在每格重复。
- **FORCE AND IMPACT**：本场打击感的交付方式——接触帧怎么写、后果持续多久、攻击者的反作用是什么、破坏推进到几级、抽帧与升格各几次、全屏光效几次各多久。
- **PHYSICS AND CONTINUITY**：轻功或御空的锚点规则、滞空上限、兵器账本五项、伤势累积、脚下条件；仙侠线加符数／丹药／法宝损耗／阵纹位置。
- **DESTRUCTION AND ENVIRONMENT**：破坏账本，按时间顺序记录「哪一格破坏了什么，之后一直保持」；另写 1~2 个环境战术元素。仙侠线要写阵纹烧痕与灵光余烬。
- **LIGHTING**：主光方向、色温、法术发光如何改变照明、破色是什么、占多少。写实档不写发光。
- **AUDIO**：破风 → 接触（金属／肉体／内力／法术四种音色要分开）→ 余振 → 环境余响；有没有喊招或念咒、有没有配乐。
- **POSITIVE CONSTRAINTS**：只写正向约束（保持可读、保持档位一致、保持兵器几何），不堆否定词去禁用用户明确要的效果。

## 默认写法

- **线别与档位先声明**：成品开头或说明里必须有一句写清线别、档位、境界与等级，否则读者无法判断这一段的分寸。
- **伤势直述**：用户已指定或明确授权时，可直接写「手臂骨折」「额角破口」「衣襟见血」，不必一律改成模糊暗示。未授权时不主动升级伤势。
- **受击反应比攻击动作更具体**：写形变、脚步、呼吸、失衡和延迟反应。
- `fast`、`powerful`、`quickly` 不单独承担速度信息；给出时间、距离或画幅占比。
- **风格名称只在用户要求时转译**为可见参数：光线、色彩、构图、镜头行为和材质。
- 用竖直硬边（柱、门框、墙缝、裂缝、光柱）做深度参照。
- 人物的移动、头发、衣摆、裤脚要跟着动作甩起来；静止的衣物会让动作变成摆拍。
- **胜负由可见结果决定**：谁被推得更远、谁的兵器先脱手、谁先喘、谁先退、谁的法宝先暗、谁的真元先空。不写「他更强」，写「他退了半步」「他的剑芒缩了一尺」。
- **留手要可见**：能杀而不杀，必须有一个具体动作（剑尖停在咽喉一寸、转身不追、收刀入鞘、只放一寸剑芒因为身后是凡人）。只写「他手下留情了」等于没写。
- **代价要可见且累积**：仙侠的第三次施法必须比第一次小、慢、抖。

## 交付前硬检查

1. **线别是否定死**？武侠线里有没有偷偷出现法术、符、阵、法宝？
2. **档位是否定死、全场是否一致**？有没有中途升档或降档？
3. **境界与真元预算**是否成立？有没有连放五个大术还站得稳？
4. **机动等级**是否一致？仙侠的离地有没有承载物（剑／云／气纹／阵）？
5. 每个镜头能否追溯到用户事件 `E##` 或状态 `S##`？原创动作是否在授权范围内？
6. 是否擅自改变人物关系、兵器、伤势约束或结局？是否擅自添加门派、道统、法宝与招式名？
7. 时间码是否完整，总长是否正确（15s 必须 30 格）？
8. **每次攻击是否写出了力的来源**（武侠：支点／推进／蓄势／代价；仙侠：真元／法宝／阵法／地脉）？
9. **每次命中是否有可读接触帧 + 0.3–0.5 秒后果 + 攻击者反作用**？
10. **是否先接触、后反应**？环境反应是否晚 0.1–0.3 秒？雷声是否晚于闪光？
11. 兵器类型与动作是否匹配？有没有刀走直线刺、长剑大幅劈砍？
12. 兵器账本五项是否成立？换手、拾械、弃械、飞掷、出鞘、收鞘是否都写了过程？
13. 轻功五锚点是否齐全？滞空是否超出等级？落地是否卸力？
14. 每次交锋是否是四阶段结构？有没有变成没有因果的招式串？
15. **法术是否有六段**（起诀／引灵／凝形／释放／生效／收势）？有没有省略「形」与「后果」？
16. **前摇是否写了至少两种载体**（手／物／天）？观众能不能提前看出他要放大招？
17. **有没有一次施法被打断或差一点被打断**？打断是否发生在凝形之前？
18. **每次大术是否还了代价**？代价是否累积（第三次比第一次小、慢、抖）？
19. **符数／丹药／法宝损耗是否记账**？有没有用完了又掏出来？
20. **法宝有没有三属性**（祭炼／灵性／损耗）？对轰时是否写了「谁的宝光先暗」？
21. **法阵是否三要素齐全**（阵图／阵眼／阵旗）？阵眼是否可见、可攻击？布阵四段是否写了？
22. **阵内规则是否有可见症状**（脚步变慢／符纸点不着／皮肤浮红线）？有没有只写「受到压制」？
23. **灵光是否有载体、是否落在环境上、是否让开接触点**？
24. **剑芒长度是否与境界匹配**（一寸／一尺／三尺／丈许／数丈）？
25. 一场是否只有一套对立色？有没有每个法术换一种颜色？
26. 破坏等级是否只增不减、方向服从受力、材质匹配？残骸与阵纹是否留到最后？
27. 是否有留白（武侠 ≤15%、仙侠 20–30%）？留白时是否有一个仍在动的细节？
28. 次级运动是否有延迟（人停了，衣摆还走 0.2 秒）？
29. 抽帧／升格／全屏光效是否超配额？抽帧是否只给重击？
30. 击退方向是否有空场？起点与落点是否重合？
31. 伤势是否累积并影响功能？有没有自愈？
32. 人物位置、朝向、距离、兵器状态、内力或真元余量、符数、法宝状态是否连续？
33. 是否仍用笼统评价替代动作（剑光如虹、招招致命、仙气飘飘、法力无边）？
34. 运镜是否服务于动作和可读性？碎片剪辑是否保留方向锚点？法阵是否有俯拍全景？
35. 结尾是否给了句号（武侠：收剑／抱拳／转身；仙侠：御剑而去／留一物／留痕不留人）？
36. 成品是否已移除内部 ID、文件路径与检查标记？

检查摘要应简短：线别与档位、境界与真元预算、时序格数、使用的招式／内力／法术／运镜原词出处、破坏推进到几级、主要连续性结果、尚未验证的成片效果。不要把整张检查表塞进提示词。
