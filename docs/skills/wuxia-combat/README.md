# 武侠 · 仙侠 打斗 · Skill 包

为东方武学与修真斗法设计、改写、转译分镜与视频提示词。**一个 Skill，两条线，先分线再定档。**

| | 武侠线 | 仙侠线 |
|---|---|---|
| 档位 | 写实武侠（默认）→ 高武 | 仙侠 → 仙侠大片 |
| 力的来源 | 身体 + 体内内力 | 真元 + 灵气 + 法器 + 阵法 |
| 时间结构 | 一瞬间的接触 | 前摇 → 释放 → 生效 |
| 代价 | 呼吸、手抖、力竭 | 真元、精血、寿元、法器、经脉 |
| 破坏上限 | 0.3 ~ 2 米（顶格 5 级） | 12 米 ~ 数千米（顶格 7 级） |

**默认写实武侠**：无光效，劲只体现为尘土、碎石、衣料与呼吸。用户没点名，不许发光、不许飞、不许放术。

## 三条底线

1. **线不串、档不越级** —— 武侠线没有法术、符、阵、法宝；仙侠线每一术都要有来源与代价。
2. **力有来源** —— 武侠：支点／推进／蓄势／代价至少两样；仙侠：真元／法宝／阵法／地脉／借力，且在句子里写出来。
3. **先接触，后反应** —— 命中顺序永远是「身体／兵器／法术先到位 → 环境反应晚 0.1–0.3 秒才起来」；雷法是「先闪、后声、再炸」。

第 3 条是招牌：刀砍进柱子，木屑晚半拍才炸开；剑芒先过，石头后错位。同时发生会显得轻，滞后反而显得重。

## 先定三件事，再动笔

**分线**（力的来源在不在身体里）、**定档**（有没有光）、**定级**（能不能飞）是三件独立的事：

| 档 | 线 | 特效 | 破坏量级 | 触发词 |
|---|---|---|---|---|
| 写实武侠（默认） | 武侠 | 无 | 0.3 米级 | 只说了「打」「武打」「武侠」 |
| 高武 | 武侠 | 掌风、剑气、气环 | 1~2 米级 | 「内力」「气劲」「真气外放」 |
| 仙侠 | 仙侠 | 灵光、符箓、剑芒、法阵 | 12 米级 | 「灵力」「法术」「御剑」「符」「阵」「法宝」 |
| 仙侠大片 | 仙侠 | 法相、光柱、领域、天象 | 120 米 ~ 数千米 | 「法相」「天地变色」「渡劫」 |

机动等级 1~12：1~2 全程地面，3~4 滞空约 0.9 秒（**空中只能打一下**），5~6 踏墙借力，7~9 飞行，**10~11 御剑／凌空虚渡，12 缩地成寸**。仙侠的离地必须有承载物（剑／云／气纹／阵）。

仙侠线还要定**境界**（炼气／筑基／金丹／元婴／化神以上），它决定真元预算与术的规模——成品里不出现境界名，只出现后果。

## 三条线的关系

| 包 | 档位 | 特征 |
|---|---|---|
| `realistic-close-combat` | 写实 | 无特效、只打近身，破坏低 |
| `superpower-energy-combat` | 超人 | 能量束、破坏五级、对波五拍 |
| **`wuxia-combat`（本包）** | **武侠 → 仙侠** | **有两条线 + 档位旋钮**，默认最保守；轻功、兵器、法术、法阵是主角 |

同一句「两个人在客栈打」：写实版给你一段贴身短打；超能版给带光效的能量对轰；本包先问你有没有内力——没有就给你一段真实到能听见瓦片响的打斗，说了「符」就给你一场有代价的斗法。

## 借鉴来源

**武侠部分**（规则骨架吸收三份公开材料，身体动作库与镜头库为自有）：

- `yipingheijiang/minimax-h3-video-prompt` 的 `traditional-wuxia.md` —— 武侠与仙侠的分界、四阶段交锋（rise→carry→turn→close）、轻功锚点、人尺度后果、不写门派
- `karuvanan/MiniMax-H3-Director-Cut-Studio` 的 `wuxia-blade-film`（MIT，131★）—— 五本账、招式退化成求生、一秒生死、生成预算分级
- `Jojocodex/wushu-action-v7`（HuggingFace）—— 四档风格表、机动与浮空等级表、特效六件

**仙侠部分**（结构借鉴 + 自建词库）：

- **法术六段与施法前摇**参考游戏与动画的「telegraph / wind-up」通用设计原则：任何高伤害动作必须有可读的前摇，玩家／观众才能反应。
- **法阵三要素（阵图／阵眼／阵旗）**参考中式修真题材的通行设定与影视呈现，把"阵"当成有中心、有节点、可被破坏的空间装置，而不是背景光效。
- **剑芒长度 = 境界刻度**是本包自建的换算表，用来替代"他很强大"这类无法拍摄的评价。
- **境界九境与真元团数**为写作预算工具，取自通行的修真境界划分，只用于内部规划，不进成品。
- 86 条法术原词（FA）为本包自建，与内力的 QI 库、身体的 ACT 库同构。

另外参考 90 年代港式武侠的公开写法（先到后爆、抽帧跳格、喊招铁律），只取原则，不复制任何具体镜头。
