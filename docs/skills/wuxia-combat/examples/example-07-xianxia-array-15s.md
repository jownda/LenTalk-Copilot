# 仙侠回归样例：破阵，15 秒

本文件用于验证仙侠 Skill 的**分线、境界预算、法术六段、施法打断、法阵三要素、符与法宝记账、代价累积**，不是所有仙侠打斗的默认招式或胜负。它是规划层样例，保留 ID 便于查验；成品按模板移除 ID 与路径，保留全部半秒时序。

**未生成视频**，不据此声称成片效果已验证。

## 条件与来源

- 模式：原创编排；下表全部为授权内创作拍点 B01 至 B30。
- **S01 线别与档位**：仙侠线 / 仙侠档。**不是仙侠大片**：破坏顶格 5 级（6 级留给"削山"级别，本段不用）。
- **S02 境界与预算**：A 金丹（真元 10 团），B 金丹（真元 10 团）。机动等级 5~6：能踏物借力，**本段不御剑飞行**——两个金丹在阵里打，飞起来就没戏了。
- **S03 人物与道具**：
  - A 阵修，青灰道袍，阵纹青白色。阵旗 4 面（插在四角），玉符 2 枚，无本命法宝。弱点是布阵慢。
  - B 剑修，月白窄袖，三尺青锋（本命剑，祭炼七成），黄符 3 张。弱点是法术只有剑诀一族。
- **S04 场景**：荒废道观前的青石广场，二十步见方。四角各有一面断碑（阵旗插在碑座旁），后方二十米是崖壁，广场中央一道旧石阶。地面是青石板，缝里有草。
- **S05 术的设定**：A 用剑诀？不——A 用**法阵族（FA-47~56）+ 一次杀阵**；B 用**剑诀族（FA-01~12）+ 一张符**。全场只有一套对立色：**A 青白，B 月白**（刻意让两者接近，靠"阵纹是线条、剑芒是刀刃"区分，避免变成霓虹灯）。
- **S06 结局**：B 破阵，A 力竭吐血，两人都没死。这是编排选择，不是默认胜负。
- **S07 预算**：抽帧 2 次（B16 剑芒切旗、B27 斩阵眼）；升格 1 次（B24 血符贴上剑身）；甩镜 2 次；全屏光效 2 次（B18 阵合拢、B27 阵眼炸开），各 ≤1 秒；留白 3 处。
- 法术出处：`references/xianxia-move-library.md`（FA-01/02/04/06/37/38/40/47/48/49/51/52/53/54/75）。
- 身体动作出处：`references/action-move-library.md`（ACT-23/24/38/122/124/223）。
- 镜头出处：`references/camera-move-library.md`。

## 这份样例在验证什么

| 验证点 | 对应格 | 说明 |
|---|---|---|
| **分线与档位不越级** | 全片 | 仙侠档，破坏顶格 5 级（B28），**没有削山**。没有人御剑飞行（等级 5~6 只在踏物范围内）。 |
| **法术六段** | B01–B02（剑诀）、B11–B12（玉符）、B23–B25（血符） | 起诀（掐、掏、咬指）→ 引灵（玉符亮、血被吸入）→ 凝形（芒成形）→ 释放（砍出）→ 生效（切断、破裂）→ 收势（芒缩、剑暗）。 |
| **前摇两种载体** | B03（手：掐诀）、B06（物：符自燃）、B11（物：玉符亮） | 观众能提前看出"他要做什么"。 |
| **施法被打断** | B04 | 第三面旗在落地的瞬间被切掉——这是"差一点"，也是全场的转折。 |
| **法阵三要素** | B01/B03/B08/B13/B14 | 阵图（纹路）、阵旗（四面，其中一面歪）、阵眼（玉符残片，悬在离地一尺，**看得见、打得到**）。 |
| **布阵四段** | B01→B13 | 落旗 → 连线 → 合拢 → 启动，跨了近 7 秒，中间一直在被打——**这正是法阵该有的代价**。 |
| **阵内规则可见** | B15/B17/B22 | 锁灵 → 剑芒从三尺缩到一寸；杀阵 → 皮肤浮红线；压阵 → 抬剑要两拍。没有一句"受到压制"。 |
| **符数记账** | B06（剩 2）→ B18（剩 1） | 三张符用了两张，最后一张一直没用——留给观众"他还有一张"的余味。 |
| **法宝损耗** | B29 | 剑脊一道细纹，剑芒暗一层。不是"打完完好如初"。 |
| **代价累积** | B12（额汗）→ B18（嘴角血）→ B25（踉跄）→ B28（喷血跪地） | A 的代价是**逐步**的；B 的代价是精血（B24 手抖）+ 红线（B26 耳后渗血）。 |
| **先到后动** | B09/B10/B27 | 剑芒先过，石屑后喷；碑先错位后塌；阵眼先碎，阵纹后半拍才逐段崩。 |
| **留白与仍在动的细节** | B19 | 0.5 秒，只有一滴汗在走。仙侠的留白比武侠多，但这一场只在最紧的地方留了一次。 |
| **破坏账本** | B05/B09/B10/B14/B20/B28 | 石阶崩角→碑穿孔→碑断→地裂→阶碎→地面下陷五级，全部留到 B30。 |
| **收束留痕** | B30 | 阵纹在、碎玉有微光、石阶断三级。**人还在，地方回不去了。** |

## 本样例刻意**没有**用的东西

| 没用 | 为什么 |
|---|---|
| 御剑飞行 | 两个金丹在阵里打，飞起来就变成空战，15 秒讲不完 |
| 雷法 | 雷法的时序（光→声→爆）很吃时间，一次就要 1.5 秒以上，会把破阵的节奏挤掉 |
| 6 级破坏（削山） | 仙侠档的上限是 6 级，但**能用不等于该用**。这一场的戏在"阵"，不在"山" |
| 法宝对轰 | A 没有本命法宝，硬加会违反"不擅自添加法宝来历" |
| 第三个全屏光效 | 配额是 2 次/15s，用完即止 |

## 成品转换要点

转成成品提示词时：

1. 移除 FA/ACT ID、格号、镜头号。
2. 把"破坏 N 级""真元 N 团"翻成可见描述（石阶崩掉一角、额角见汗、跪下去）。
3. 全局只写一次的东西：**线别与档位（仙侠/仙侠档）、境界（金丹）、机动等级 5~6、一套对立色（青白/月白）、破坏顶格 5 级、抽帧 2 次、升格 1 次、全屏光效 2 次各 ≤1 秒**。
4. `QI AND TECHNIQUE SYSTEM` 段整段用仙侠写法：剑诀 + 法阵两族、前摇靠掐诀与旗／符、剑芒三尺（被锁后一寸、血符后两尺半）、符 3 张、玉符 2 枚、本命剑七成、真元 10 团、打断规则（打手／打物／打身）、代价清单。
5. 逐格保留时间码，30 格一格不少。
6. `AUDIO` 段写清：无配乐；剑鸣、符纸燃烧的"嗤"、阵纹的低频嗡、雷声（本段无）、阵毁时连续的碎裂声；**施法前有 0.3 秒静场**（B13、B27 各一次）。
