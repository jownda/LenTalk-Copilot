# 当前规则回归样例：废墟徒手交锋，15秒

本文件用于验证 Skill 的时间粒度、原词调用与状态延续，不是所有打斗的默认招式或胜负。它是规划层样例，保留ID便于查验；成品按模板移除ID和路径，保留全部半秒时序，将原词转成可见动作与镜头执行描述，名称仅作辅助。未生成视频，不据此声称成片速度或命中表现已验证。

## 条件与来源

- 模式：原创编排；下表全部为授权内创作拍点B01至B30。
- S01：成年男子与成年女子均为受训高手，双方徒手，手中没有物件；15秒全程交锋，无对白、摆拍或定格。
- S02：废墟地面有碎砖，后方有预先可见的朽木隔板；女子起始在画面左，男子在右。摄影机起始在两人南侧，后续沿南侧空地移动，保留交锋方向。
- S03：允许一处风格化飞移和朽木破坏；没有指定胜负，末格延续交手，不额外编写击杀或终局。
- S04：拳臂末端沿单一轨迹形成自然运动虚影，躯干和脚步方向可追踪；手持保留摄影者步伐颠簸、侧倾和转身惯性。
- 招式出处：`references/action-move-library.md` 的「原词索引与出处」及对应家族；ACT-ID均取自该表。
- 镜头出处：`references/camera-move-library.md` 的「景别」「运镜方式」；SHOT/MOVE-ID均取自该表。
- 中文执行写法：`references/chinese-action-writing.md`。不把「快、狠、猛烈」单独作为动作说明。

## 状态延续检查

- 女子左嘴角血痕从B06出现，后续没有复原；B29左肩受击由转肩和换脚延续到B30。
- 男子右颊擦红从B09出现；后肩衣物从B16挂破，裤膝从B26擦破；后续不能复原。
- 朽木隔板先在S02可见，B15受背撞折断，B16仍落板，B28地上仍有断板。破口与人物各自路径清楚。
- 双方一直徒手；拳脚回收、抵挡、受击和位移接续，没有自动加持物、致命结局或定格。
