# 武侠回归样例：雪夜客栈，剑对刀，15 秒

本文件用于验证武侠 Skill 的**定档、兵器语法、轻功纪律与收束**，不是所有武侠打斗的默认招式或胜负。它是规划层样例，保留 ID 便于查验；成品按模板移除 ID 与路径，保留全部半秒时序，将原词转成可见动作与镜头执行描述。

**未生成视频**，不据此声称成片速度或命中表现已验证。

## 条件与来源

- 模式：原创编排；下表全部为授权内创作拍点 B01 至 B30。
- **S01 档位**：写实武侠。**无任何光效**——劲只有尘土、雪粉、衣料、木屑与呼吸。机动等级 3：会轻功，但本段不飞、不腾空出招。
- **S02 兵器和人物**：A 女剑客，青衣，三尺青锋（双刃直身剑），右手持，剑尖始终朝下或朝前；B 刀客，灰袍，柳叶刀（单刃弯身），右手持，左肩有旧伤。两人均受训多年。
- **S03 场景**：雪夜客栈后院。薄雪覆青石板，三根廊柱（左起第二根在 B 侧），两个半满酒坛贴墙，晾衣绳横在两人之间，檐下一盏灯笼。退路：A 身后是院门，B 身后是矮墙。
- **S04 预算**：破坏顶格 3 级；抽帧 2 次（给两次决定性接触）；**不用升格**；甩镜 1 次；留白 2 处（每处 0.5 秒，均有一个仍在动的细节）。
- **S05 结局**：A 留手（点到为止），B 未死，跪在雪里。这是编排选择，不是默认胜负。
- 招式出处：`references/action-move-library.md` 长刃族（ACT-223~230）、冷兵器近身（ACT-114~121）、步法（ACT-122~129）。
- 镜头出处：`references/camera-move-library.md`。
- 中文执行写法：`references/chinese-action-writing.md`。不把「快、狠、猛烈」单独作为动作说明。

## 半秒动作表

刀剑的回收与下一动作可以衔接；防守与步法可以重叠；半秒格不是一次出招配额。同一镜头覆盖多格。

| 格 | 时间 | 招式原词与回应 | 具体画面、可见结果及下一格接口 | 镜头 |
|---|---|---|---|---|
| B01 | 0.0–0.5s | A：拔刀 ACT-228；B：侧步 ACT-24 | A 拇指顶开剑鞘，剑身出来只剩一寸时手腕先转，剑尖自然垂向地面；B 向右横挪半步，刀横在胸前，刀尖略朝下。脚下的薄雪被两人各踩出一小片碎痕。 | J01 |
| B02 | 0.5–1.0s | A：直线刺 ACT-223（点向 B 持刀前臂）｜B：刃背格挡 ACT-230 | A 剑尖前送，只走一条直线，肩几乎没动；B 用刀背斜着一挡，两件兵器相碰一声脆响（`TANG`），雪粒从刀背震落。B 的手腕被震得向外偏了半寸。 | J01 |
| B03 | 1.0–1.5s | B：斜劈 ACT-225｜A：后撤 ACT-23 | B 不退反进，刀从右上斜劈下来，走完整一条弧；A 后脚先撤，整个人退出半步，刀锋从她胸前掠过，带走一片衣角。 | J01 |
| B04 | 1.5–2.0s | A：弧线削 ACT-224（削 B 持刀手腕）｜B：收手 + 侧步 ACT-24 | A 顺着刀的回收期反削，剑走横线，切向 B 的手腕；B 手一收，剑锋擦过他的手背，留下一道细白痕（未破皮）。B 侧步退开，两人重新拉开一臂半。 | J01 |
| B05 | 2.0–2.5s | 留白 | 两人都不动，相距一臂半。**唯一在动的是雪**：一片雪落在 A 的剑脊上，停了半秒才化。B 的呼吸比刚才长了一点。灯笼被风吹得偏了一下。 | J01 |
| B06 | 2.5–3.0s | B：滑步切入 ACT-124｜A：垫步 ACT-122 | B 前脚贴地滑进来，雪被推成一小堆；A 垫步调整到侧面，两人错开半个身位，剑与刀第一次并列在同一画面里。 | J01 |
| B07 | 3.0–3.5s | B：劈砍 ACT-116｜A：交刃压线 ACT-226 | B 举刀直劈，A 双手托剑横架，刃身相压，发出一声较长金属摩擦声（`BLADE SCRAPE`）；两人同时向前压，肩胛都绷了起来。 | J02 |
| B08 | 3.5–4.0s | 交刃相持（第一拍） | 两人刃身相压，谁也不退。A 的剑被压得向下弯了一点，B 的手背青筋鼓起。B 的后脚在雪里轻微打滑，退了半寸。 | J02 |
| B09 | 4.0–4.5s | A：抽刃 + 侧步 ACT-24｜B：刀势落空 | A 手腕一翻把剑抽出来，整个人向右斜走；B 的刀失去支撑向前顿了一下，刀尖扎进地面，扎出一个浅坑。 | J02 |
| B10 | 4.5–5.0s | B：回身横斩 ACT-227｜A：后撤 ACT-23 | B 借着刀扎地的力转身，刀横着扫回来；A 已经在后退，刀锋从她左袖外缘带过，**袖口被划开一道**（破坏 2 级）。布片在雪里飘了半秒才落。 | J02 |
| B11 | 5.0–5.5s | A：后撤 ACT-23（续）｜B：跟进 | A 连退两步，脚步在雪里踩出不整齐的坑；B 不急不缓地跟上来，刀尖一直指着她的中线，不给她重整架势的时间。 | J03 |
| B12 | 5.5–6.0s | B：双手劈斩 ACT-229｜A：刃背格挡 ACT-230 | B 双手压刀狠劈，这一下重；A 抬剑硬接，剑身被砸得弯出一道弧，弹回来时还在抖。她的手背撞在剑柄护手上，擦出一点红。 | J03 |
| B13 | 6.0–6.5s | B：压刀｜A：单膝下沉 | 刀压在剑上不放，B 把全身重量压下去；A 的膝盖被迫弯下去，一条腿几乎落地，靴面陷进雪里。她的剑还在撑。 | J03 |
| B14 | 6.5–7.0s | B：劈砍 ACT-116（落空）｜A：侧让 | A 忽然把剑往外一带，自己向侧面让开；B 的刀失了支撑，整条弧带着人往前冲，**刀砍进左边第二根廊柱**——木屑炸开，柱面裂开一道深口（破坏 3 级）。 | J03 |
| B15 | 7.0–7.5s | 刀的回收期（0.5 秒） | 刀卡在木头里。B 往外拔，第一下没拔动，木屑又被带出来一点。**这半秒就是破绽**：A 已经在动。 | J04 |
| B16 | 7.5–8.0s | A：直线刺 ACT-223（刺 B 左肩）｜B：拔刀 | A 一剑直刺，剑尖钉进 B 的左肩，**衣料陷进去、血渗出一点**（破坏 2 级）；同一瞬 B 终于把刀拔出来，木头崩掉一块。两人同时退开半步——**抽帧一次**（2 帧）。 | J04 |
| B17 | 8.0–8.5s | B：后撤 + 换手调整 | B 退了半步，肩上有血，刀换了个握法（从正握改成更靠后的握），呼吸乱了一拍。他没有看伤口。 | J04 |
| B18 | 8.5–9.0s | B：弧线削 ACT-224｜A：下潜躲闪 | B 咬牙冲上来横削，A 低头，刀从她头顶上方掠过，削掉几根发丝，发丝在灯笼光里飘着落下。 | J04 |
| B19 | 9.0–9.5s | B：膝撞 ACT-09｜A：架 | B 收不住，抬膝顶上来；A 用小臂横架，被顶得后脚离地，后背撞上墙边的酒坛——**坛子裂开，酒和碎片一起泼出来**（破坏 2 级）。 | J04 |
| B20 | 9.5–10.0s | A：滑步切入 ACT-124（借酒滑地）｜B：稳身 | A 顺势踩着泼出来的酒滑出去半步，反而站到了 B 的侧后；B 转身找人，靴底在酒上打了个滑。 | J04 |
| B21 | 10.0–10.5s | 留白 | 两人换位后短暂对峙。**唯一在动的是灯笼**：被刚才的气流带得晃了三下，光影在两人脸上扫过。A 的剑尖重新垂下去。 | J05 |
| B22 | 10.5–11.0s | B：劈砍 ACT-116｜A：交刃压线 ACT-226 | B 先动，刀还是那一下直劈；A 这次不硬接，用剑身侧着贴上去，把刀的力往外引。 | J05 |
| B23 | 11.0–11.5s | A：交刃压线 + 侧步 ACT-24｜B：刀被带偏 | A 顺着刀势向外一步，剑身贴着刀身滑过去，把整把刀带向一侧；B 的上身被自己的力带得前倾，刀已经不在中线。 | J05 |
| B24 | 11.5–12.0s | A：弧线削 ACT-224（切 B 持刀手背）｜B：脱手 | A 反手一削，剑锋从 B 的手背切过；B 的手指一松，**刀脱手飞出去，插在雪里**（破坏 2 级）。**抽帧第二次**（3 帧）。 | J05 |
| B25 | 12.0–12.5s | A：追身一步｜B：空手后退 | A 没有停，向前踏一步；B 空着手后退，抬双臂护住面门，肩膀已经缩起来。刀在两人之间插着，谁都没去拿。 | J05 |
| B26 | 12.5–13.0s | A：直线刺 ACT-223（停住）｜B：僵住 | A 一剑直刺，剑尖在离 B 咽喉一寸的地方**停住**。剑身还在轻微地抖。B 的喉结动了一下，双手慢慢放下来。 | J06 |
| B27 | 13.0–13.5s | 停住（留手） | 剑尖不动。**唯一在动的是 B 的血**：从他左肩顺着袖子往下滴，落在雪上，一点一点洇开。A 的手很稳。 | J06 |

| B30 | 14.5–15.0s | 收束 | 镜头后拉。雪继续落，落在插在院子中央的那把刀上，落在廊柱的裂口里，落在 B 的肩上。灯笼还在轻轻晃。没有配乐，只有风声。 | J07 |

## 这份样例在验证什么

| 验证点 | 对应格 | 说明 |
|---|---|---|
| **定档不越级** | 全片 | 写实武侠，无光效；最强的破坏是廊柱裂开（3 级）。没有任何人飞起来。 |
| **兵器语法** | B02/B04/B07/B12/B23/B24 | 剑走线（刺、削）、刀走面（劈、横斩）；交刃压线是「绞」；刃背格挡有明确部位；刀砍进柱子后会卡住。 |
| **先到后动** | B14/B16/B19 | 刀先砍进柱子，木屑才炸开；剑先刺进肩，血才渗出来；人先撞上坛子，坛子才裂。 |
| **攻击者反作用** | B03/B12/B14/B24 | B 的刀落空会带得自己前冲；A 硬接重劈会被震得手背发红；刀脱手是因为手背被切。 |
| **抽帧配额** | B16/B24 | 两次，都是决定性接触，都只有 2~3 帧。 |
| **留白与仍在动的细节** | B05/B21/B27 | 雪、灯笼、血滴——各自 0.5 秒，都在动。 |
| **受击后先找架势** | B17/B20 | B 受伤后不看伤口、先换握法；A 被撞后踩着酒滑出去反而占位。 |
| **收束句号** | B28–B30 | 收剑、归鞘、转身。这是武侠独有的句号，不是「两人静止对峙」。 |
| **破坏账本** | B10/B14/B16/B19/B24 | 袖口裂→柱子裂→肩伤→酒坛碎→刀脱手，全部留到最后一格还在。 |

## 成品转换要点

转成成品提示词时：

1. 移除 ACT ID、格号、镜头号。
2. 把「破坏 2/3 级」这类标记翻成可见描述（袖口裂开一道、柱面裂开深口）。
3. 全局只写一次的东西：**档位（写实武侠/无光效）、兵器几何（三尺剑、柳叶刀）、抽帧 2 次、破坏顶格 3 级**。
4. 逐格保留时间码，30 格一格不少。
5. `AUDIO` 段写清：无配乐，只有雪、风、金属声、呼吸；两种金属音要分开（脆响 `TANG` 给轻碰，长摩擦 `BLADE SCRAPE` 给交刃，闷响给刀砍进木头）。
