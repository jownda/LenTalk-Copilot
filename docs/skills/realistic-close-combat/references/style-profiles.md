# 打法档案：从“像谁”到“用哪几招”

本文件补的是取词路由的第二关（角色归属）。`action-move-library.md` 有 230 条原词，但“这个人该拿哪 2–3 族”原本没人管，每场都得临场判断。这里给出可以直接套用的档案。

**三份文件的分工**：本文件决定“这个人怎么打”，`action-move-library.md` 提供“这一拍用什么招”，`combo-library.md` 提供“这一串怎么连下去”。

## 使用规则

复杂高速影视需求同时读 `high-speed-screen-choreo.md`。档案用于保持角色辨识度，主战族之外的过渡动作不因数量而禁用；档案中的连打长度、腾空次数与幅度建议不得覆盖用户明确要求的表演复杂度。角色能力、明确的单一风格约束与既定剧情仍优先。

1. **档案是选词配置，不是人物授权**。下文描述的是公开武术体系与银幕呈现的技法特征，用于创作时统一打法，不声称得到本人或其家属认可，也不复制任何具体作品的镜头。
2. **人名不进成品**。提示词里不写“像李小龙一样”“成龙式打斗”，只写可拍的动作与身体状态。这与“招式名是技法名、不是门派名”是同一条纪律：观众要看的是打法，不是标签。
3. **一个角色只用一份档案**，最多在主档基础上借 1 个破招族。中途换档（前三十秒截拳道、后三十秒柔道）必须有剧情理由——受伤、换武器、对手换了距离。
4. **两套档案要对冲**。同档对打会打成镜像：两个人都退着打、都等对方启动，节奏会死。配对表见文末。
5. 档案里标“禁用/慎用”的原词，除非用户明确要求，不要取。那不是“这招不好”，是**这招会让这个人的打法失真**。

## 二、关键词怎么落到档

用户不会按档案编号说话，按下面的说法判档；落在两档之间的，取**距离**更接近的那一档（距离定错后面全错）：

| 用户这么说 | 判为 | 判错的代价 |
|---|---|---|
| “像李小龙”“截拳道”“寸拳”“快、准、打完就走”“截住他” | 01 | 判成 06 就丢掉了腿和截击，变成纯拳击 |
| “咏春”“贴身短打”“黏住不放”“不退” | 02 | 判成 06 会一直后退，人物立不住 |
| “泰拳”“膝肘”“扫踢”“硬碰硬” | 03 | 判成 04 会变成表演式摆腿 |
| “套路”“武术表演”“打得漂亮”“翻腾” | 04 | 判成 03 就少了观赏性 |
| “打不过才还手”“随手抓东西”“狼狈” | 05 | 判成 09 会变得太专业，人物没了 |
| “拳击”“只会拳”“打点”“刺拳试探” | 06 | — |
| “摔”“抱”“地面”“锁住”“降伏” | 07 | 判成 09 会把降伏写成执法按压 |
| “混混”“没练过”“乱打”“抡” | 08 | 判成 06 会打得太干净 |
| “警察”“保镖”“制服”“控住”“押走” | 09 | 判成 08 会写成打人而不是控人 |
| “老拳师”“发劲”“不动”“一推就飞” | 10 | 判成 02 会变成贴身连打，丢了束放 |

**用户已经指定了具体的三五个招式**（例如“刺拳接侧踹接标指”）时，不必先判档：直接按这三个原词反查，出现在哪些档的交集里就取那档，冲突时以距离为准。

## 三、组合指纹

这几个原词连着出现，基本就是这个档，可以据此反查或校验：

| 连着看到的原词 | 判为 | 依据 |
|---|---|---|
| 标指 + 寸拳 + 截腿 / 侧踹 | 01 截拳道型 | 点接触 + 短程发力 + 直线腿，三者同时出现只有这一档 |
| 桥法（沉/留/磨/订/穿）+ 短直拳 | 02 咏春短桥型 | 桥法配寸劲短拳，别的档不用桥法开局 |
| 肘（横斩/上挑）+ 膝（斜切/飞）+ 扫踢 | 03 泰拳擂台型 | 肘膝同段出现且带扫踢控距 |
| 外摆腿 / 后旋踢 / 里合腿 + 大弧线拳 | 04 传统套路型 | 大幅摆腿配转身鞭拳，观赏性配置 |
| 翻滚卸力 / 贴地滑铲 + 横砸 / 棍端戳击 | 05 环境道具型 | 先躲后抓器物，脱困优先于打击 |
| 刺拳 + 后手直拳 + 偏头 / 下潜 | 06 职业拳击型 | 纯拳无腿，防守靠头与身 |
| 抱腿摔 / 大外刈 + 压制 / 十字固 | 07 摔柔压制型 | 摔倒后不下压就是断链 |
| 抡拳 / 砸拳 + 头撞 + 推开 | 08 街头斗殴型 | 大弧线加头撞，动作没有精度 |
| 压臂 / 压肩锁臂 / 掰指 + 膝压 | 09 军警控暴型 | 控住即停，不用重击收尾 |
| 沉桥 / 制桥 + 掌根推击 | 10 老拳师发劲型 | 桥法不为连打，只为一次整身发出 |

反过来：一段里同时出现三个以上不同档的指纹，就是**混档**了，按使用规则第 3 条收回到一档。


## 四、档案卡详解

速查表只给取哪些词；这一节说明为什么，以及这个档最容易写坏的地方。写提示词时不必读全，只读选中的那一档。

### 01 截拳道型（银幕参考：李小龙）

**一句话**：在对手启动的瞬间用最短的线打断，不接不发。

| 项 | 内容 |
|---|---|
| 主战族 | 直线拳 + 直线腿（前手主导，后手少用） |
| 破招族 | 线路防守 + 变线与假动作 |
| 终结 | 标指，或侧踹 |
| 距离 | 中距为主，进出都在 0.8–1.2m 内完成，不贴身缠斗 |
| 节奏 | 截击优先：对方起手的同时己方前手已到，不做“格挡—反击”两拍 |
| 代表原词 | 刺拳 ACT-01、短直拳 ACT-03、寸拳 ACT-42、侧踹 ACT-08、截腿 ACT-62、踢胫 ACT-64、标指 ACT-52、拍挡 ACT-19、拍掌 ACT-54、假刺拳 ACT-16、垫步 ACT-122、滑步切入 ACT-124 |

- **禁用/慎用**：抡拳、转身鞭拳、飞踢、高扫、抱摔、全部地面技。这个人不靠大弧线，也不在地上解决问题。
- **容易写坏**：写成“挡一下再打回去”——那是常规防反，不是截击。截击的关键是**同一个半秒格里，对手的启动和己方的命中同时发生**。另一个坑是标指堆太多，变成指戳表演，一段一次就够。

### 02 咏春短桥型（银幕参考：叶问／甄子丹）

**一句话**：不退，贴着前臂往里挤，用最短行程连续喂拳。

| 项 | 内容 |
|---|---|
| 主战族 | 桥手接触 + 直线拳（短直拳为主） |
| 破招族 | 线路防守 + 掌指打击 |
| 终结 | 寸拳，或标指 |
| 距离 | 贴身 0.3–0.8m，几乎不拉开 |
| 节奏 | 连绵：一拍接一拍，接触不断，靠桥法换线而不是靠退步换线 |
| 代表原词 | 摊手位＝拍挡 ACT-19、伏手位＝拍掌 ACT-54、膀手位＝架臂 ACT-21、短直拳 ACT-03、寸拳 ACT-42、标指 ACT-52、沉桥 ACT-135、留桥 ACT-143、磨桥 ACT-145、订桥 ACT-144、穿桥 ACT-141、踢胫 ACT-64 |

- **禁用/慎用**：大弧线拳、回旋踢、飞膝、主动抱摔。这个人的力气花在中线上，不在幅度上。
- **配额豁免**：这一档是唯一允许桥法占整段一半的档案（其余档按 `action-move-library.md` 默认 2 拍上限），代价是每 2 拍桥法必须夹 1 拍打击或控制，不能纯桥法对练。
- **容易写坏**：桥法连用四五拍，两人手臂搅在一起谁也没打到谁。**两拍桥法之内必须出拳或转控**。另一个坑是让他一直退——咏春是往里进的，退着打就散了。

### 03 泰拳擂台型（银幕参考：托尼·贾）

**一句话**：用腿和膝开路，把对手赶到围绳或墙角，再用肘结束。

| 项 | 内容 |
|---|---|
| 主战族 | 横向腿 + 近身打击 |
| 破招族 | 直线腿（正蹬控距）+ 贴身控制 |
| 终结 | 横斩肘，或飞膝 |
| 距离 | 中距起手，靠膝和肘在贴身结束；进出幅度大 |
| 节奏 | 重拍驱动：每 2–3 拍一次全力，中间用低扫和正蹬控距 |
| 代表原词 | 中段扫踢 ACT-65、鞭腿 ACT-66、低扫 ACT-10、正蹬 ACT-59、膝撞 ACT-09、膝击 ACT-14、飞膝 ACT-78、横斩肘 ACT-74、上挑肘 ACT-75、斜切膝 ACT-79、架颈 ACT-30 |

- **禁用/慎用**：标指、掰指、关节技、地面降伏。这个人是站着的，倒地等于输。
- **容易写坏**：只顾踢腿不管支撑脚，画面变成隔空摆腿；或者每拍都是重击，没有轻拍控距，两秒就喘不上气。

### 04 传统套路型（银幕参考：李连杰）

**一句话**：动作漂亮、幅度大、节奏有起伏，但写实档必须收。

| 项 | 内容 |
|---|---|
| 主战族 | 横向腿 + 弧线拳 |
| 破招族 | 躲闪 + 步法位移 |
| 终结 | 后旋踢，或下劈腿 |
| 距离 | 中距为主，靠大幅度换位制造观赏性 |
| 节奏 | 起伏明显：一串快动作后接一个定势，再爆发 |
| 代表原词 | 外摆腿 ACT-73、后旋踢 ACT-70、下劈腿 ACT-67、里合腿 ACT-178、旋风踢 ACT-71、摆拳 ACT-04、转身鞭拳 ACT-46、侧步 ACT-24、摆身 ACT-27、换架 ACT-129 |

- **禁用/慎用**：**定势停顿、震脚亮相、腾空连击**（单个腾空可留，但要写落地承重，一段最多 1 次）。这一档是唯一需要按 combo-library「△ 到底要收敛什么」四条逐条改的：幅度缩到一肩内、脚不离地、连打只取 2–3 拍、删掉亮相。
- **容易写坏**：直接照银幕节奏写，结果像武术表演而不是打斗。**收完还剩多少，就写多少**，不要为了好看把幅度加回去。

### 05 环境道具型（银幕参考：成龙）

**一句话**：不是最能打，是最会用身边的东西，且挨打之后才爆发。

| 项 | 内容 |
|---|---|
| 主战族 | 躲闪 + 脱离与重置 |
| 破招族 | 短棍钝器（临时器物按此族取词）+ 冷兵器近身通用动作 + 贴身控制 |
| 终结 | 器械横砸，或推倒 |
| 距离 | 忽远忽近：被追时拉开，抓到器物立刻贴身 |
| 节奏 | 挨打—找物—反打三段式，一段交锋只走一轮 |
| 代表原词 | 后撤 ACT-23、侧步 ACT-24、下潜 ACT-26、翻滚卸力 ACT-127、贴地滑铲 ACT-126、抓腕 ACT-28、推开 ACT-37、抽身 ACT-38、横砸 ACT-117、棍端戳击 ACT-118、器械互锁 ACT-119、高位劈打 ACT-205、顶棍压制 ACT-210、抵棍推开 ACT-212、弃械 ACT-195 |

## 五、双人对打怎么配对

同档对打容易镜像，按下表配对能自动产生节奏差：

| A 方 | B 方 | 冲突点 | 要注意的 |
|---|---|---|---|
| 01 截拳道 | 03 泰拳 | 一个要拉开一击脱离，一个要贴身用膝肘 | 让泰拳方不断逼近，截拳道方被迫在劣势距离出招 |
| 02 咏春 | 06 拳击 | 一个不退，一个要维持一臂距离 | 拳击方必须一直退，退到墙角才反打 |
| 07 摔柔 | 06 拳击 | 一个要贴，一个要打点 | 拳击方前两拍占优，被抱到腿之后立刻劣势 |
| 05 道具 | 09 控暴 | 一个找东西，一个只求控住 | 控暴方不追打，用控制逼道具方放掉手里的东西 |
| 04 套路 | 08 街头 | 一个动作标准，一个全是破绽但敢冲 | 套路方的漂亮动作在乱拳下失效，这是本配对的看点 |
| 10 老拳师 | 03 泰拳 | 一个不动，一个不停 | 泰拳方打完一套发现没推动对方，气势反被压住 |

两方都选同族（比如都是拳击型）时，必须在**距离和节奏上分开**：一方抢攻、一方反击，不能两人同时退。

## 六、临时要一份档案怎么办

用户点名的人或风格不在上表时，按三步现配，不要硬套现有档案：

1. **定距离**：这个人是靠拉开距离打（选直线拳、直线腿），还是靠贴住打（选桥手接触、关节控制），还是靠摔倒打（选投技、地面）？距离定错，后面全错。
2. **定节奏**：抢攻型（先出手）、反击型（等对方动）、压制型（不求快求位置）。节奏决定配额怎么花。
3. **定一条禁令**：这个人物绝不做什么？——不跳、不倒地、不追人、不用大弧线、不恋战。禁令比招式清单更能立住人物。

三步定完，再回 `action-move-library.md` 查原词，查不到的标“库外变体”，不自造。
