# 时序、动作密度与镜头节奏

## 两种时序必须实际列出

- 打斗：每0.5s一格，规划表和成品动作段都逐格列出。15s纯打斗覆盖30格，起点为0.0、终点为15.0；不得改写成若干1–2s段落。总长不是0.5s整数倍时，仅末格按实际余量收束。
- 剧情/对白：每2–3s一个时序块。与打斗混合时按段落类型切换，不把对白强塞进半秒，也不把数秒打斗压成一句「双方交手」。尾段余量照实标明。
- 时序格不等于镜头：同镜可覆盖多个连续半秒格；景别和运镜相同可写「续上镜」，但动作推进、反馈和状态变化必须逐格交代。
- 不把「0.1秒出拳」等参数当作生成效果保证。秒数是编排目标；成片速度仍需实际测试，未出片不声称已经解决。

## 每格怎样保持动作压力

每格至少推进一项可见变化：攻击线路、防守回应、接触/落空结果、位移、控制关系、器械状态或落地余势。连续格不能重复「双方对拆」而不产生变化。

先从招式库取原词，再排出因果：当前动作形成的重心、朝向、距离与支撑，使下一格动作能发生。回收与下一击启动可以重叠；受击方头肩偏转、躯干折叠、脚下修正可以和继续防守并行。不把每招写成「准备—出招—站回原位」的串联表演。

半秒格不是半秒必须换招或命中。踢击、飞移、摔撞可跨格：上一格写发起/接触，本格写身体继续位移和追击，下格写落地接防守。不要一格塞入换位、转身、三次踢击、腾空、落地整套动作。

剧情转译只安排用户给定动作与持续状态；信息不足且会改剧情时询问。原创编排允许按用户目标补招。两种模式都不为了填格而改变人物、武器、伤势上限、胜负和结局。

## 默认连续交锋，不设静腔配额

打斗默认从动作中开始，以攻击线、距离和攻守变化区分动作簇。换气通过景别或动作类型变化完成，不自动插入对视、摆架势、喘息特写、定格或站立收势。

用户要求全程不停顿时，冻结、AP、静态插入镜和独立结果停留全部排除；重击反应与碎屑余势在继续移动中呈现，镜头跟住重新进入的下一拍。不要用相机空转代替人物本该继续的动作。

只有用户指定停顿、对白、慢节奏或既定剧情有持续状态时才安排较缓段。旧样片的「两簇一腔」和长余波只供这些情境参考，不是本 Skill 默认节奏。

## 镜头选择

先组织完整动作短语，再分配半秒格并按连续视觉任务合并镜头，最后从运镜库选景别与主运镜原词。半秒不是单招耗时，一格可承载组合内多个短动作；复杂全身动作可跨格。不要先套固定镜长再往里堆招。高速复杂需求同时执行 `high-speed-screen-choreo.md`。

- 贴身拳臂：中景/近景＋跟镜头或移镜头，容纳接触及第一拍反应。
- 腿法、腾空与摔撞：全景＋移镜头或拉镜头，让支撑脚和落点可见。
- 下潜到起身：垂直摇镜头，或真正有机身升降路径时用降镜头/升镜头。
- 方向交接：水平摇镜头或移镜头，用前一格动作引出新方向。

常见镜长只是参考，不能代替半秒动作时序。切点优先保持攻击方向、接触后果与空间连续；不机械要求动作必须完成某个百分比。快感来自格内动作衔接与可见反馈，不靠切点密度或形容词增加。

## 交付前检查

1. 打斗格是否连续、无空缺/重叠，末格是否到达要求时长？15s纯打斗是否30格？
2. 每格能否说清谁在做什么、对手如何回应、上一格留下什么状态？
3. 连击之间是否存在未说明的收势、回位、等对手或静止填充？
4. 每镜是否有库内景别/运镜原词及路径？连续镜头是否跨格保留同一路线？
5. 伤势、左右手、武器和环境破坏是否跨格持续？
6. 剧情/对白块是否与打斗格分开，用2–3s规划？
