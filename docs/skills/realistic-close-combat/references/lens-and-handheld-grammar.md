# 镜头语法与手持纪律

## 以原生运镜库为准

生成前读取 `camera-move-library.md`。本文件补充机身、光学和路径，不另造运镜词条；主文件的半秒时序与用户运动要求优先。

| 路径/构图描述 | 使用的原词 | 注意 |
|---|---|---|
| 跟退、跟移 | 跟镜头 / 移镜头 | 跟随双方共同位移，写摄影者路线。 |
| 前送 | 推镜头 | 是推入幅度与触发描述，不是新名称。 |
| 后拉、拉开 | 拉镜头 | 落点能交代腿法/位移，不默认停住。 |
| 横移 | 移镜头 | 侧向或斜向移动，写主体相对位置。 |
| 上摇、下摇 | 垂直摇镜头 | 摄影机俯仰角变化。 |
| 上抬、下沉机身 | 升镜头 / 降镜头 | 有机身整体升降路径才使用。 |
| 甩镜、绕行、过肩、插入特写、冻结 | 原库登记的LOCAL-01至LOCAL-05 | 见运镜库的本地来源登记，区分移动、构图和强调，不冒充七类外部原词。 |

## 光学与机位

焦段和高度按空间与主体运动选择；原样片的28–35mm全景、50–85mm近景和胸眼高机位仅是参考，不锁死每场。

腿法、飞移、摔撞时用全景留出脚与落点；近景保留接触双方必要关系。机位随下潜、落地或摄影者移动改变时说明路径，不凭空跳高低或换轴。

## 把手持写成可见行为

默认手持，用户要求手持幅度明显时，不以固定微抖频率、极小厘米幅度或平滑追踪覆盖需求。

- 跟镜头/移镜头：摄影者随主体后撤或侧步，产生上下颠簸、侧倾和换脚顿点。
- 水平摇镜头：摄影者跟随转身有过冲与修正，落点继续接动作，不机械停稳。
- 推镜头/拉镜头：机身随摄影者前后步伐起伏；接触瞬间可短震，随后继续原追踪路径。
- 降镜头/升镜头：机身跟随倒地、起身或腾空改变高度，不自动给静态展示镜。

保持主运动方向可追踪。只削弱遮住关键关系的无来源抖动，不把全部手持晃动消除；也不以乱晃或空转替代人物出招。

## 运动虚影与切点

拳头和脚端可在单一轨迹上模糊，用户要快到虚影时不逐帧强求清晰。维持两人身份、躯干/脚步方向和接触后果；武器换手、夺取或脱手等关键状态不能靠模糊跳过。

0.5s是动作时序格，不是切镜频率。一个跟镜头可以覆盖多格连续出招；切点沿未回收动量、人物换位或接触结果接续，不机械按完成百分比切。不要把每次接触都拆成拳头特写。

全程不停顿时不加静态眼神、喘息、冻结或AP；含定格的复合原词不适用时换基础原词，不擅自删组成再保留整条名称。
