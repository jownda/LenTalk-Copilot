# 接触物理

## 适用原则

本文件负责把接触写成可见过程。剧情转译不创建用户未给的攻击/伤势；原创编排可在已定人物、器械、伤势上限与结果内设计接触。两种模式都先从招式库取原词，再补线路和身体反馈。

## 徒手动力链

按需要写出：脚的支撑、腿的传力、髋的转动、肩的送出、肘或手的末端轨迹。不要只写“他用力打”。命中后，攻击者也要遵守重心变化：前倾、收步、重新支撑或被自己的动量带走，具体取决于用户指定的动作结果。

```text
脚蹬地 → 髋转 → 肩送 → 前臂/拳/肘走线 → 接触点 → 受击方形变
```

## 持械动力链

持械动作至少交代：

1. 哪只手握持，手腕和肘部处于什么角度。
2. 武器从哪里起，沿直线、弧线、下压线或推送线运动。
3. 武器接触的是人体、衣物、墙、地面、门框还是其他物件。
4. 接触后武器是继续通过、卡住、反弹、脱手、被抓住还是留在原处。

不要把“刀”写成抽象的威胁；要写刀尖、刀背、握柄和目标之间的关系。不要为了增加紧张感自动添加刺击、割伤或夺刀。

## 作用线与环境

环境响应沿作用线发生：灰尘滑开、水面被推开、门板振动、物件滚动或碎屑落下。只有用户指定或动作直接造成的环境响应才可以加入。环境破坏不是必需项。

## 受击顺序

写实受击通常按以下顺序表现，但不要强行套用到用户没有指定的结果：

```text
接触 → 短暂僵直 → 局部形变 → 脚下失稳 → 呼吸改变 → 延迟护伤或重新支撑
```

推、拉、拖、撞和摔不一定产生“命中僵直”。如果用户描述的是持续推动或被拖走，应写脚跟不上、衣物被拉紧、身体被带走和撞停，而不是凭空添加 hitstop。

## 量化

给出秒数和距离、步数或画幅占比。没有可靠依据时，使用相对量也可以：半步、一个身位、四分之一画幅。数字服务于空间可读性，不得反过来改变用户剧情。
