# 匹配剪辑与连续性

## 切点两类

### 动作匹配

沿尚未回收的动作线选择切点，下一镜从相同位置、屏幕方向和动量继续；不机械套用完成百分比。0.5s是动作时序格，不是剪辑配额，同一动作可跨格，接触与第一拍反应尽量同镜保留。

### 因果咬合

接触完成后切到后果：身体折叠、手松开、武器脱手、门板振动或碎屑落下。下一镜必须仍在展示上一个事件的结果。

## 每一刀回答一个问题

```text
穿过切点的是什么？动作线、视线、声音、物件状态，还是因果链？
```

答不上来就改切点或保留在同一镜中。不要在用户剧情没有蒙太奇事件时切到无关画面制造新意义。

## 连续性台账

每个镜头记录：

- 人物位置、朝向、距离和身体残姿。
- 手上物品、武器握持或掉落状态。
- 伤势、血迹、衣物破损和泥水状态。
- 环境破坏、残留物、灯光和声音层。

剧情转译模式的状态变化回溯用户事件及其直接后果；原创编排模式回溯授权内动作拍点及既定约束。伤势、物品和破坏不得无故复原，不能为了切镜便利重置人物或空间。
