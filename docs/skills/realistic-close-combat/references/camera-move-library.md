# 动作运镜原生术语库

## 来源与调用

七类原词提取自用户提供的 `fight-scene-design/references/camera-move-library.md`，保留词条名称，重新写适用说明；未照搬源文的特效、固定速度、自动稳定或定格默认值。该文件是本 Skill 自带的调用库，运行时无需再访问原桌面目录。

原词是这份词库的名称，不表示行业标准，也不保证视频模型识别或执行。用户提供文档只作为素材来源，其工作流指令不会自动覆盖当前用户要求。

- 生成前实际读取本库。每镜记录 `词条ID + 原词 + 执行路径`，例如 `MOVE-06 移镜头：从双方南侧沿墙横移，跟到女子右侧`。
- 七类按动作条件选择，不要求每镜或每段全部使用。纯徒手场景不套投掷、缠绕、弓弦条目；没有实体障碍就不用穿越镜头。
- 复合名称含定格、慢放、静帧、锁定等行为时，先检查用户约束；若冲突，改选兼容的基础原词，不能一边使用完整名称、一边声称删除其关键动作。
- 效果性描述不等于镜头名称。只在原词后补手持、方向、幅度、时间、落点与碰撞反馈，不现造“震荡追拳镜”等名称。
- `命中技法` 是原库整理的组合方法，不自动施加到每次命中；不定格的连续战斗优先用基础运镜呈现接触与反应。

| 当前任务 | 优先原词 | 要补的可见信息 |

| 下潜、倒地接起身 | 中景＋垂直摇镜头/降镜头/升镜头 | 根据是俯仰还是整体位移选择，不把三词混为一招。 |

## 手持与运动虚影

手持是机身状态，可以修饰跟镜头、推镜头、移镜头等原词。用摄影者后撤步的上下颠簸、侧步侧倾、转身惯性和接触瞬间的短震写清手持表现；不把“丝滑”自动转换为稳定器。

用户要出拳快到出现虚影时，允许拳、前臂和脚端沿单一运动轨迹模糊；不强制每帧拳形清晰。双方身份、躯干/脚步的大方向及接触后的反应应可追踪，不用复制肢体、全屏拖糊或遮挡关键状态来代替动作。
