# 运镜与接触交付

镜头语法（焦段、机位高度、甩镜、过肩、插入、冻结）见 `lens-and-handheld-grammar.md`；节奏与速度的实测数值见 `rhythm-and-motion-baseline.md`。本文件只讲"一次接触怎么被镜头送到观众面前"；运镜原词和ID以 `camera-move-library.md` 为准。文中的前送/跟移等是路径描述，规划时对应推镜头/跟镜头等原词。

## 镜头职责

每个镜头选择一个主要任务：展示动作线、展示接触、展示局部反应、展示位移、展示武器状态、展示空间关系或展示结果。不要为了“电影感”把多个无关任务塞进一个短镜头。

## 运镜句式

每个主动运镜尽量写清：

```text
起点 → 主运动 → 幅度或距离 → 时长 → 落点
```

例：

```text
镜头从她的肩后起步，沿刀柄方向前推 30 厘米，用 0.3 秒落在刀尖与门框的接触点。
```

相邻镜头不必机械反向。若同向，说明它是在延续同一段移动或制造加速；若换向，确保人物动作和空间轴线仍然可读。

## 交付重量的四种方式

普通接触写自然反应即可。肢体末端运动虚影、自然受击反应与手持机身受力可并行；冻结/AP等特殊强调不默认叠用。全程不停顿时不使用冻结/AP，不独立停留展示结果。

### 1. 拖影接触（轻量强调）

用户要拳脚快到虚影时，允许运动末端沿轨迹明显模糊，不强制每帧拳形或接触瞬间锐利；以躯干偏转、脚步修正和相对位置证明动作方向及命中结果。

```text
拳头在画面里留下一道短拖影，接触点落在对手下颌偏左，手和下颌都能看清。
```

适用：用户要求肢体运动虚影的动作。保留身体位置和受击反馈，不用复制肢体或全屏拖糊代替可追踪的动作。

### 2. 受击位移

命中本身只占 2–3 帧，重量交给后面 0.3–0.5 秒：身体退出原构图、退半个到一整个身位、脚离地、撞到墙或柱。

```text
接触后 0.4 秒，他的上身后仰，右脚离地，整个人向后退了半个身位，肩膀撞上身后的柱子。
```

适用：需要显示力量差、或空间要被这一击改写时。位移必须朝作用线的方向，不能横着飘。

### 3. 冻结强调（仅用户允许停顿）

关键一次接触后，镜头和人物一起定住 1.0 秒。世界只保留一个还在动的细节：一缕头发、一次呼吸、衣角回弹。

```text
刀停在他的喉前 5 厘米。两人同时定住 1 秒，只有刀尖极小幅度的颤动。
```

适用：全片一次，放在最重或最险的一击。用两次就失效。

### 4. AP 双锁（仅用户允许停顿）

```text
跟移：镜头同向同速跟完整个攻击行程。
骤停：接触帧猛地停在接触点。
静默：0.1–0.15 秒，镜头和身体同帧短暂停住，只留一个细节继续动。
```

默认不用；用户要求或指定的主观效果确实需要时，每 10 秒不超过 1 次、15 秒不超过 2 次。纪实手持、连续长镜或快速混战时可以少用或不用。

## 不靠慢镜、不靠特效

重量来自四点，写清任意两点即可成立：

1. 力的来源（脚、髋、肩的顺序）；
2. 接触后的**位移**（人动、物动、墙动）；
3. 攻击者自己的失衡（前倾、多走半步、被自己的动量带走）；
4. 一个仍在动的细节（衣角、发丝、灰尘）。

不用慢镜、冲击波、闪光、残影或特效震屏代替重量。原创编排可把腾空、明显飞移或环境碰撞留给少数高潮重拍；写清发力、方向和落点，避免每次命中都给相同的夸张位移。

## 景别与可读性

近景用于接触点、手、武器和伤势；中景用于人物关系和位移；较宽的画面只在交代多人空间或用户指定的空间事件时使用。持械动作需要让握持手、武器末端和目标同时可读，避免用过近特写丢掉作用线。
