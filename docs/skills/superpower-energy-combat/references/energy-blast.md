# 能量轰击

能量轰击是最容易被写成「放烟花」的段落。原因只有一个：**只有结果，没有过程**。本文件把能量攻击拆成可写的阶段，保证每一次都「有来处、有去路、有代价」。

## 1. 六阶段生命周期

任何一次能量攻击，六个阶段缺一不可。

```text
① 聚能  → ② 引导  → ③ 传播  → ④ 相遇/命中 → ⑤ 响应 → ⑥ 消散
```

| 阶段 | 必写内容 | 常见漏写 |
|---|---|---|
| ① 聚能 | 在哪个部位成形、什么形状、周围有什么反应（碎石浮起、衣摆被吸、空气扭曲） | 直接亮，没有成形过程 |
| ② 引导 | 身体/兵器给出方向：转髋、送肩、推掌、指、目光锁定点 | 手一抬就打出去，没有瞄准 |
| ③ 传播 | 束径、飞行时间、尾迹、被照亮的两侧、掠过物 | 出手即到，零传播 |
| ④ 相遇/命中 | 接触点在哪、对手怎么应对（挡、闪、硬接、用构造抵） | 对手站着不动挨打 |
| ⑤ 响应 | 身体四通道 + 破坏等级提升 | 只有光，没有形变和位移 |
| ⑥ 消散 | 光收束、余烟、焦痕、地面残留 | 光一直亮着，不收尾 |

**时间分配参考**（15 秒内的单次轰击）：聚能 0.3–0.8s、引导 0.2s、传播 0.1–0.4s、命中 0.1s、响应 0.3–0.5s、消散 0.2–0.5s。整条链 1.5–2.5 秒。

## 2. 三种载体

### 2.1 束流（Beam）

单向、连续、可以扫。

必写四项：

1. **束径**：拇指粗 / 手臂粗 / 一人宽 / 一栋楼宽。粗细决定量级。
2. **方向与起点**：从掌心出发，还是从指尖、眼睛、兵器尖。
3. **落点行为**：贯穿（打穿并继续）、停住（被护体顶住）、扫过（沿一条线切过去）。
4. **被照亮的两侧**：光打在两人脸上、地上、墙上，方向和强弱要一致。

```text
掌心推出的青白色光束约一人宽，沿地面直推，把地砖犁出一道直线焦痕；
光束在对方胸口前三十厘米处被护体顶住，护体凹成碗形，涟漪向外扩散，青白的光从凹面反射回他脸上。
```

要点：束流最强的地方是**被顶住的那一瞬**，不是打出去的那一瞬。写「顶住」比写「轰出」更有打击感。

### 2.2 弹体（Bolt）

有飞行时间、可以被打掉、可以被闪开。

必写四项：

1. **出手动作**：甩手、弹指、掷出、从背后抽出。
2. **飞行轨迹**：直线 / 弧线 / 变向 / 分裂成多枚。
3. **命中的三种结果**：命中爆开、被挡下、被闪开擦过。
4. **爆开范围**：半径多大，掀翻了什么。

```text
他反手甩出三枚暗红色光点，光点沿弧线绕开正面的护盾，在对手侧后同时炸开，
冲击把地上的碎石整体推向一侧，三米内的积水被压出一个凹坑。
```

要点：**弹体必须有一次「没打中」**。全中会让对手变成靶子，也失去紧张感。

### 2.3 场域（Field）

覆盖一片空间、持续施压。

必写四项：

1. **边界**：球形、柱形、贴地一片、以自身为中心多少米。
2. **覆盖范围**：里面有什么、边界在哪可见（光的薄膜、扭曲的空气、浮起的尘埃）。
3. **内部反应**：里面的人被怎么影响（变重、变慢、被压、被抽能）、物体怎么动。
4. **维持代价**：施法者要保持姿势、要持续输出、不能移动、护体变薄。

```text
以他为圆心半径五米的空气开始下沉，地面的尘土被压得贴平，
对手踏进边界的一步明显变慢，脚下的碎石被压进泥里；
他的右手一直维持着向下的掌势，左肩的护体薄膜薄了一半。
```

要点：场域戏的看点是**代价**，不是范围。范围大而施法者毫无负担，就变成万能技能。

## 3. 对波 / 对冲：五拍

用户要「对轰」「拼能量」「顶回去」时，必须写满五拍，禁止停在相持。

```text
① 蓄力：双方各自成形，强弱要有可见差距（一边亮得更稳，一边在抖）
② 轰出：两个方向的引导动作都可见
③ 相遇：交界线落在画面可读位置（画面 1/3 处、两人正中、偏向一方）
④ 拉锯：交界线向弱势方推移；弱势方给身体反应
⑤ 反推 → 洞穿/战果
```

### 拉锯阶段的必写内容

弱势方必须有身体反应，否则看不出谁在输：

- 支撑脚沿地面犁出两道沟，脚跟在沟底刮出白痕；
- 护体出现裂纹，裂纹从接触面往肩膀扩散；
- 牙关咬紧、颈侧血管凸起、额角渗汗；
- 背后的墙开始凹陷，碎屑从他肩侧往下掉。

### 反推的触发必须具体

不许写「他爆发了，反推回去」。要给一个可拍的动作：

- 换手：另一只手也压上来，光束变粗一档；
- 第二能源：胸口的第二核心点亮；
- 队友供能：一只手从背后搭上肩，能量沿手臂灌入；
- 卸力：主动偏转角度，让对方的力斜着滑出去，然后从侧面打进去。

### 战果

对轰结束后必须有一方付出代价：

- 破防（护体整片碎落）、
- 击退（沿交界线方向飞出，撞穿一层结构）、
- 脱手（兵器被打飞）、
- 过载（手臂灼伤、能量纹路熄灭、单膝跪地）。

**禁止**：对轰结束后双方各退一步、毫发无伤、继续下一轮。

### 四条红线

1. 禁止两条光带僵持不动超过 1.5 秒。
2. 禁止双方同高度、静止、面对面互推持续数秒——会被拍成静态壁纸。必须高低错位（一方悬空、一方踏地）或角度错位（斜向交叉），且至少一方在位移中施法。
3. 大型构造（巨手、兽形、光柱）必须在施法者**体外**、朝向对手；施法者不得被自己的构造包裹（会看起来像自伤）。
4. 相撞后 1.5 秒内必须完成「构造裂纹 → 交界推移 → 一方碎裂 → 胜者触及败者身体」，不许停在相持。

## 4. 蓄力

### 三种蓄力写法

| 写法 | 画面 | 适用 |
|---|---|---|
| 短蓄（0.3–0.5s） | 末端聚出一个小光点，脚下裂一条缝 | 高速片、连招中段 |
| 长蓄（0.8–1.5s） | 周围碎石浮起、衣摆朝反方向被吸、地面环形裂开 | 一张一弛片、决胜前 |
| 边打边蓄 | 近身交锋的间隙往末端补能，一句话带过 | 全程高速片 |

### 蓄力必须有画面任务

不要写「他开始蓄力」。写蓄力**对世界做了什么**：

```text
他左手压住对方的手腕，右手掌心朝下缓缓收拢；
脚下的碎石一颗颗离地半寸，悬着不动，衣摆被从下往上吸得笔直；
掌心那颗光点从指甲盖大长到拳头大，光把他的下颌照亮，眼窝陷进阴影里。
```

### 蓄力与节奏的关系

- 一张一弛片：蓄力段是全片最低速点，之后必须是全片最高速点（差额越大越爽）。
- 全程高速片：不写长蓄力，用边打边蓄；决胜一击允许 0.5 秒的极短蓄力。
- 蓄力被打断是合法的战术：近身贴脸、打断手势、打偏兵器指向。

## 5. 护体与护盾

护体不是无敌，它是一条**可消耗的寿命条**。

```text
受击 → 凹陷/涟漪 → 负荷扩散（裂纹、闪烁、告警声） → 破裂 → 后果延续
```

- **第一次受击**：只凹陷，不裂。给观众看到「挡住了」。
- **累积受击**：裂纹从受击点扩散，边缘开始剥落，光变暗。
- **破裂**：整片碎成光屑，碎片有下落的重量感，不是直接消失。
- **破裂之后**：护体不能再出现，直到明确条件（重新启动、换装、队友补能）。

写法示例：

```text
第二击落下，护盾凹成一个碗，裂纹从凹陷中心向两侧蔓延到肩膀；
第三击命中同一位置，整片护盾像薄冰一样碎开，光屑往下掉，落到地面还在闪了两下才灭。
```

### 护体的方向性

护体通常有覆盖扇区。背后、侧面、脚下是薄弱面。这让「绕后」「下压」「贴地攻击」变成有效战术，而不是无意义的走位。

## 6. 构造具现

巨手、光刃、锁链、兽形、盾墙。

必写五项：

1. **来源**：从手心长出、从地面升起、从背后展开。
2. **成形过程**：先有骨架轮廓，再填实体，最后定形。不要一瞬间出现完整成品。
3. **归属**：明确是谁的构造、攻击谁。同一句里写清。
4. **交互**：抓、砸、扫、挡、缚，接触点要具体。
5. **消散**：任务完成或被打碎后，碎裂、剥落、化为粒子。

红线：

- 构造不许把施法者包在里面（看起来像自伤或作茧）。
- 构造不许遮挡接触点与两人轮廓。
- 构造的体积要与施法者的能量余量匹配；巨大构造之后必须有「虚了」的表现。

## 7. 隔空牵引与位移类能量

推、拉、定身、瞬移，是超能打斗里最容易被写成「想怎样就怎样」的一类。

规则：

- **必须有作用对象和方向**：拉谁、往哪拉、拉多远。
- **必须有反作用**：拉人时自己也被拽得前倾；定住重物时脚下要生根。
- **不能被拉的东西要说明原因**：抓住固定物、开启护体、负荷过重。
- **瞬移必须有痕迹**：起点残留轮廓、终点落脚反应、中间空气被挤压的环形扰动。
- **不能连续瞬移三次以上**：会让空间关系彻底失效。

## 8. 消散

消散是「这一击结束了」的信号，也是节奏的呼吸口。

必写：

- **光怎么收**：向外扩散淡掉、向内坍缩熄灭、被风吹散。
- **留下什么**：焦痕、裂纹、余烟、悬浮未落的碎屑。
- **人怎么样**：谁在喘、谁的手在抖、谁先站起来。

收束句示例：

```text
光束在 0.8 秒内从末端往回缩，缩到掌心时闪了一下就灭了；
空气里还浮着没落下的灰，落在他肩膀上；他的右手垂在身侧，指尖在抖。
```

## 9. 能量攻击的组合段

单发轰击容易单调，按下面这些段式拼接（每段 1.5–3 秒）：

| 段式 | 结构 | 用途 |
|---|---|---|
| 压制段 | 连续三发弹体 → 对方闪避换位 → 突进缩短距离 | 建立射程优势 |
| 反制段 | 对方突进 → 贴脸打断施法 → 用近身换回距离 | 破局 |
| 换血段 | 双方同时出手 → 各自命中 → 双向弹开 | 均势对拼 |
| 蓄力段 | 边打边蓄 → 一击放出 → 对方硬接被推走 | 转折 |
| 决胜段 | 长蓄力 → 对波 → 反推 → 洞穿 | 收尾 |

拼接纪律：相邻两段不能是同一种（连续两个压制段会让节奏塌）。每段结束写清位置、朝向、能量余量。

## 10. 检查

- 六阶段是否齐全？缺的那一步能不能补上因果，而不是删掉阶段？
- 束径/弹道/场域边界是否写了具体尺寸？
- 对手是否真的做了应对（挡/闪/接/反击）？
- 对轰是否写满五拍，拉锯里弱势方有没有身体反应？
- 护体是否经历了「凹陷 → 裂纹 → 破裂」而不是一次消失？
- 消散是否写了收束方式与残留？
- 全屏光效是否 ≤1 秒且接触点可读？
