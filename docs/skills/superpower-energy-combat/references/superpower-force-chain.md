# 超能发力链

本文件解决一件事：**让「他力气很大」变成能拍的画面**。所有超能动作都必须能拆成「支点 → 传力 → 末端 → 反作用」四段；超能力只是让这四段的**效果**变大，不能让它们**消失**。

## 1. 基础四段（写实底线）

```text
支点：脚掌/脚踝/膝/髋/肩/手撑物，谁是这一击的根
传力：扭矩从哪一节转到哪一节，先后顺序
末端：拳、掌根、指、肘、膝、脚背、脚刀、肩、头、兵器
反作用：打完以后，攻击者自己被推到哪、哪只手在抖、脚下踩碎什么
```

写成品时不必逐项注释，但每一击的句子里必须能找出这四段中的三段。**找不到支撑的那一击，就是飘的。**

常见漏写与补法：

| 漏写 | 症状 | 补法 |
|---|---|---|
| 没有支点 | 人像贴图平移，出拳像挥手 | 写「后脚掌碾进地面，地砖在脚跟下先裂开一条缝」 |
| 没有传力顺序 | 动作看起来像特效驱动的木偶 | 写「髋先转到位，肩才跟上，拳最后到」 |
| 末端含糊 | 分不清是拳、掌还是肘 | 明确接触面积：面 / 点 / 线 |
| 没有反作用 | 攻击者像站在滑轨上 | 写「一拳打完，他自己被顶得后撤半步，前脚在地上刮出一道白痕」 |

## 2. 空中动作的支点等价物

超能打斗最大的翻车点是「在空中蹬一下」。空气不是支点，必须给出等价物，并且**只给一种，说清楚**：

| 动作 | 支点等价物 | 写法要点 |
|---|---|---|
| 二段跳 / 空中变向 | 脚下凝出的能量踏板、蹬碎的浮石、器物抛出后蹬踏、推进喷口 | 踏板出现 → 蹬碎 → 碎屑朝反方向散开，三步都要有 |
| 滞空 | 反重力场、磁力悬浮、气流托举、能量翼 | 先有持续的可见消耗（脚下气流、翼面光影、身体轻微起伏），再谈滞空 |
| 高速冲刺 | 地面蹬裂起步、推进尾焰、气劲反推 | 起步处必须留痕：脚印、裂纹、被蹬飞的碎石 |
| 瞬闪 | 残留轮廓 + 两点之间的可见痕迹 | 残影 2–3 道快速淡出，落点处有落脚反应（尘、水花、地面凹陷） |
| 悬停施法 | 脚下构造、浮空法阵、念力托举 | 施法时身体要有承重感：肩背绷紧、衣摆被自身能量吹起 |

**红线**：同一段里换支点等价物 = 观众失去物理参照。要么一直用能量踏板，要么一直用推进，不能第一跳踏板、第二跳莫名悬停。

## 3. 能量链的四段

能量不是「发光」，是一条有起点、有路径、有末端、有释放的链。

```text
起点：核心/胸口/丹田/义体反应堆/掌心符印/兵器血槽
路径：沿脊柱上行 → 过肩 → 沿肱骨外旋 → 汇入掌心
末端：裹住拳面 / 在掌心聚成锥形 / 沿刃口铺开 / 在脚背拉成一条线
释放：贴住目标才放（近身）/ 推出去（轰击）/ 不放出只加重（蓄而不发）
```

写作纪律：

- **起点固定**：全片一个起点，不许这一招从胸口、下一招从眼睛。
- **路径可见**：一条亮线沿手臂爬升，比「周身金光」有用得多，也不容易糊住人脸。
- **末端形态决定接触效果**：面接触推开、点接触穿透、线接触切割。形态变了，效果必须跟着变。
- **蓄而不发是高级用法**：能量只到末端不外放，用来加重普通拳脚。这种写法既保住打击感，又不让画面变成烟花秀。

## 4. 力程：近身与隔空要分开写

| 力程 | 生效条件 | 传播过程（必写） | 受击表现 |
|---|---|---|---|
| 接触力程 | 必须有实际接触 | 无（就在接触点发生） | 形变、压缩、位移、骨折、甲片凹陷 |
| 隔空力程 | 必须有可传播的介质或场 | 空气扭曲 / 尘线推进 / 水面波纹 / 碎屑先飞 → 再命中 | 先被压后被打飞、衣服贴向受力面、呼吸被打断 |

隔空力程的三种常见写法：

1. **气劲推地**：掌根前推 → 地面一道尘线笔直推到对手脚下 → 尘线尽头炸开 → 对手被掀。尘线是时间的可视化。
2. **冲击波环形扩散**：落地 → 以落点为圆心地面下陷 → 环状尘浪向外推 → 到对手小腿高度时把他掀翻。环形有传播时间，不是瞬间全场。
3. **空气压缩**：拳未到，对手头发先被压向脸侧 → 然后是面部形变 → 然后才是位移。这个顺序不能倒。

**红线**：抬手 → 对手已经飞出去，中间零帧，一律判为失败。至少要有「介质先动」的一格。

## 5. 受力四通道

每次关键重击从四个通道里选 2–3 个写，不要四个全上（会糊）。

1. **身体**：守势压缩、肩背随力转动、后脚补步、重心失衡、空中姿态改变、落地缓冲或翻滚。
2. **物件/环境**：护甲凹陷、兵器震颤、积水沿力向溅出、鞋底推出尘土与沟痕、接触处碎片崩落、断裂方向服从受力方向。
3. **镜头/时间**：接触前极短停顿、命中瞬间冲击帧、受控短震、关键一击短促升格、击退后随势拉镜再回正常速度（配额见 `impact-budget.md`）。
4. **声音**：破风 → 接触材质声与低频 → 余振 → 落地声。因果顺序不能错。

## 6. 尺度分级

夸张程度服从人物量级，不要给每个人都用同一套反馈。

| 尺度 | 代表主体 | 受击表现 | 环境响应上限 |
|---|---|---|---|
| 凡人 | 拳手、士兵 | 踉跄、滑步、单膝跪地 | 水痕、尘线、木器开裂 |
| 强化者 | 改造士兵、轻装义体 | 贴地滑行、撞裂木石、撞穿薄墙 | 柱断、墙塌、气劲掀物 |
| 超能者 | 异能主角、魔修、灵能战士 | 凌空击退、穿破建筑、沿地面犁出深沟 | 石台崩碎、山体缺口、云海被冲开 |
| 巨构 | 巨型构造体、重装义体、兽形 | 多足撑地仍被推动、结构件变形、动作迟滞 | 地面龟裂、步震、烟尘柱 |
| 群体波次 | 虫群、无人机群、傀儡潮 | 密度空缺、编队缺口、潮线凹陷、单位沿力向爆散 | 覆盖物被犁出空带、堆积物位移 |

规则：

- **同一场最多两次「越级」**：一个强化者可以有一次打出超能者级别的效果，但必须有代价（透支、装备损毁、队友供能），且只能一次。
- **上下限都要守住**：能劈开大楼的人，被普通一拳打退三步是合理的（他在收力/在护人）；但被普通一拳打得吐血就不合理。
- **群体要写密度**：打散一片敌群后，空缺只能存在一到两拍，随后必须由后排补上，否则人数感消失。

## 7. 三个阶段的力量曲线

一场打斗的「力量感」不是恒定的，按阶段走：

```text
接触期：常规力度，破坏 1–2 级，主要建立双方量级对比
升级期：开始出现能量与位移，破坏 2–3 级，一次中段重击改变位置
决胜期：全片最强一击，破坏 4–5 级，明确胜负，之后立刻收束
```

- **不要在开场就用满**。开场打穿大楼，后面就无牌可打。
- **中段重击负责改地形**：把人打到另一个区域，而不是原地继续对拆。
- **决胜一击要有铺垫**：更长的蓄力、更明确的瞄准、更深的身体代价（前摇可见）。
- **打完要收**：胜利方喘息、手臂发抖、护体碎掉；失败方滑退、撞停、挣扎起身失败。不许站定摆造型超过 1 秒。

## 8. 反作用清单

写完一次重击，问自己「打的人付出了什么」。可选的代价：

- 后撤半步、多走一步、被自己的动量带走；
- 出拳侧的手腕发麻、指节渗血、护体过载闪一下；
- 支撑脚把地面踩陷，拔出时带起碎块；
- 呼吸被打断、短暂耳鸣、视野边缘发白；
- 兵器震得虎口崩开、能量余量掉一格。

**一次重击至少给一样。** 全片一个都不给，观众就会觉得「这不叫打架，这叫放技能」。
