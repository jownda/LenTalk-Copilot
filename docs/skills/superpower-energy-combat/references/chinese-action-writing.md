# 中文动作与运镜写法

## 禁止笼统词代替画面

成品动作描述不使用「激烈打斗」「拳拳到肉」「火花四溅很爽」「高手对决」「全程高能」「高速、猛烈」等笼统效果句。用户说这些词时，把需求落实到招式、线路、攻防回应、接触反馈和镜头运动，不原样当作动作指令。

| 不合格的描述 | 用具体画面替换 |
|---|---|
| 高速出拳，双方猛烈对拆 | 男子后手直拳进入，女子拍挡；男子回收未完即接摆拳，女子下潜，前臂沿单一路径留下短拖影。 |
| 拳拳到肉 | 短直拳打中躯干，衣料受压，受击者上身折下、后脚滑开半步，仍抬臂接下一击。 |
| 招式狠辣 | 点明本格使用的肘击/短钩拳等原词、方向、对手回应及实际结果，不用评价句。 |
| 运镜很猛、很丝滑 | 移镜头从两人侧面沿墙跟到女子身后；摄影者后撤换脚导致上下颠簸，接触时机身短震后继续追踪。 |
| 闪避后立即反击 | 点明是哪种闪避、哪只手接哪项库内招式、距离如何接得上。 |

## 内部用原词核对，成品用可见动作表达

生成前读取 `action-move-library.md`。规划层保留 `词条ID＋原词＋成品描述的对应关系`；成品以可见运动为主，不强制重复招式名称。常见名称有助理解时可简短保留；陌生术语、门派与动物意象转成具体身体轮廓和运动，不用另一个陌生词替换。用户明确要求保留名称时照做，并补足可见描述。内部ID与出处不进成品。

每格句式：

```text
[起止时间，0.5s] 谁的哪部分沿什么路径移动；对方同时或随即怎样回应；可见结果及接到下一格的状态。按当前阶段选写，不逐格重复整套说明。
```

起势、走线、落点和结果可跨格连续，不要求每格重复完整四段。剧情转译只展开用户事件；原创编排可在既定人物能力、伤势和结果范围内补动作。

写速度优先使用回收未完接下一招、防守中反击、步法带动距离变化，以及拳臂末端运动虚影。不强制每一拳填一个极小秒数，也不把没有依据的速度数字称为实测。

### 复杂动作的视觉锚点

优先写能区别于普通拳脚的画面特征：身体朝向如何改变，肢体画出直线还是弧线，轮廓从高到低还是由收拢到展开，以及结束时人在哪里。发生接触时补可见接触关系与符合既定结果的反馈；不能仅靠一个招式名让模型自行猜测。

必要时使用一个简短的日常运动类比，帮助表达轮廓或轨迹；紧接具体画面，避免模型把类比物体真的放进场景。能直接说清则不用类比。不得从来源例句复制武器、伤势、落点或结局。

短动作从当前状态接续即可，不必每次重新描述准备姿势；复杂全身动作需要的起落、转向和支撑转换仍须呈现，不因“只写结果”而瞬移或跳过中间过程。正向描述用于说明期望画面，必要限制仍可明确写出；不把“提到禁止项必然生成它”当作模型定律。

### 信息精简：删重复，保留因果

- 全局一次：人物外观、空间参照、光线、画幅、正常播放与机身状态。逐镜一次：景别、摄影路径及覆盖时间。逐格只写动作、回应、状态变化和接续。
- 同镜延续不重复焦段、身高、衣着和整套站姿。身份易混时重申角色名或关键锚点；发生变化时明确更新。不能为了省字让“他/她”失去指代。
- 每格优先保留主体运动与必要回应，再补会影响下一格的结果。材质与衣发细节仅在它们帮助识别速度或重量时出现，不对每次接触都堆满所有反馈。
- 不设任意字数硬限。删除解释性评价、重复约束和同义形容词；保留全部半秒格、格内先后/同时关系、复杂动作的中间过程，以及伤势、武器和空间变化。
- 内部动作与成品逐项对照：精简后动作次序、数量、授权结果和时间范围仍一致；若某个特征被删后无法区分动作，就把该特征补回。

### 局部表达示例：连续转向，不靠术语

此例仅示范一秒的运动表达，不是完整打斗模板，也不规定动作速度。设定为同一中景连续覆盖两格，两名角色无接触地换位。

笼统写法：角色做复杂旋转，快速闪到对方侧面。

较明确的写法：

```text
[0.0–0.5s] 蓝衣者沿画面左侧弧线移步，肩背连续转向镜头；灰衣者同步向右让开，两人间的空隙始终可见。
[0.5–1.0s] 蓝衣者延续同一转向，衣摆仍向外展开时脸已重新朝向灰衣者；灰衣者继续移出原位置，二人在画面中的左右关系完成交换。镜头沿原路径跟随，双脚仍在画内。
```

检查点：两格有同一连续过程；谁向哪边移动可追踪；格界没有强制停住；身份与最终相对位置明确。用于打斗时须映射本次已选动作，不能照抄此例替代连招。

### 来源与适用范围

以上吸收用户附件 `原文附件skill.zip` 内 `higgsfield-fight-scene.skill` 的动作转译思路，参考其 `SKILL.md`、`references/moves-catalog.md` 和 `references/choreography-patterns.md`，以本项目规则重新表述，未复制其招式段落。来源中的模型效果说法属于作者经验，尚未在本项目验证。未引入原作者身份、自动更新协议、固定英文输出、停顿节奏、低位腿法限制或固定风格锁。

## 运镜原词与执行描述分开

读取 `camera-move-library.md`，按七类选择原词。每镜用一个主要运镜，可配适用的构图和机身状态；不为凑分类堆满全部七类。

```text
景别原词＋运镜原词＋机身状态：起点 → 路径/方向 → 幅度或空间参照 → 时长/覆盖动作格 → 落点。
```

例如「中景，手持移镜头；沿断墙从两人侧面跟到女子右侧，覆盖前后两格，随摄影者后撤步上下颠簸」。不要另起「震荡追拳」「冲击贴身镜」等库外名。

已有「跟退/跟移」「前送」「后拉」「横移」「上摇/下摇」只作路径修饰；选用原词分别归入跟镜头/移镜头、推镜头、拉镜头、水平/垂直摇镜头，不把修饰词伪装成新库词。

## 运动虚影和手持晃动

用户要求拳脚快到虚影时，拳头、前臂和脚端可沿同一轨迹出现明显的短促运动模糊；躯干位置、双方身份、攻击大方向与接触后的反应仍可追踪。不要强制每帧手脚清晰，不把光效残影、复制肢体当作运动速度。

手持要写出后撤脚步的上下颠簸、侧步侧倾、转身惯性、接触时的机身短震。不能只写「手持」后又全段要求平滑、稳定、微抖；用户要的手持幅度由这些具体行为承担。

## 重量、伤势与夸张

用衣料受压、肩线偏转、躯干折叠、脚底滑移、落地余势等具体结果交付命中。有效命中后伤势与功能变化持续存在，不每次重新写成完好架势。

腾空、飞移、撞破木板可用于高潮，必须有发起、方向、落点和余势；用普通打击的较小位移衬托，不每击同级放大。全程不停顿需求下，不用冻结/AP/静态特写交付重量。

## 持械与语言

刀尖、刀背、握柄、棍端、护手、前臂、门框等对象要明确；写握持手、握持方向、接触对象及接触后的状态。用户指定徒手时不添加器械或持物动作。

成品语言遵从用户要求；中文成品使用自然中文，不因来源为英文就切换语言，不输出中英整段复读。词条来源放内部规划或用户要求的检查表，不塞进模型提示词。
