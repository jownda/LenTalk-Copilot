# 能力体系与视觉规则

超能力打斗的「燃」，一半来自打得好，一半来自**规矩立得住**。规矩一松，观众立刻知道这人想多强就多强，紧张感瞬间没了。本文件负责把能力变成有边界的系统。

## 1. 能力体系卡（五项必填）

每个有超能的人物，内部先填这张卡；不必向用户展示全表，但成品里的每个超能动作都必须能对上这张卡。

| 项 | 内容 | 影响什么 |
|---|---|---|
| 来源 | 身体核心 / 义体反应堆 / 法器 / 血脉 / 契约 / 科技装置 | 能量从哪出、被打哪会失效 |
| 射程层 | 贴身（0–1m）/ 近程（≤5m）/ 中程（5–30m）/ 远程（>30m） | 他站哪打、对手怎么逼近 |
| 形态 | 束 / 弹 / 场 / 构造 / 强化自身（五选二到三） | 每场只用 2–3 种，不许每招换 |
| 代价 | 耗能 / 过热 / 反噬 / 冷却 / 视野受限 / 行动变慢 | 什么时候会弱 |
| 失效 | 被打断 / 被吸干 / 核心被打坏 / 被针对 | 决胜的胜负手从哪来 |

### 来源必须固定

写一次「胸口核心」，全片都是胸口核心。不许这一招从掌心、下一招从眼睛、再下一招从脚下。观众需要一个可以盯着看的「力量源」。

### 射程决定战术

| 射程层 | 优势 | 弱点 | 典型打法 |
|---|---|---|---|
| 近程 | 爆发高、难躲 | 必须先贴身 | 用位移和护体硬吃一发，换近身 |
| 中程 | 攻守平衡 | 距离被拉近就失效 | 用轰击逼对方移动，维持距离 |
| 远程 | 安全 | 蓄力长、易被打断 | 靠地形和队友拖时间 |

打斗好看的核心是**射程差的博弈**：远程方想拉开，近身方想贴上。每换一次距离，就是一次攻守交换。

## 2. 代价必须可见

代价不是设定里的括号注释，是画面上能看见的东西。

| 代价 | 可见表现 | 出现时机 |
|---|---|---|
| 耗能 | 护体变薄、光色变暗、聚能变慢 | 连续输出之后 |
| 过热 | 手臂冒白汽、皮肤泛红、指尖焦黑 | 大功率一击之后 |
| 反噬 | 用完后咳血、单膝跪地、耳鸣 | 越级使用之后 |
| 冷却 | 想再放却只挤出一点光，掌心闪两下就灭 | 关键时机被打断 |
| 视野受限 | 光太亮，自己眯眼、看不清对手 | 近距离对轰之后 |
| 行动变慢 | 脚步沉、反应慢半拍、被抢位 | 场域维持期间 |

**代价要在最需要的时候发作**，而不是均匀分摊。全片最惨的时刻，往往就是代价发作的时刻。

## 3. 色彩纪律

一场战斗只允许**一套对立色**。

```text
主角：青蓝（冷、锐、向内收）
敌方：暗红（热、钝、向外扩）
```

规则：

- 主色只给两人各自的能量，不混用。
- 辅助色（白、金）只用于高光与火花，且不改变整体色相。
- 禁止每个技能一个颜色（彩虹轮播会让画面变成迪斯科）。
- 环境色不抢主色：如果场景是大面积橙色（火光、夕阳），主角用青蓝正好对比；如果场景已是青蓝（夜空、水下），主角要换暖色或提高明度。
- 能量染色天空单次 ≤1 秒，不改变环境底色。

## 4. 特效分层

特效分两层，绑定对象不同，不能混。

| 层 | 绑定对象 | 举例 | 时长 |
|---|---|---|---|
| 核心特效 | **命中瞬间** | 光爆、接触点火花、能量波纹、护体凹陷 | 0.1–0.3 秒，随之消散 |
| 辅助特效 | **运动过程** | 动态模糊、残影、速度线、衣发翻飞、粒子尾迹 | 跟随动作，动作停则停 |

纪律：

- 核心特效不允许长时间挂着。打完了还亮着，就是「贴图没关」。
- 辅助特效不能遮住主体轮廓、肢体衔接和接触点。
- 残影 2–3 道快速淡出，不能变成分身。
- 技能余波只留焦痕、裂纹与碎屑；**禁止地面残留发光法阵圈或彩色光环**（下一镜会被当成新元素）。
- 能量染色天空 ≤1 秒。

## 5. 能量等级与画面成本

同一套能力，从「随手」到「拼命」要拉开画面差距，否则观众感觉不到升级。

| 等级 | 蓄力 | 视觉 | 破坏 | 代价 |
|---|---|---|---|---|
| 随手 | 无 | 只有末端微光 | 1–2 级 | 无 |
| 认真 | 0.3–0.5s | 可见束流/弹体、被照亮环境 | 2–3 级 | 轻微 |
| 全力 | 0.8–1.5s | 长束、构造、环形冲击波 | 3–4 级 | 明显（过热、喘） |
| 拼命 | 长蓄 + 前摇 | 全屏光效（≤1s）、地形改变 | 5 级 | 严重（反噬、失能一瞬） |

**一场只允许一次「拼命」。** 用两次，第一次就不算拼命。

## 6. 能力与身体的绑定

超能力必须长在身体上，不能浮在空中变成独立特效。

- 能量从体内出来，身体要有反应：肌肉绷紧、皮肤下亮起纹路、血管凸起、体温升高（周围空气扭曲）。
- 出力越大，身体姿态越极端：弓步更深、脊柱后弓、牙关咬死。
- 用错部位会受伤：用手臂放超出负荷的能量，手臂先废。
- 被打断时身体要有反馈：手势被打偏、能量倒灌、手掌被自己的光灼一下。

## 7. 特殊能力类型的补充规则

### 强化自身型（体术流）

- 力量增幅要有「压不住」的表现：握碎手里的东西、落脚踩裂地面、呼吸带白汽。
- 速度增幅要有「刹不住」的代价：转向要划弧、停下要滑一段。
- 不打能量，靠位移与打击取胜；允许蓄而不发的末端微光。

### 场域型

- 边界必须可见（薄膜、扭曲、浮尘）。
- 维持需要姿势和注意力：被打断就散。
- 对自己也生效（重力场里自己也变重），否则就是无解。

### 构造型

- 成形有先后：骨架 → 填充 → 定形。
- 有重量：落地会砸出坑、被击会震颤。
- 有归属：同一句写清是谁的、打谁。
- 被打碎要有碎块，不能直接消失。

### 吸收/反弹型

- 吸收有上限：吸到某个量就必须放出去或撑爆。
- 吸收过程可见：能量沿身体表面流入某个部位。
- 反弹有延迟和方向：不是原路反射，而是转个角度打回去。

## 8. 能力不许越界的三条

1. **不许临场加设定**。用户没说「他能飞」，就不能在打不过的时候突然飞走。
2. **不许无代价升级**。要变强，必须蓄更久、付更大代价、借外力，三者至少一样。
3. **不许违反已建立的物理**。前面说他的护体挡不住穿透，后面就不能硬接一记穿甲。

## 9. 检查

- 每个超能人物是否有来源、射程、形态、代价、失效五项？
- 一场是否只用 2–3 种形态？
- 代价是否在最关键的时刻发作并被看见？
- 是否只有一套对立色？
- 核心特效是否绑定命中、辅助特效是否绑定运动？
- 有没有残留的发光法阵/光环被带进下一镜？
- 「拼命」级是否只出现一次？
