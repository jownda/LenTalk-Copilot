# 接触物理（含超能等价链）

## 适用原则

本文件负责把接触写成可见过程。剧情转译不创建用户未给的攻击/伤势；原创编排可在已定人物、器械、伤势上限与结果内设计接触。两种模式都先从招式库、能量库取原词，再补线路和身体反馈。

超能只改变**量级**，不改变**顺序**。脚蹬地 → 髋转 → 肩送 → 末端 → 接触 → 形变，这条链在超能打斗里一样成立，只是每一环的效果被放大。详见 `superpower-force-chain.md`。

## 徒手动力链

按需要写出：脚的支撑、腿的传力、髋的转动、肩的送出、肘或手的末端轨迹。不要只写「他用力打」。命中后，攻击者也要遵守重心变化：前倾、收步、重新支撑或被自己的动量带走。

```text
脚蹬地 → 髋转 → 肩送 → 前臂/拳/肘走线 → 接触点 → 受击方形变
```

## 超能等价链

```text
能量起点（核心/义体/法阵） → 可见路径（沿脊柱、手臂、兵器） → 末端成形 → 释放
```

两条链是**叠加**关系，不是替代关系：能量可以裹在拳上，但拳仍要按拳的走线打出去。

- 只有能量没有身体 → 像放技能，不像打架。
- 只有身体没有能量 → 超人设定失效，看起来仍是普通人。

## 持械动力链

持械动作至少交代：

1. 哪只手握持，手腕和肘部处于什么角度。
2. 武器从哪里起，沿直线、弧线、下压线或推送线运动。
3. 武器接触的是人体、衣物、墙、地面、门框还是其他物件。
4. 接触后武器是继续通过、卡住、反弹、脱手、被抓住还是留在原处。

能量附着在兵器上时，额外写：附着发生在刃口、刃背还是整柄；附着后兵器重量与手感有无变化（有变化就必须演出来，例如挥动变慢半拍）；脱手后能量是否随之消失。

## 隔空力程

隔空攻击（气劲、冲击波、能量束、力场）必须写出**传播过程**，这是它与接触力程的唯一区别。

```text
抬手/推掌 → 介质先动（空气扭曲、地面尘线、水面波纹、碎屑先飞）
→ 命中（接触点出现） → 身体形变 → 位移
```

顺序不能颠倒。介质没动就命中，等于瞬移。

## 作用线与环境

环境响应沿作用线发生：灰尘滑开、水面被推开、门板振动、物件滚动或碎屑落下。

超能场景额外要求：

- 环境响应与量级匹配（见 `destruction-and-environment.md` 五级）。
- 破坏方向服从受力方向。
- 残留物（焦痕、裂纹、断口）持续到结尾。

## 受击顺序

写实受击通常按以下顺序表现：

```text
接触 → 短暂僵直 → 局部形变 → 脚下失稳 → 呼吸改变 → 延迟护伤或重新支撑
```

超能者可以压缩或跳过「短暂僵直」（抗击打更强），但**不能跳过形变与失稳**。跳过这两项，人就会显得像塑料模型。

推、拉、拖、撞和摔不一定产生「命中僵直」。如果用户描述的是持续推动或被拖走，应写脚跟不上、衣物被拉紧、身体被带走和撞停，而不是凭空添加 hitstop。

## 量化

给出秒数和距离、步数或画幅占比。没有可靠依据时，使用相对量：半步、一个身位、四分之一画幅、飞出三米。

超能场景尤其需要量化，因为「被打飞」的默认尺度在不同模型里差异极大：

- 普通一拳：后退半步到一步。
- 有效重击：一到两个身位，脚离地。
- 超能重击：飞出三到十米，撞穿一到两层结构。
- 决胜击：十几米以上，或直接被地形改变吞掉。

同一场里必须由小到大递进，不能第一击就飞十米。

## 空场检查

写任何击退前，检查起点、方向、距离、落点、落点障碍五项。起点与落点重合时，模型会把人物钉在原地摆造型。修法见 `destruction-and-environment.md` 第 4 节。
