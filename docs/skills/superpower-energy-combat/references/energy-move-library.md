# 能量招式库

能量攻击的原词索引。**取词纪律与招式库一致**：规划层用原词与 ID 核对，成品写可见画面，不把 ID 投喂给模型。

本库只收「能量作为攻击手段」的原词；身体动作用 `action-move-library.md`，两者可以叠加（例如「裹拳的摆拳」= ACT 弧线拳 + EN 近身能量）。

## 取词路由

先定三件事，再查表：

1. **距离**：贴身（0–1m）/ 近程（≤5m）/ 中程（5–30m）/ 远程（>30m）。
2. **目的**：造成伤害 / 换距离 / 破阵型 / 打断施法 / 防守 / 收尾。
3. **形态**：束（直、连续）/ 弹（有飞行）/ 场（覆盖）/ 构造（有实体）/ 强化（加在自己身上）。

查表时优先选同族连续 2–3 条，不要跨族乱取——跨族越多，画面越像技能展示。

## 组合段（按段拼接，相邻段不要同型）

| 段式 | 取词 | 结构 |
|---|---|---|
| 压制段 | EN-14 → EN-16 → EN-49 | 连发 → 散射逼位 → 突进 |
| 反制段 | EN-50 → EN-33 → EN-26 | 踏板逼近 → 抓住放电 → 贴脸轰 |
| 换血段 | EN-13 与 EN-27 同时 | 双方各出一手，双向弹开 |
| 破防段 | EN-10 → EN-10 → EN-81 | 同一点两发破甲 → 洞穿 |
| 蓄力段 | EN-38 → EN-79 | 边打边蓄 → 全力一击 |
| 决胜段 | EN-02 → EN-80 → EN-82 | 重炮 → 对波反推 → 环形崩解 |

## 禁用写法

- 「一道光」不写束径与落点 —— 无法判断量级。
- 「能量爆发」不写从哪出、往哪去 —— 等于没写。
- 每招换一种颜色 / 一种形态 —— 体系崩塌。
- 抬手即命中 —— 没有传播，就没有力量。
- 对轰相持数秒不动 —— 会被拍成静态壁纸。
- 技能放完地面留发光法阵 —— 下一镜会变成新元素。
- 构造把施法者包住 —— 看起来像自伤。
- 连续三次瞬移 —— 空间关系失效。
