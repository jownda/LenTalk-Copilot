# 样片拉片记录 02：多人持械混合近身战

## 样片范围与精度

- 时长约 48.1 秒，1740×1080，30fps；画面为手持/肩扛感的剪辑动作段，含持续配乐/声音轨。
- 以下时间段按视频抽帧观察估算，分段边界约有 ±0.3–0.5 秒误差；不是逐帧剪辑检测，也不据此声称精确命中帧或实际接触。
- 这是一段风格化电影动作，含明显大位移和腾空高潮。提取的是节奏、反应链和摄影机组织方法，不把夸张位移写实化。

本文件记录旧样片，不设定本 Skill 默认节奏。生成仍按主文件逐0.5s规划并交付打斗；样片的蓄压、重置和数秒余波只在用户允许时取用。全程不停顿时，受击与落地后果放在继续追击、防守或移动中交代，不另加结果展示段。

## 时间轴观察

|---|---|---|
| 0–2.5s | 烟雾中人物进入并转向；先给姿态、空间和危险方向，短暂蓄压 | 近景/中近景缓慢跟随，斜构图与环境烟雾先建立气氛，没有立刻把镜头切成逐拳碎片 |
| 2.5–8.5s | 首轮突袭、低头闪避、近身拳脚和短促控制；一轮动作结束后身体仍在移动，接上下一位攻击者 | 贴身中近景快速重构图，偶尔保留两人关系；切点多落在动作方向改变或注意力转移处。手持起伏、倾斜与运动模糊明显，部分细节因此不完全清楚 |
| 8.5–11.5s | 首轮敌手退出画面/落地，主角显出手中器械，新的攻击者进入，动作短暂重置 | 镜头拉开，让器械和新攻击者进入同一空间；这段“看清局势”的过门为下一簇重新蓄压 |
| 11.5–19.5s | 第二轮强度抬高：器械交锋、躲避、踢击和大幅位移交替；一次腾空/击飞成为段落高点 | 中景、全身和大广角来回切换。大位移时放宽构图，呈现从发力到对手离开原位置的距离；接近时又回到贴身跟拍 |
| 19.5–23.5s | 器械线被双方手臂卡住，争夺转成推压和身体控制；动作数量减少但压力增加，随后一方失去支撑 | 较近的双人构图持续保留武器和手臂关系。镜头没有为每个小动作切开，紧张来自持续受力、武器方向和身体逐步塌陷 |
| 23.5–29s | 倒地后短暂空隙，另一名攻击者重新进入；近身抓抱、压低重心，把人带向柱/箱体附近 | 镜头从地面结果回到中景，随后靠近身体控制；空间硬边和箱体帮助读出位移，不只拍面部 |
| 29–35.5s | 长杆/棍状器械扫入，主角躲、格、贴近，再形成近身控制和反制；攻防方向数次转换 | 一段较宽全身镜展示器械作用线，之后切到更近的身体交叠；动作方向和攻击者身份靠重新构图维持，而不是每拍都换轴 |
| 35.5–38.5s | 大幅腾空/撞击成为第二个高潮，接着目标倒地并伴随纸箱/灰尘等环境余势 | 先让全身动作和空间高度可见，再切低位落点与环境尘屑。冲击的余波持续数秒，身体没有在接触帧后立刻“复位” |
| 38.5–42s | 倒地者迟缓调整，器械留在地上；主角经过并重新建立胜者与场地关系 | 低机位停留在倒地者和地面器械，再拉成宽景。击打段结束后，镜头有意放慢，给惯性、呼吸和局势确认时间 |

## 节奏与打击感拆解

### 1. 节奏按“交锋段落”变化，不按每拳切镜

首轮交手的动作密度高，但观众仍能看到闪避、攻击方向、对手进入和结果。几次切镜改变主体或景别，却不把每一个拳头拆成单独特写。重要的是动作短语完整：发起/避让 → 接触或控制 → 身体结果 → 下一位攻击者或下一段动作进入。

### 2. 用方向交接让下一拍有因果

闪避和受击后的身体移动，经常把人物带到新的画面位置；摄影机随两人共同位移重新构图。下一次攻击从人物已形成的新距离和朝向接出，而不是在一个静止姿势上凭空出现。多人段尤其应明确攻击者从画面哪一侧进入、主角当前朝向谁。

### 3. 打实靠“接触短、后果长”

接触本身很快，随后反应可以持续数拍：躯干转动、肩线塌下、支撑脚挪位、退步、倒地、手臂护住受击区域，或碰撞物件后仍继续下滑。身体受力后还在移动，是重量感的一部分。不要把所有力量都塞进接触瞬间的冻结或震屏。

### 4. 节奏低谷可以是持续受力，不必空下来

约 19.5–23.5 秒的武器/手臂卡锁段动作变少，但双方仍持续推压、改变支撑和争夺作用线。它不是静止摆 pose，而是力量没有释放的压力段。之后重新进入更快动作时，提速会更明显。

### 5. 高潮后留出“落地—余波—确认”

大位移接触之后，样片给倒地、尘屑和地面器械留了数秒，再用宽景确认谁仍站立。这个长尾把高潮变成有后果的结果。动作提示词可按场景缩短，但不能在每次命中后都重复同样长度的停留。

## 对 Skill 的可复用规则

- 多人动作先按交锋对象/控制权变化划成动作段落，再在段落内部安排接触拍点；不要按每个拳头逐一强切。
- 每次防守、受击或位移都要改变下一拍至少一项：距离、朝向、支撑、攻击线、器械控制或场景位置。
- 碰撞反应分两层写：接触点短而清楚；随后用连续身体动作交代受力传递和重心恢复/失衡。连续重击可重叠回收与下一击启动，但不能让身体反馈消失。
- 快段中适度回到全身/宽景，尤其在多人换位、踢击、器械长线或大幅位移前后；贴近镜头负责感受压迫，宽景负责证明动作和空间关系。
- 手持晃动可以随摄影者脚步、转身、贴身碰撞和重击发生；让主运动方向仍可追踪。斜构图可以加强失衡或混战压迫，但持续斜拍会损害方向判断，不设为默认。
- 可把腾空、明显飞移或撞箱/撞柱用作高潮放大，不必限定在纯写实模式之外。优先集中在少数高点，并让起势/发力、飞行方向、落点和落地余势形成可读因果；普通交锋仍保留较克制的受力尺度，靠反差托起夸张高潮。若用户指定严格写实，再降低夸张级别。
- 在重击后按结果选短反应、继续缠斗或长 aftermath；高潮的长留应服务于伤势/胜负/空间变化，普通接触不套用。

## 不宜直接照搬

- 该片的斜角、广角透视、拖影、腾空位移和环境撞击明显偏电影化；它们可作为高潮设计资源，不必成为普通每一击的默认尺度。若目标是严格写实，应相应降低幅度。
- 抽帧能分析姿态和镜头关系，无法单独确认每个剪辑点的逐帧接触、演员安全距离或音效层。不可把视觉上的大位移等同于真实伤害等级。
- 片中声音轨持续到接近片尾；当前分析未逐段试听和分离音乐/撞击音，因此不据此制定音效配额。
