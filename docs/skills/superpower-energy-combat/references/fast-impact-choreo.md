# 高速贴身冲击模式

用户要求快速拳脚、连续命中、贴身跟拍、“拳拳到肉”或给出类似的实拍参考时读取。它是一组可选的呈现参数，不是新的剧情许可；用户明确给出的动作数量、顺序和结果始终优先。

## 本模式写作约束

先执行主文件的写作硬规则：读取招式库、运镜库和中文写法；打斗逐0.5s规划并输出。用户要15s纯打斗时列30格，每格说明动作如何接续，不把「高速、猛烈、拳拳到肉」写成效果指令。

规划层核对招式原词；成品每格写「可见运动＋必要回应＋接触/落空后的变化」，同镜的景别、运镜与手持路径不逐格重复。拳臂末端允许沿运动方向出现虚影，不强制每帧手脚清晰；按当前动作选用必要反馈，不堆满全部身体和材质细节。数字仅是编排设定，不声称视频模型能精确执行或样片已实测。

全程不停顿时，不安排静腔、冻结、AP、静态眼神/喘息特写或为结果确认而停演；受击反应、落地余势和伤势变化放在继续移动/继续攻防中呈现。手持晃动按后撤步、转身、受力分别描述，不用「平滑」「轻微微抖」把用户要求抵消。

## 参考片的可见特征

近身动作参考靠短促的拳腿交换、密集的躲闪和身体反应维持压强。前一支约 33 秒样片中，镜头在全景、中景和接触特写间切换；动作簇中贴着双方移动，控制或持械僵持时短暂放慢并保持近距离。旧拉片记录中的约 48 秒多人持械样片则呈现“短爆发 → 武器/空间重置 → 持续受力低谷 → 再爆发 → 长余波”。发丝、衣摆、躯干和支撑脚的延迟运动把一次接触延伸到后果。两支样片都不是恒定高密度，第二支的分段记录见 `references/reference-clip-analysis-02.md`。

这类素材常带明显手持晃动、运动模糊和快速重构图。这里的“丝滑”指动作和镜头节奏衔接顺畅、运动方向有连续性，不等于稳定器或无晃动画面。用户要求丝滑时，保留有来源的步伐起伏、受撞震动和快速重构图；让摄影机的启动、转向和落点成为可追踪的连续轨迹，压低无来源的随机抖动。镜头可以晃，但晃动要跟着摄影者脚步、身体受力或动作冲击发生。

## 动作节奏

用户反馈动作慢、单调或缺少连招时，必须同时读取 `high-speed-screen-choreo.md`。先编完整视觉短语再分格；下方2–4个接触拍点不是上限，0.3–0.5s反应是与后续动作并行的延续窗口，不是接触后独立等待。复杂全身动作使用足够的中景或全景，不为近景比例切掉完成过程。

- 默认实速。优先以半秒格中的动作先后与回收重叠安排速度；单次出拳或出腿的秒数如需填写，明确是本次编排参数，不硬套前一支样片的速度。
- 连续攻击可写成一段动作链：上一击的回收、下一击的启动、对方的闪躲或受击反馈可以重叠。剧情转译模式只描述素材里已有的招式，不把防守自动变成反击；原创编排模式可按动作目标设计新招与回应。
- 可把同一连续动作在一个跟拍镜头内呈现约 2–4 个接触拍点，常见镜长约 0.8–1.5s；这是可选范围，不是密度配额。动作太多或太复杂时延长镜头、分成因果相连的镜头，或询问缺失的编排。
- 普通单次命中采用“短接触 + 反应延续”：接触瞬间清楚，随后通常 0.3–0.5s 展示头肩偏转、躯干折叠、脚步修正或被带动的位移。重击、摔撞或大幅位移可让反应继续数拍，直到身体/物件余势和新站位交代清楚；反应幅度服从用户指定结果，不把擦过升级成重伤或倒地。
- 连续攻防按完整交锋短语组织，不要每拳必切。多人场景里用攻击者进入方向、双方朝向和重心/距离变化交代下一拍由谁接手；器械僵持可减少招式数量，以持续推压、支撑脚变化和作用线争夺制造压力。
- 高潮命中之后按结果安排“落地 → 余波 → 局势确认”：全程不停顿需求下，宽景随落地、追击或格挡继续移动，结果确认不占独立静止格。用户允许停留时才考虑较长结果镜头，不复制样片的具体秒数。
- 可用适度腾空、明显飞移或环境撞击放大少数关键重击；这类夸张能增加爽感，不视为错误。用前面的动作压力、清楚的受力方向和落地余势支撑它，并让普通打击保持相对克制，形成力度层级；用户要求严格写实时再收回夸张幅度。
- 用头发、衣摆和身体惯性延续动作，不把这些惯性细节误写成额外招式。剧情转译模式不额外添加独立动作；原创编排模式可按授权设计持械控制、脱离或攻防变化，并维持武器状态连续。

## 贴身运镜

- 用原词「中景」「全景」交代双方距离、方向和腿部动作；连续交换中可贴近为「近景」，让拳路、闪避和受击反应保持在同一动作线上。
- 摄影机追踪双方的共同运动中心，而非每一拳都独立追手。选用「移镜头」或「跟镜头」沿侧向/弧线路径跟住位移；需要靠近时选「推镜头」，前送幅度与接触反馈配合，不另造镜头名。
- “丝滑跟拍”写清起点、连续行程、转向和落点；保持方向与速度变化可读，同时保留有来源的手持起伏和接触震动。避免无来源的随机抖动、每拳一次甩镜或无理由急停。不要因为“丝滑”自动切换到稳定器，也不要抹掉动作需要的镜头晃动。
- 快速动作可在攻击线尚未收回时匹配切换方向或景别，但接触点及第一拍受击反应尽量留在同镜。在空间关系需要重建时用「全景」交代，不要长时间只切脸和拳头。
- 在多人换位、踢击、长器械作用线或大幅位移前后回到全身/宽景；贴身景别提供压迫，宽景证明方向、距离和结果。斜构图可在失衡或混战节点短用，随后恢复可读的空间方向。
- 用户要出拳快到虚影时，允许拳、前臂和脚端出现明显但短促的运动模糊；保留身体大方向、相对位置和接触后的反馈。不要以全程清晰或减少全部手持晃动为默认修正。

## 读取第二支样片时

用户给出多人、持械与徒手混战参考，或要求分析“高潮之后怎么落地”时，读取 `references/reference-clip-analysis-02.md`。它提供约略时间段和交锋结构，不是固定镜头数/秒数模板；样片中的腾空与远距离飞移可作为风格化高潮资源，按整体写实程度和动作强弱选择使用。

## 重量与限制

“拳拳到肉”靠可读的接触关系和反应，不靠每击叠特效：拳/腿到达明确目标，接触瞬间短，身体反应紧随其后，衣发和重心继续运动。冲击音可在用户要求声音设计时与关键接触同步；不要自动给每拳配同样的夸张撞击声。

不要默认冻结、AP、震屏、强拖影或慢镜。它们与连续高速感冲突，只有用户明确要求或特定事件需要强调时才使用，并服从主 Skill 的当前硬规则；全程不停顿时冻结/AP为0，不引用旧样片配额。
