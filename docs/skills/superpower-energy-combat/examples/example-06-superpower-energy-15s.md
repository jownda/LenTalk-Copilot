# 回归样例：废弃中庭超能对拼，15 秒 30 格

本文件用于验证「0.5 秒粒度 + 能量六阶段 + 破坏五级 + 冲击预算」四件事同时成立时怎么写。它是规划层样例，保留 ID 便于查验；成品按模板移除 ID 与路径。未生成视频，不据此声称成片效果已验证。

## 条件与来源

- 模式：原创编排；下表 B01–B30 全部为授权内创作拍点。
- S01：主角 A（青蓝能量，掌炮与裹拳，射程近程，代价=右手过热）；对手 B（暗红能量，胸口核心，近身冲击与护体，代价=护体消耗）。
- S02：废弃中庭，两侧各三根方形立柱，中央一片浅水，后方一堵砖墙；A 起始在画面左，B 在右；摄影机起始在两人南侧。
- S03：允许一处腾空、一处对波；结局为 A 胜，B 被洞穿后失去战斗能力；不写死亡。
- S04：片型按「一张一弛」处理；冲击帧 0 次、hit-stop 0 次、升格 0 次、全屏光效两次各 ≤1 秒。本样例刻意把一个「一张一弛」的场次压进 15 秒的高密度，用来验证节奏仍然成立。
- S05：手持跟拍为主，接触短震后继续原路径；不甩镜。
- 招式出处：`references/action-move-library.md`（ACT-）；能量出处：`references/energy-move-library.md`（EN-）；镜头出处：`references/camera-move-library.md`。

## 能量与破坏账本

| 项 | 内容 |
|---|---|
| 色系 | A 青蓝（锐、向内收）；B 暗红（钝、向外扩）；辅助色只用白色高光 |
| A 的能量起点 | 胸口偏左，沿右臂内侧上行到掌心；右手过热时纹路由青转暗 |
| B 的能量起点 | 胸口正中一颗核心，聚能时核心由中心向外扩张一圈 |
| 护体 | 只 B 有，覆盖正面与两侧，背后与脚下是薄弱面；消耗到第三次受击时破裂 |
| 破坏推进 | 2 级（1.0s 地砖）→ 3 级（7.0s 断柱）→ 3 级（8.5s 柱裂）→ 4 级（14.0s 穿墙）→ 5 级（14.5s 地面塌陷成坑） |
| 残留 | 断柱、柱裂、地面沟痕、砖墙缺口、水被冲开，全部保持到结尾 |

## 本样例验证了什么

1. **每格都有力的来源**：B01 蹬碎地砖、B10 蹬碎踏板、B18 撞柱、B27 犁沟——没有一个动作是凭空发生的。
2. **每次命中都有三件套**：B03（接触—退半步—A 前脚承重）、B12（接触—护体凹陷—A 落地缓冲）、B29（接触—穿墙—A 手臂垂落）。
3. **先接触后特效**：B07 先聚能再甩出、B09 先飞行再炸、B17 先压弯水纹再命中。
4. **破坏只增不减**：断柱（B15）在 B16、B17 里继续存在；柱裂（B18）保留到结尾；穿墙（B29）之后街景成为新背景光源。
5. **能量六阶段齐全**：以 B25–B30 为例，蓄力（B23/B24）→ 引导（B25）→ 传播（B25）→ 相遇（B25）→ 响应（B26/B27）→ 消散（B30）。
6. **对波五拍 + 高低/角度错位**：B25 两束不是平行对顶，A 从低处斜上推，B 从高处斜下压，避免同高度静止对推。
7. **冲击预算未超**：全片冲击帧 0、hit-stop 0、升格 0、全屏光效 2 次各 ≤1 秒（B26、B29）。
8. **代价被演出来**：A 右手过热到指尖发抖（B30）；B 核心裂纹（B28）→ 护体洞穿（B29）。
